Here's a complete implementation of `normalize_corpus` that walks an input directory, normalizes every `.txt` file, and mirrors the folder structure into an output directory.

```python
import os
import unicodedata
import re


def normalize_corpus(input_dir, output_dir, lowercase=False):
    """
    Normalize every .txt file under input_dir and mirror the folder structure
    into output_dir.

    Normalization applied:
      1. Unicode NFC normalization.
      2. Whitespace collapse: any run of whitespace -> single space; strip ends.
      3. Optional lowercasing.

    Args:
        input_dir (str): Root directory containing .txt files.
        output_dir (str): Root directory to write normalized .txt files.
        lowercase (bool): If True, lowercase the text.

    Returns:
        dict: Summary with counts of files processed, skipped, and errors.
    """
    if not os.path.isdir(input_dir):
        raise NotADirectoryError(f"Input directory does not exist: {input_dir}")

    os.makedirs(output_dir, exist_ok=True)

    # Collapse any run of Unicode whitespace into a single ASCII space.
    whitespace_re = re.compile(r"\s+", flags=re.UNICODE)

    stats = {"processed": 0, "skipped": 0, "errors": 0}
    errors = []

    for root, _dirs, files in os.walk(input_dir):
        for filename in files:
            if not filename.lower().endswith(".txt"):
                stats["skipped"] += 1
                continue

            src_path = os.path.join(root, filename)

            # Compute mirrored destination path.
            rel_path = os.path.relpath(src_path, input_dir)
            dst_path = os.path.join(output_dir, rel_path)
            os.makedirs(os.path.dirname(dst_path), exist_ok=True)

            try:
                with open(src_path, "r", encoding="utf-8", errors="strict") as f:
                    text = f.read()

                # 1. Unicode NFC normalization
                text = unicodedata.normalize("NFC", text)

                # 2. Whitespace collapse + trim
                text = whitespace_re.sub(" ", text).strip()

                # 3. Optional lowercasing
                if lowercase:
                    text = text.lower()

                with open(dst_path, "w", encoding="utf-8") as f:
                    f.write(text)

                stats["processed"] += 1

            except UnicodeDecodeError as e:
                stats["errors"] += 1
                errors.append((src_path, f"decode error: {e}"))
            except Exception as e:
                stats["errors"] += 1
                errors.append((src_path, f"{type(e).__name__}: {e}"))

    stats["error_details"] = errors
    return stats


if __name__ == "__main__":
    import argparse

    parser = argparse.ArgumentParser(description="Normalize a .txt corpus.")
    parser.add_argument("input_dir", help="Source directory")
    parser.add_argument("output_dir", help="Destination directory")
    parser.add_argument(
        "--lowercase",
        action="store_true",
        help="Lowercase the normalized text",
    )
    args = parser.parse_args()

    result = normalize_corpus(args.input_dir, args.output_dir, args.lowercase)
    print(
        f"Processed: {result['processed']}  "
        f"Skipped: {result['skipped']}  "
        f"Errors: {result['errors']}"
    )
    for path, msg in result["error_details"]:
        print(f"  ! {path}: {msg}")
```

### How it works

1. **Validation & setup** — checks the input exists and creates the output root.
2. **`os.walk`** — recursively traverses the input tree, so nested subdirectories are handled automatically.
3. **Extension filter** — only files ending in `.txt` (case-insensitive) are processed; everything else is skipped.
4. **Path mirroring** — `os.path.relpath` + `os.path.join` reproduces the same relative layout under `output_dir`, and `os.makedirs(..., exist_ok=True)` creates intermediate folders as needed.
5. **NFC normalization** — `unicodedata.normalize("NFC", text)` composes characters into canonical form (e.g. `e` + combining acute → `é`).
6. **Whitespace collapse** — the regex `\s+` matches tabs, newlines, non-breaking spaces, and other Unicode whitespace, replacing each run with a single space; `.strip()` removes leading/trailing space.
7. **Optional lowercasing** — applied last, so it operates on already-normalized text (this matters for some locales where case folding interacts with composition).
8. **Error handling** — decode failures and other exceptions are recorded per-file rather than aborting the whole run.

### Notes and possible tweaks

- **Encoding**: assumes UTF-8. For mixed encodings, swap in a detection library (e.g. `charset-normalizer`) and pass the detected encoding to `open`.
- **Preserving newlines**: if paragraph breaks matter, replace `\s+` with `[^\S\n]+` to collapse horizontal whitespace but keep line breaks, or split on blank lines first.
- **Idempotency**: the function is idempotent — running it twice on the same output produces identical results, which is convenient for reproducibility checks.
- **Symlinks**: `os.walk` doesn't follow symlinked directories by default; pass `followlinks=True` if you want that behavior.
