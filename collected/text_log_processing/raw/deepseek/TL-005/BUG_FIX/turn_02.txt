You're right on both counts — let me address them precisely.

## The two bugs

**1. Flattening subdirectories.** The original used `os.path.relpath(src_path, input_dir)`, which *should* preserve the tree... but the crash-prone part is that `os.path.dirname(dst_path)` returns `""` when `rel_path` has no directory component, and `os.makedirs("")` raises `FileNotFoundError`. More subtly, if `input_dir` has a trailing slash or is `.`/`..`, `relpath` can produce surprising results, and mixing `os.walk`'s `root` with manual joining is fragile. The robust fix is to compute the relative path from the walk root itself and always normalize it.

**2. Crashing on empty files.** An empty file normalizes to `""`, and if you (or downstream code) try to `os.makedirs` on an empty dirname, or if any code assumes non-empty content, it breaks. The real crash in the original is `os.makedirs(os.path.dirname(dst_path), exist_ok=True)` when `dst_path` is a bare filename — `dirname` is `""`. The fix is to guard the `makedirs` call.

## Fixed implementation

```python
import os
import unicodedata
import re


def normalize_corpus(input_dir, output_dir, lowercase=False):
    """
    Normalize every .txt file under input_dir and mirror the folder structure
    into output_dir. Empty files are handled correctly (written as empty).

    Normalization:
      1. Unicode NFC normalization.
      2. Whitespace collapse: any run of whitespace -> single space; strip ends.
      3. Optional lowercasing.

    Args:
        input_dir (str): Root directory containing .txt files.
        output_dir (str): Root directory to write normalized .txt files.
        lowercase (bool): If True, lowercase the text.

    Returns:
        dict: Summary with counts of files processed, skipped, and errors.
    """
    if not os.path.isdir(input_dir):
        raise NotADirectoryError(f"Input directory does not exist: {input_dir}")

    # Normalize roots so relpath behaves predictably (no trailing slash, etc.).
    input_dir = os.path.abspath(input_dir)
    output_dir = os.path.abspath(output_dir)

    # Refuse to write into the source tree, which would cause feedback loops.
    if output_dir == input_dir or output_dir.startswith(input_dir + os.sep):
        raise ValueError(
            f"output_dir must not be inside input_dir: {output_dir}"
        )

    os.makedirs(output_dir, exist_ok=True)

    whitespace_re = re.compile(r"\s+", flags=re.UNICODE)

    stats = {"processed": 0, "skipped": 0, "errors": 0, "empty": 0}
    errors = []

    for root, _dirs, files in os.walk(input_dir):
        for filename in files:
            if not filename.lower().endswith(".txt"):
                stats["skipped"] += 1
                continue

            src_path = os.path.join(root, filename)

            # Mirror the tree: relative path is computed from the *walk root's*
            # parent relationship to input_dir, preserving subdirectories.
            rel_path = os.path.relpath(src_path, input_dir)
            dst_path = os.path.join(output_dir, rel_path)

            # Guard: dirname may be "" for top-level files. Never makedirs("").
            dst_dir = os.path.dirname(dst_path)
            if dst_dir:
                os.makedirs(dst_dir, exist_ok=True)

            try:
                with open(src_path, "r", encoding="utf-8", errors="strict") as f:
                    text = f.read()

                # Empty file -> normalized text stays empty; write it as-is.
                if text:
                    text = unicodedata.normalize("NFC", text)
                    text = whitespace_re.sub(" ", text).strip()
                    if lowercase:
                        text = text.lower()
                    if not text:
                        # File was pure whitespace; it collapses to empty.
                        stats["empty"] += 1
                else:
                    stats["empty"] += 1

                with open(dst_path, "w", encoding="utf-8") as f:
                    f.write(text)

                stats["processed"] += 1

            except UnicodeDecodeError as e:
                stats["errors"] += 1
                errors.append((src_path, f"decode error: {e}"))
            except Exception as e:
                stats["errors"] += 1
                errors.append((src_path, f"{type(e).__name__}: {e}"))

    stats["error_details"] = errors
    return stats


if __name__ == "__main__":
    import argparse

    parser = argparse.ArgumentParser(description="Normalize a .txt corpus.")
    parser.add_argument("input_dir", help="Source directory")
    parser.add_argument("output_dir", help="Destination directory")
    parser.add_argument(
        "--lowercase", action="store_true", help="Lowercase the normalized text"
    )
    args = parser.parse_args()

    result = normalize_corpus(args.input_dir, args.output_dir, args.lowercase)
    print(
        f"Processed: {result['processed']}  "
        f"Empty: {result['empty']}  "
        f"Skipped: {result['skipped']}  "
        f"Errors: {result['errors']}"
    )
    for path, msg in result["error_details"]:
        print(f"  ! {path}: {msg}")
```

## What changed and why

| Problem | Fix |
|---|---|
| `os.makedirs(os.path.dirname(dst_path))` crashes when `dirname` is `""` (top-level files) | Guard with `if dst_dir:` before calling `makedirs` |
| Flattening / path weirdness from trailing slashes or relative roots | `os.path.abspath` both roots up front, then `relpath` from the absolute `input_dir` |
| Empty files treated as errors or triggering whitespace ops | Skip normalization for empty `text`; count them under `empty` and still write the (empty) output file |
| Whitespace-only files silently vanish into `""` | Explicitly counted as `empty` so you can audit them |
| Output could be nested inside input, causing `os.walk` to re-read its own output on re-runs | Explicit guard raising `ValueError` |
