```python
import re
import csv

# Apache combined/common log line regex
# Matches: ip - - [timestamp] "METHOD URL PROTO" status size
LOG_RE = re.compile(
    r'^(?P<ip>\S+)\s+'          # client IP
    r'\S+\s+'                    # identd (usually '-')
    r'\S+\s+'                    # userid (usually '-')
    r'\[(?P<timestamp>[^\]]+)\]\s+'  # [timestamp]
    r'"(?P<method>\S+)\s+'       # "METHOD
    r'(?P<url>\S+)\s+'           # URL
    r'[^"]*"\s+'                 # PROTO"
    r'(?P<status>\d{3})\s+'      # status code
    r'(?P<size>\S+)'             # size (may be '-')
)


def convert_access_log(in_path, out_path, methods, status_classes):
    """
    Parse an Apache-style access log into a filtered CSV.

    Returns dict with 'written' and 'skipped' counts.
    """
    methods_set = set(methods)
    status_classes_set = set(status_classes)

    written = 0
    skipped = 0

    with open(in_path, 'r', encoding='utf-8', errors='replace') as fin, \
         open(out_path, 'w', newline='', encoding='utf-8') as fout:

        writer = csv.writer(fout)
        writer.writerow(
            ['ip', 'timestamp', 'method', 'url',
             'status', 'statusClass', 'size']
        )

        for line in fin:
            line = line.rstrip('\n')
            if not line:
                skipped += 1
                continue

            m = LOG_RE.match(line)
            if not m:
                skipped += 1
                continue

            ip = m.group('ip')
            timestamp = m.group('timestamp')
            method = m.group('method')
            url = m.group('url')
            status = m.group('status')
            size_raw = m.group('size')

            # Normalize size: '-' means 0, otherwise must be int
            if size_raw == '-':
                size = 0
            else:
                try:
                    size = int(size_raw)
                except ValueError:
                    skipped += 1
                    continue

            status_class = status[0] + 'xx'

            # Filters
            if methods_set and method not in methods_set:
                continue
            if status_classes_set and status_class not in status_classes_set:
                continue

            writer.writerow(
                [ip, timestamp, method, url, status, status_class, size]
            )
            written += 1

    return {'written': written, 'skipped': skipped}
```

Key points:

- **Regex**: Captures `ip`, `timestamp`, `method`, `url`, `status`, and `size` from a standard Apache line. The protocol field is matched but not captured. `\S+` for identd/userid keeps it tolerant of `-` or actual values.
- **statusClass**: Derived as `status[0] + 'xx'` (e.g. `'200'` → `'2xx'`).
- **Filtering**: Empty `methods` / `status_classes` iterables act as "allow all" for that dimension; non-empty ones are treated as whitelists.
- **Streaming**: Uses a `for line in fin` loop and a `csv.writer`, so memory usage is O(1) regardless of log size.
- **Malformed handling**: Non-matching lines and unparsable sizes increment `skipped`. Filtered-out (well-formed) lines are *not* counted as skipped — only true parse failures are.
- **Size `-`**: Normalized to `0`.
- **Standard library only**: `re`, `csv`.
- **Order preserved**: Rows are written in the order they're read; the header is always first.

If your logs omit the referrer/user-agent fields (common log format) and instead use `"METHOD URL PROTO" status size`, this regex still works because the trailing `[^"]*"` matches the (possibly empty) protocol section inside the quotes. For a strictly common-format line like `... "GET /x HTTP/1.0" 200 123`, the `\S+\s+[^"]*"` part will just have `\S+` match `HTTP/1.0` and `[^"]*` match the empty remainder before the closing quote.
