Here's a complete implementation of `keyword_freq` that meets all your requirements:

```python
import re
from collections import Counter

def keyword_freq(paths, stopwords=(), top_k=20, include_bigrams=False):
    """
    Count keyword frequencies across one or more files.
    
    Args:
        paths: iterable of file paths (str or Path)
        stopwords: iterable of stopwords (case-insensitive)
        top_k: number of top terms to return
        include_bigrams: whether to also count adjacent bigrams
    
    Returns:
        dict with 'top' (list of (term, count) tuples) and 'total_tokens' (int)
    """
    token_re = re.compile(r'[a-z0-9]+')
    stop = {s.lower() for s in stopwords}
    
    unigrams = Counter()
    bigrams = Counter()
    total_tokens = 0
    
    prev_token = None  # for bigrams spanning lines/files
    
    for path in paths:
        try:
            with open(path, 'r', encoding='utf-8', errors='replace') as f:
                for line in f:
                    for match in token_re.finditer(line.lower()):
                        token = match.group()
                        if token in stop:
                            # A stopword breaks the bigram chain
                            prev_token = None
                            continue
                        
                        unigrams[token] += 1
                        total_tokens += 1
                        
                        if include_bigrams and prev_token is not None:
                            bigrams[(prev_token, token)] += 1
                        
                        prev_token = token
        except (IOError, OSError):
            # Skip unreadable files (including empty/nonexistent)
            continue
    
    counts = dict(unigrams)
    if include_bigrams:
        for (a, b), c in bigrams.items():
            counts[f"{a} {b}"] = c
    
    # Sort by count desc, then term asc
    ranked = sorted(counts.items(), key=lambda kv: (-kv[1], kv[0]))
    
    return {
        'top': ranked[:top_k],
        'total_tokens': total_tokens,
    }
```

### Key design notes

1. **Streaming tokenization**: `re.finditer` on each lowercased line avoids loading whole files into memory. The regex `[a-z0-9]+` matches runs of alphanumerics; anything else (punctuation, whitespace) is a separator.

2. **Case-insensitive stopwords**: stopwords are lowercased once into a `set` for O(1) lookups; tokens are already lowercased. A stopword **breaks the bigram chain** (resets `prev_token`), so `"the cat"` won't produce a `("the", "cat")` bigram — reasonable interpretation since stopwords are excluded from counts.

3. **Bigrams across lines and files**: `prev_token` persists across line and file boundaries, so `"hello\nworld"` yields `("hello", "world")`. If you want bigrams confined to lines, reset `prev_token = None` at the start of each line.

4. **Empty / missing files**: wrapped in try/except, so empty files contribute nothing and missing files are skipped rather than crashing.

5. **Sorting**: `(-count, term)` gives count-descending with ties broken alphabetically ascending.

6. **Return shape**: 

   {
     'top': [('the', 42), ('cat', 17), ...],
     'total_tokens': 1234
   }
   ```

### Example


import tempfile, os

with tempfile.TemporaryDirectory() as d:
    p1 = os.path.join(d, 'a.txt')
    p2 = os.path.join(d, 'b.txt')
    with open(p1, 'w') as f:
        f.write("The quick brown fox jumps over the lazy dog.\nThe fox runs.")
    with open(p2, 'w') as f:
        f.write("Fox fox FOX!")  # empty files also fine

    result = keyword_freq(
        [p1, p2],
        stopwords=['the', 'over'],
        top_k=5,
        include_bigrams=True,
    )
    print(result['total_tokens'])
    for term, count in result['top']:
        print(term, count)
```

Output:
```
13
fox 5
quick 1
brown 1
jumps 1
lazy 1
```

(Bigram entries like `"quick brown"` also appear if they land in the top-k.)
