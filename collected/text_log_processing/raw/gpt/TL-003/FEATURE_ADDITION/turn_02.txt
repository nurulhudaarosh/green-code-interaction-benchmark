```python
def dedup_lines(in_path, out_path, mode="exact"):
    if mode not in ("exact", "normalized"):
        raise ValueError("mode must be 'exact' or 'normalized'")

    seen = set()
    total = unique = 0

    with open(in_path, "r", encoding="utf-8") as infile, \
         open(out_path, "w", encoding="utf-8") as outfile:

        for line in infile:
            total += 1

            if mode == "exact":
                key = line
            else:
                key = " ".join(line.strip().lower().split())

            if key not in seen:
                seen.add(key)
                outfile.write(line)  # Keep original line unchanged
                unique += 1

    return {
        "total": total,
        "unique": unique,
        "removed": total - unique
    }
```

- `exact`: compares raw lines.
- `normalized`: strips leading/trailing whitespace, lowercases, and collapses internal whitespace.
- **Output remains unchanged**—the first original version of each unique line is written.
