```python
import sys
from collections import Counter

def remove_duplicates(lines, ignore_blank=True):
    # Normalize: strip leading/trailing whitespace (also removes stray \r)
    cleaned = [l.strip() for l in lines]
    if ignore_blank:
        cleaned = [l for l in cleaned if l]
    counts = Counter(cleaned)
    return [(line, counts[line]) for line in dict.fromkeys(cleaned)]

if __name__ == "__main__":
    if len(sys.argv) > 1:
        with open(sys.argv[1], encoding="utf-8", newline="") as f:
            text = f.read()
    else:
        text = sys.stdin.read()

    # splitlines handles \n, \r\n, \r and a missing final newline
    for line, count in remove_duplicates(text.splitlines()):
        print(f"{count}\t{line}")
```

What changed:
- `splitlines()` replaces `rstrip("\n")`, so `\r\n` files and a last line with no trailing newline are counted the same as every other line.
- `strip()` makes `"apple"`, `"apple "` and `"apple\r"` count as one entry.
- Blank lines are skipped by default; call `remove_duplicates(lines, ignore_blank=False)` to count them.

If you want to keep internal whitespace differences (e.g. `"a  b"` vs `"a b"`) as separate lines, this already does. To collapse them too, use `" ".join(l.split())` instead of `l.strip()`.
