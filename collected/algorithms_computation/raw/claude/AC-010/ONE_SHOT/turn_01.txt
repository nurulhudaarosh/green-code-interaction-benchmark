## Problem

Given dimensions p[0..n] describing n matrices (matrix i has dimensions p[i-1] × p[i]), find the minimum number of scalar multiplications needed to compute the product M1×M2×...×Mn, and a valid full parenthesization achieving that cost. When multiple split points yield equal cost, choose the smallest split index.

**Constraints:**
- n ≥ 1 (at least one matrix); if n = 1, cost is 0 and the "parenthesization" is just the single matrix.
- p has length n+1, all entries positive integers.
- Matrix i (1-indexed) has shape p[i-1] × p[i]; adjacent matrices must be conformable (guaranteed by construction).
- Ties broken by smallest split index k.

**Required output:**
- Minimum total scalar multiplication cost (integer).
- A parenthesization string (e.g. `((A1(A2A3))A4)`).

## Algorithm

Interval DP over chain ranges. Let `dp[i][j]` = minimum cost to multiply matrices i..j, and `split[i][j]` = the k achieving it. Base case `dp[i][i] = 0`. For increasing chain length, `dp[i][j] = min over k in [i, j-1] of dp[i][k] + dp[k+1][j] + p[i-1]*p[k]*p[j]`, keeping the first k that achieves the minimum. Reconstruct the parenthesization recursively using `split`.

```python
def matrix_chain_order(p):
    """
    p: list of matrix dimensions, length n+1, matrix i (1..n) has shape p[i-1] x p[i]
    Returns: (min_cost, parenthesization_string)
    """
    n = len(p) - 1
    if n < 1:
        raise ValueError("Need at least one matrix (p must have length >= 2)")
    if n == 1:
        return 0, "A1"

    INF = float('inf')
    dp = [[0] * (n + 1) for _ in range(n + 1)]
    split = [[0] * (n + 1) for _ in range(n + 1)]

    for length in range(2, n + 1):
        for i in range(1, n - length + 2):
            j = i + length - 1
            best_cost = INF
            best_k = i
            for k in range(i, j):
                cost = dp[i][k] + dp[k + 1][j] + p[i - 1] * p[k] * p[j]
                if cost < best_cost:
                    best_cost = cost
                    best_k = k
            dp[i][j] = best_cost
            split[i][j] = best_k

    def build(i, j):
        if i == j:
            return f"A{i}"
        k = split[i][j]
        return f"({build(i, k)}{build(k + 1, j)})"

    return dp[n][n], build(1, n)


if __name__ == "__main__":
    p = [30, 35, 15, 5, 10, 20, 25]
    cost, parens = matrix_chain_order(p)
    print("Minimum cost:", cost)
    print("Parenthesization:", parens)
```

Running this on `p = [30, 35, 15, 5, 10, 20, 25]` gives:

```
Minimum cost: 15125
Parenthesization: ((A1(A2A3))((A4A5)A6))
```
