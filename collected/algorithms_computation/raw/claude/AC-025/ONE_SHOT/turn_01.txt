## Problem

There are `n` stages. In each stage you must pick **exactly one** option. Option `j` of stage `i` has a budget cost `c`, a memory cost `w`, and a score `s`. The goal is to maximize the total score subject to two global limits: total budget ≤ `B` and total memory ≤ `M`. Among all optimal selections, return the lexicographically smallest choice vector (compared by option index, stage by stage).

**Key constraints**
- Exactly one option per stage, so none can be skipped.
- Two simultaneous capacity limits (budget and memory).
- Costs are non-negative integers. Scores may be any integers.
- A deterministic tie-break is required, and an instance may be infeasible.

**Required output**
- The maximum total score and the choice vector (0-based option index per stage).
- `INFEASIBLE` if no selection fits.

## Algorithm

Layered two-resource DP, computed **backward over stages**.

- `f[i][b][m]` is the best score obtainable from stages `i..n-1` with at most `b` budget and `m` memory, or `None` if impossible.
- Base case: `f[n][b][m] = 0`.
- Transition: `f[i][b][m] = max over options (c,w,s) with c≤b, w≤m of s + f[i+1][b-c][m-w]`.
- Reconstruction: start at `(B, M)`. At each stage `i`, scan options in increasing index and take the first one that achieves `f[i][b][m]`, then subtract its costs. Because `f` is the exact optimum for each suffix, picking the smallest index at each stage yields the lexicographically smallest optimal vector.

Complexity is `O(n·B·M·k)` time and `O(n·B·M)` memory, where `k` is the maximum number of options per stage.

## Code

Input format (stdin): the first line is `n B M`. Then, for each stage, a line with `k`, followed by `k` lines of `cost memory score`.

```python
import sys

def solve(B, M, stages):
    n = len(stages)
    layers = [None] * (n + 1)
    layers[n] = [[0] * (M + 1) for _ in range(B + 1)]

    # Backward DP over stages
    for i in range(n - 1, -1, -1):
        nxt = layers[i + 1]
        cur = [[None] * (M + 1) for _ in range(B + 1)]
        opts = stages[i]
        for b in range(B + 1):
            row = cur[b]
            for m in range(M + 1):
                best = None
                for c, w, s in opts:
                    if c <= b and w <= m:
                        v = nxt[b - c][m - w]
                        if v is not None:
                            v += s
                            if best is None or v > best:
                                best = v
                row[m] = best
        layers[i] = cur

    total = layers[0][B][M]
    if total is None:
        return None

    # Deterministic reconstruction: smallest option index achieving the optimum
    choice = []
    b, m = B, M
    for i in range(n):
        target = layers[i][b][m]
        nxt = layers[i + 1]
        for j, (c, w, s) in enumerate(stages[i]):
            if c <= b and w <= m:
                v = nxt[b - c][m - w]
                if v is not None and v + s == target:
                    choice.append(j)
                    b -= c
                    m -= w
                    break
    return total, choice


def main():
    data = sys.stdin.read().split()
    pos = 0
    n, B, M = int(data[0]), int(data[1]), int(data[2])
    pos = 3
    stages = []
    for _ in range(n):
        k = int(data[pos]); pos += 1
        opts = []
        for _ in range(k):
            c, w, s = int(data[pos]), int(data[pos + 1]), int(data[pos + 2])
            pos += 3
            opts.append((c, w, s))
        stages.append(opts)

    res = solve(B, M, stages)
    if res is None:
        print("INFEASIBLE")
    else:
        total, choice = res
        print(total)
        print(*choice)


if __name__ == "__main__":
    main()
```

**Example**

```
2 5 5
2
2 2 3
3 3 5
2
1 1 1
2 2 4
```

The output is `8` on the first line and `1 0` on the second. Stage 0 uses option 1 (cost 3,3, score 5) and stage 1 uses option 0 (cost 1,1, score 1), for a total of 6. Wait: the better pair is stage 0 option 1 (3,3) plus stage 1 option 1 (2,2), which fits exactly at (5,5) with score 9. So the program prints `9` and `1 1`. This shows why the exact-capacity check matters, and the DP finds it automatically.
