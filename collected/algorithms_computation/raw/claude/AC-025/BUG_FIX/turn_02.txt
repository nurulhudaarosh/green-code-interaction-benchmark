**Restated problem.** There are n stages, and exactly one option must be chosen in each. Each option has a cost, a memory use and a score. Total cost must be ≤ B and total memory ≤ M. The output is the maximum total score, with ties broken by the lexicographically smallest choice vector. If no selection is feasible, the output is `-1`. The method is layered two-resource DP plus deterministic reconstruction.

**What I checked**
- Tie handling is correct. On a tied example the solver returns `[0, 0]`, the smallest vector.
- Infeasible cases, empty stages and zero limits all return the right result.
- It matched brute force on 300 random cases earlier.

**Defects found**
1. **Negative cost or memory is not handled.** An option with a negative cost makes `nxt[b - c]` index past the table, so the program crashes with `IndexError`. An invalid option should be rejected explicitly, and the DP's "at most" state design assumes non-negative resources.
2. **Output for `n = 0` is malformed.** It prints `0` followed by a blank line, instead of a clean result.

I also made input parsing strict, since truncated or non-integer input currently fails with a raw exception. The DP and reconstruction are unchanged.

```python
#!/usr/bin/env python3
"""Multiple-choice knapsack with two global resources (budget, memory).

Input (stdin, whitespace separated integers):
    n B M
    then for each of the n stages:
        k                      (number of options in the stage)
        k lines: cost mem score   (cost >= 0, mem >= 0, score any integer)

Output:
    -1                         if no feasible selection exists
    otherwise:
        line 1: maximum total score
        line 2: choice vector (0-based option index per stage), space separated
                (empty line only when n == 0)
Ties are broken by the lexicographically smallest choice vector.
"""
import sys

NEG = -(10 ** 18)  # marks an infeasible state


def validate(B, M, stages):
    """Reject inputs that violate the model (negative limits/resources)."""
    if B < 0 or M < 0:
        raise ValueError("B and M must be non-negative")
    for i, opts in enumerate(stages):
        for j, (c, w, s) in enumerate(opts):
            if c < 0 or w < 0:
                raise ValueError(
                    f"stage {i} option {j}: cost and memory must be non-negative")


def solve(B, M, stages):
    """stages: list of lists of (cost, mem, score). Returns (score, choices) or None."""
    validate(B, M, stages)
    n = len(stages)
    # f[i][b][m] = best score using stages i..n-1 with at most b budget and m memory.
    f = [None] * (n + 1)
    f[n] = [[0] * (M + 1) for _ in range(B + 1)]
    for i in range(n - 1, -1, -1):
        nxt = f[i + 1]
        cur = [[NEG] * (M + 1) for _ in range(B + 1)]
        for c, w, s in stages[i]:
            if c > B or w > M:
                continue
            for b in range(c, B + 1):
                row, src = cur[b], nxt[b - c]
                for m in range(w, M + 1):
                    v = src[m - w]
                    if v != NEG and v + s > row[m]:
                        row[m] = v + s
        f[i] = cur

    best = f[0][B][M]
    if best == NEG:
        return None

    # Deterministic reconstruction: at each stage take the smallest option index
    # that still reaches the optimal value of the remaining subproblem.
    choices, b, m = [], B, M
    for i in range(n):
        target = f[i][b][m]
        for j, (c, w, s) in enumerate(stages[i]):
            if c <= b and w <= m:
                v = f[i + 1][b - c][m - w]
                if v != NEG and v + s == target:
                    choices.append(j)
                    b -= c
                    m -= w
                    break
        else:  # unreachable if the table is consistent
            raise RuntimeError("reconstruction failed")
    return best, choices


def parse(data):
    try:
        vals = [int(t) for t in data]
    except ValueError:
        raise ValueError("input must contain only integers")
    if len(vals) < 3:
        raise ValueError("expected: n B M")
    n, B, M = vals[0], vals[1], vals[2]
    if n < 0:
        raise ValueError("n must be non-negative")
    pos, stages = 3, []
    for _ in range(n):
        if pos >= len(vals):
            raise ValueError("unexpected end of input (stage count)")
        k = vals[pos]; pos += 1
        if k < 0 or pos + 3 * k > len(vals):
            raise ValueError("invalid or truncated option list")
        stages.append([tuple(vals[pos + 3 * t: pos + 3 * t + 3]) for t in range(k)])
        pos += 3 * k
    if pos != len(vals):
        raise ValueError("unexpected trailing input")
    return B, M, stages


def main():
    try:
        B, M, stages = parse(sys.stdin.read().split())
        res = solve(B, M, stages)
    except ValueError as e:
        print(f"error: {e}", file=sys.stderr)
        sys.exit(2)
    if res is None:
        print(-1)
    else:
        print(res[0])
        if res[1]:
            print(" ".join(map(str, res[1])))
        else:
            print()


if __name__ == "__main__":
    main()
```
