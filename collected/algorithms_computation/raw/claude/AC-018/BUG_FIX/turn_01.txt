**Problem:** Given two integer polynomials, each represented as a list of coefficients, compute their product exactly and return the coefficient list of the result.

**Assumptions and constraints:**
- Coefficients are integers and may be negative or zero.
- Index `i` holds the coefficient of x^i (lowest degree first). The same convention is used for the output.
- If A has length n and B has length m, the product has length n + m − 1.
- Exactness matters, so no floating-point arithmetic. Python's arbitrary-precision integers make this safe.
- If either input is empty, it represents the zero polynomial, so the result is `[0]`.
- The sizes are assumed small enough that O(n·m) work is practical.

**Required output:** A list of integers, the coefficients of A(x)·B(x), in the same lowest-degree-first order.

**Algorithm:** Direct convolution. Every pair of terms a_i·x^i and b_j·x^j contributes a_i·b_j to result index i + j:

  c[k] = Σ over i + j = k of a[i]·b[j]

Time is O(n·m) and memory is O(n + m). Zero coefficients are skipped as a cheap optimization. Trailing zeros in the result (for example, from inputs that themselves have trailing zeros) are left as they are, so the output length always equals n + m − 1 unless an input is empty. The one exception is that a product that is entirely zero is still returned at full length.

**Implementation:**

```python
from typing import List


def multiply_polynomials(a: List[int], b: List[int]) -> List[int]:
    """Return the coefficients of a(x) * b(x), lowest degree first."""
    if not a or not b:
        return [0]

    result = [0] * (len(a) + len(b) - 1)
    for i, ai in enumerate(a):
        if ai == 0:
            continue
        for j, bj in enumerate(b):
            if bj:
                result[i + j] += ai * bj
    return result


if __name__ == "__main__":
    tests = [
        # (1 + 2x) * (3 - x) = 3 + 5x - 2x^2
        ([1, 2], [3, -1], [3, 5, -2]),
        # (1 + x)^2 = 1 + 2x + x^2
        ([1, 1], [1, 1], [1, 2, 1]),
        # (x - 1)(x + 1) = -1 + x^2
        ([-1, 1], [1, 1], [-1, 0, 1]),
        # multiplication by zero polynomial
        ([0], [5, 7, 9], [0, 0, 0]),
        # constants
        ([-4], [6], [-24]),
        # empty input -> zero polynomial
        ([], [1, 2], [0]),
        # large coefficients stay exact
        ([10**30, -10**30], [10**30, 10**30], [10**60, 0, -10**60]),
    ]
    for a, b, expected in tests:
        got = multiply_polynomials(a, b)
        assert got == expected, (a, b, got, expected)
    print("All tests passed.")
```

**Notes:**
- The solution is deterministic and uses only built-in Python, with no imports beyond `typing`, no network, no randomness, and no interaction.
- If the inputs were much larger, Karatsuba or an exact integer-based FFT/NTT approach would be faster, but the direct method is simplest and always exact, which fits the stated constraints.
