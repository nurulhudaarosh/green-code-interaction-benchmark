## Problem

Given a list `nums` of positive integers and a target `T`, decide whether some subset of `nums` sums to exactly `T`. If so, return the subset's indices, choosing:

1. the fewest elements, then
2. the lexicographically smallest ascending index list among those.

**Constraints and output**
- Each element may be used at most once (0/1 selection), and elements are identified by index, so duplicate values are distinct items.
- All values are positive integers, and `T >= 0`.
- The output is an ascending list of indices, `[]` when `T == 0`, or `None` if no subset reaches `T`.
- Time is O(n·T) states and transitions, plus tuple copying; memory is O(T) states.

## Algorithm

1. Let `dp[s]` be the best `(count, indices)` pair for sum `s` using only items `i..n-1`. Start with `dp[0] = (0, ())`, and every other sum unreachable.
2. Process items from the last index down to the first. For item `i` with value `a`, sweep `s` from `T` down to `a`, which keeps the selection 0/1. If `dp[s-a]` is reachable, form the candidate `(count+1, (i,) + indices)`.
3. Because `i` is smaller than every index already stored, prepending it keeps the list ascending. It also makes the candidate lexicographically comparable to the existing `dp[s]`.
4. Keep the smaller candidate under Python's tuple comparison. The count is compared first, then the index tuple. Equal counts mean equal lengths, so this is exactly the required order.
5. Optimal substructure holds. For a fixed first index `i`, the best completion is the best `(count, indices)` for the remaining sum over items `> i`, so the DP is correct.
6. The answer is `dp[T]`.

## Implementation

```python
from typing import List, Optional, Sequence, Tuple


def min_cardinality_subset(nums: Sequence[int], target: int) -> Optional[List[int]]:
    """Return ascending indices of a subset of `nums` summing to `target`,
    with the fewest elements, ties broken by lexicographically smallest
    index list. Return None if impossible."""
    if target < 0:
        raise ValueError("target must be non-negative")
    for x in nums:
        if not isinstance(x, int) or isinstance(x, bool) or x <= 0:
            raise ValueError("all numbers must be positive integers")

    # dp[s] = (count, index_tuple) using items processed so far, or None.
    dp: List[Optional[Tuple[int, Tuple[int, ...]]]] = [None] * (target + 1)
    dp[0] = (0, ())

    # Process from the last index to the first so prepending keeps order.
    for i in range(len(nums) - 1, -1, -1):
        a = nums[i]
        if a > target:
            continue
        for s in range(target, a - 1, -1):  # descending => 0/1 usage
            prev = dp[s - a]
            if prev is None:
                continue
            cand = (prev[0] + 1, (i,) + prev[1])
            cur = dp[s]
            if cur is None or cand < cur:
                dp[s] = cand

    best = dp[target]
    return None if best is None else list(best[1])


if __name__ == "__main__":
    tests = [
        ([3, 34, 4, 12, 5, 2], 9, [2, 4]),          # 4 + 5
        ([5, 5, 5, 10], 10, [3]),                   # single element beats 5+5
        ([2, 3, 5, 5], 10, [2, 3]),                 # 5 + 5
        ([1, 2, 3, 4], 5, [0, 3]),                  # 1+4 beats 2+3 lexicographically
        ([7, 8], 0, []),                            # empty subset
        ([2, 4, 6], 5, None),                       # impossible
        ([], 3, None),
    ]
    for nums, t, expected in tests:
        got = min_cardinality_subset(nums, t)
        assert got == expected, (nums, t, got, expected)
        print(nums, t, "->", got)
```

The solution uses only the standard library. It is fully deterministic, with no randomness, network access, or user input.
