# Restated problem

**Traveling Salesperson Solver.** Given a complete symmetric distance matrix `dist` for n ≤ 14 cities, find the minimum-cost Hamiltonian cycle that starts and ends at city 0. Ties prefer the smaller predecessor. The solution uses Held-Karp subset DP, is deterministic, and uses only the standard library, with no network, APIs, randomness, or interaction.

**Existing required outputs (unchanged)**
1. `min_cost`: the cost of the optimal cycle.
2. `tour`: the city sequence starting and ending at 0.

Special cases: n = 0 gives `0, []`; n = 1 gives `0, [0, 0]`; n = 2 gives `dist[0][1] + dist[1][0], [0, 1, 0]`.

# New feature: `operation_summary`

It is **opt-in**. When it is not requested, the return value, the CLI output, and the algorithm's behavior are exactly as before.

`operation_summary` is a dict of deterministic counters:

| Field | Meaning |
|---|---|
| `base_initializations` | Base states `dp[{j}][j]` set (n−1) |
| `transition_evaluations` | Candidate predecessors compared in the DP |
| `transition_updates` | Strict improvements that changed a best value (this is where the smaller-predecessor tie rule acts) |
| `closing_evaluations` | Last-city candidates compared when closing the cycle |
| `closing_updates` | Strict improvements at the closing step |
| `reconstruction_steps` | Parent-pointer steps taken to rebuild the tour |
| `total_operations` | `base_initializations + transition_evaluations + closing_evaluations + reconstruction_steps` |

`transition_updates` and `closing_updates` describe decisions but are not added into the total, so nothing is double counted. For n ≤ 2 (the special cases) all counters are 0.

# Implementation

```python
import sys
import json


def solve_tsp(dist, include_summary=False):
    """Held-Karp TSP from and to city 0.

    Default (include_summary=False): returns (min_cost, tour), unchanged.
    include_summary=True: returns (min_cost, tour, operation_summary).
    Ties are resolved in favor of the smaller predecessor.
    """
    n = len(dist)
    ops = {
        "base_initializations": 0,
        "transition_evaluations": 0,
        "transition_updates": 0,
        "closing_evaluations": 0,
        "closing_updates": 0,
        "reconstruction_steps": 0,
        "total_operations": 0,
    }

    def finish(cost, tour):
        if include_summary:
            ops["total_operations"] = (
                ops["base_initializations"]
                + ops["transition_evaluations"]
                + ops["closing_evaluations"]
                + ops["reconstruction_steps"]
            )
            return cost, tour, ops
        return cost, tour

    if n == 0:
        return finish(0, [])
    if n == 1:
        return finish(0, [0, 0])
    if n == 2:
        return finish(dist[0][1] + dist[1][0], [0, 1, 0])

    m = n - 1                      # cities 1..n-1 map to bits 0..m-1
    full = (1 << m) - 1
    INF = float("inf")

    dp = [[INF] * m for _ in range(1 << m)]
    parent = [[-1] * m for _ in range(1 << m)]

    for j in range(m):
        dp[1 << j][j] = dist[0][j + 1]
        ops["base_initializations"] += 1

    for mask in range(1, 1 << m):
        row = dp[mask]
        for j in range(m):
            if not (mask >> j) & 1:
                continue
            prev_mask = mask ^ (1 << j)
            if prev_mask == 0:
                continue           # base case already set
            prev_row = dp[prev_mask]
            best = INF
            best_i = -1
            # ascending i + strict '<' => smaller predecessor wins ties
            for i in range(m):
                if not (prev_mask >> i) & 1:
                    continue
                ops["transition_evaluations"] += 1
                cand = prev_row[i] + dist[i + 1][j + 1]
                if cand < best:
                    best = cand
                    best_i = i
                    ops["transition_updates"] += 1
            row[j] = best
            parent[mask][j] = best_i

    # Close the cycle; ascending j + strict '<' => smaller last city wins ties
    best_cost = INF
    last = -1
    for j in range(m):
        ops["closing_evaluations"] += 1
        cand = dp[full][j] + dist[j + 1][0]
        if cand < best_cost:
            best_cost = cand
            last = j
            ops["closing_updates"] += 1

    # Reconstruct
    path = []
    mask = full
    cur = last
    while cur != -1:
        ops["reconstruction_steps"] += 1
        path.append(cur + 1)
        prev = parent[mask][cur]
        mask ^= (1 << cur)
        cur = prev
    path.reverse()

    return finish(best_cost, [0] + path + [0])


def main():
    args = sys.argv[1:]
    want_summary = "--summary" in args

    data = sys.stdin.read().strip()
    if not data:
        return
    try:
        dist = json.loads(data)          # JSON matrix, e.g. [[0,1],[1,0]]
    except json.JSONDecodeError:
        tokens = data.split()            # or: n followed by n*n numbers
        n = int(tokens[0])
        vals = [float(x) if "." in x else int(x) for x in tokens[1:1 + n * n]]
        dist = [vals[r * n:(r + 1) * n] for r in range(n)]

    if want_summary:
        cost, tour, summary = solve_tsp(dist, include_summary=True)
    else:
        cost, tour = solve_tsp(dist)

    print(cost)
    print(" ".join(map(str, tour)))
    if want_summary:
        print("operation_summary:", json.dumps(summary, sort_keys=True))


if __name__ == "__main__":
    main()
```

# Example

Input: `[[0,10,15,20],[10,0,35,25],[15,35,0,30],[20,25,30,0]]`

**Without the flag** (original behavior):
```
80
0 2 3 1 0
```

**With `--summary`:**
```
80
0 2 3 1 0
operation_summary: {"base_initializations": 3, "closing_evaluations": 3, "closing_updates": 1, "reconstruction_steps": 3, "total_operations": 21, "transition_evaluations": 12, "transition_updates": 11}
```

The counts follow from the algorithm. For n = 4 (m = 3) there are 3 base states, and 6 + 6 = 12 transition evaluations (three 2-city masks with two endings and one candidate each, then the full mask with three endings and two candidates each). The closing step makes 3 evaluations and reconstruction takes 3 steps, so the total is 3 + 12 + 3 + 3 = 21.

# Correction to my previous answer

My earlier example output was wrong. Both `0 1 3 2 0` and `0 2 3 1 0` cost 80. The closing step compares last city 1 against last city 2, and the tie goes to the smaller one, city 1, so the code actually returns `0 2 3 1 0`, as shown above. My earlier trailing explanation was also muddled on this point. The code itself was correct; only the example output was misreported.

**Notes**
- The counters depend only on n and on where strict improvements occur, so they are fully deterministic for a given input.
- For worst-case n = 14 the transition evaluations are m·(m−1)·2^(m−2) = 13·12·2048 = 319,488 and `total_operations` is about 319.5K. The counting overhead is a few integer increments per evaluation.
