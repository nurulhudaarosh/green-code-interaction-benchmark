# Problem

Maintain an integer array that supports two kinds of operations, given in a mixed sequence:

1. **Point update** — replace the value at a given index with a new value.
2. **Range sum query** — return the sum of elements in an inclusive index range `[l, r]`.

Each query must be answered at the time it occurs (reflecting all updates applied before it), and results must be returned **in the order the queries appear**.

## Key constraints

- Array size `n` and number of operations `q` can be large (up to ~10^5–10^6), so both operations should run in **O(log n)** time — a naive approach (O(n) per query or update) would be too slow at scale.
- Indices are validated to be within bounds `[0, n-1]`.
- Values are integers (can be negative), so the structure must support arbitrary integer updates, not just increments.
- Operations arrive as a stream/sequence and must be processed in order (updates before a query affect that query; updates after it don't).
- No randomness, network access, or external dependencies — pure deterministic computation using the standard library only.

## Required output

A list of integers, one per range-sum query, in the same order the queries were issued.

# Algorithm

A **Fenwick tree (Binary Indexed Tree)** supports prefix-sum queries and point updates in O(log n):

- Internally it stores partial sums indexed by the lowest set bit of the index, using 1-based indexing.
- **Point update** (`add index by delta`): starting at `index+1`, repeatedly add `delta` to `tree[i]` and advance `i += i & (-i)` until past the end.
- **Prefix sum** (`sum of [0, i]`): starting at `index+1`, repeatedly add `tree[i]` and move `i -= i & (-i)` until reaching 0.
- **Range sum** `[l, r]` = `prefix_sum(r) - prefix_sum(l-1)`.
- To do a **point replacement** (set value, not just add), track current values separately and apply a delta of `new_value - old_value` to the Fenwick tree.

Both operations cost O(log n), so `q` operations total O(q log n) time — efficient even for large inputs.

# Implementation

```python
class FenwickTree:
    """Binary Indexed Tree supporting point updates and prefix-sum queries in O(log n)."""

    __slots__ = ("n", "tree")

    def __init__(self, n: int):
        self.n = n
        self.tree = [0] * (n + 1)  # 1-indexed internally

    def add(self, index: int, delta: int) -> None:
        """Add `delta` to the element at 0-based `index`."""
        i = index + 1
        while i <= self.n:
            self.tree[i] += delta
            i += i & (-i)

    def prefix_sum(self, index: int) -> int:
        """Sum of elements in [0, index] (0-based, inclusive). Returns 0 if index < 0."""
        if index < 0:
            return 0
        i = index + 1
        total = 0
        while i > 0:
            total += self.tree[i]
            i -= i & (-i)
        return total

    def range_sum(self, left: int, right: int) -> int:
        """Sum of elements in [left, right] (0-based, inclusive)."""
        if left > right:
            return 0
        return self.prefix_sum(right) - self.prefix_sum(left - 1)


class ArrayWithRangeSum:
    """
    Maintains an integer array under point replacement and inclusive
    range-sum queries, backed by a Fenwick tree.
    """

    def __init__(self, initial: list):
        self.n = len(initial)
        self.values = list(initial)          # current array values
        self.tree = FenwickTree(self.n)
        for idx, val in enumerate(initial):
            if val != 0:
                self.tree.add(idx, val)

    def _check_index(self, index: int) -> None:
        if not (0 <= index < self.n):
            raise IndexError(f"index {index} out of bounds for array of size {self.n}")

    def update(self, index: int, new_value: int) -> None:
        """Point replacement: set array[index] = new_value."""
        self._check_index(index)
        delta = new_value - self.values[index]
        if delta != 0:
            self.tree.add(index, delta)
            self.values[index] = new_value

    def query(self, left: int, right: int) -> int:
        """Inclusive range-sum query over array[left..right]."""
        self._check_index(left)
        self._check_index(right)
        if left > right:
            raise ValueError(f"invalid range: left={left} > right={right}")
        return self.tree.range_sum(left, right)


def process_operations(initial: list, operations: list) -> list:
    """
    initial: starting array of integers.
    operations: list of tuples, each either
        ("update", index, new_value)
        ("query", left, right)
    Returns: list of results for each "query" operation, in order.
    """
    structure = ArrayWithRangeSum(initial)
    results = []
    for op in operations:
        kind = op[0]
        if kind == "update":
            _, index, new_value = op
            structure.update(index, new_value)
        elif kind == "query":
            _, left, right = op
            results.append(structure.query(left, right))
        else:
            raise ValueError(f"unknown operation type: {kind}")
    return results


if __name__ == "__main__":
    # Deterministic self-test / demonstration
    initial_array = [1, 3, 5, 7, 9, 11]

    ops = [
        ("query", 1, 3),      # sum of [3,5,7] = 15
        ("update", 1, 10),    # array becomes [1,10,5,7,9,11]
        ("query", 1, 3),      # sum of [10,5,7] = 22
        ("update", 4, 0),     # array becomes [1,10,5,7,0,11]
        ("query", 0, 5),      # sum of all = 1+10+5+7+0+11 = 34
        ("query", 2, 2),      # single element = 5
    ]

    output = process_operations(initial_array, ops)
    print(output)  # Expected: [15, 22, 34, 5]

    assert output == [15, 22, 34, 5], "Self-test failed"
    print("Self-test passed.")
```

**Notes on the implementation:**
- Fully deterministic: no randomness, no I/O beyond the demonstration `print`, no network/API calls.
- Uses only the Python standard library (in fact, no imports at all are needed).
- `update` is a true point *replacement*: it computes the delta between the old and new value and applies that delta to the Fenwick tree, keeping a shadow `values` array in sync for future delta computations.
- Bounds and range validity are checked explicitly, raising clear exceptions on misuse.
- The bundled `__main__` block is a small deterministic self-test showing expected output for a fixed sequence of operations.
