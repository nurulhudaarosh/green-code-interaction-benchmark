# Problem

**Understanding.** One server processes jobs one at a time and never interrupts a running job (non-preemptive). Each job is `(id, arrival, burst, priority)`. Whenever the server becomes free, it chooses among jobs that have already arrived and are still waiting.

**Selection rule** (in order):
1. Larger priority first.
2. Ties: earlier arrival time.
3. Ties: smaller job ID.

**Key constraints / assumptions**
- A started job runs to completion.
- If the server is idle and nothing is waiting, it jumps to the next arrival time.
- A job arriving exactly when the server frees up is eligible (`arrival <= t`).
- Job IDs are unique, times are non-negative, and burst may be 0.
- Deterministic: the key `(-priority, arrival, id)` is a total order, so results never depend on insertion order.
- Standard library only; no network, randomness, or interaction.

**Required output**
- For every job: completion time and waiting time (`start - arrival`).
- Average waiting time over all jobs (0.0 when there are no jobs).

# Algorithm

1. Sort jobs by `(arrival, id)`.
2. Keep a min-heap keyed by `(-priority, arrival, id)`, so the best job under the selection rule is always at the top.
3. Start the clock `t` at the earliest arrival. Loop until all jobs are done:
   - Push every job with `arrival <= t` onto the heap.
   - If the heap is empty, set `t` to the next arrival and continue.
   - Otherwise pop the best job: `start = t`, `completion = t + burst`, `waiting = start - arrival`, then `t = completion`.
4. Average waiting time = total waiting / number of jobs.

Complexity: O(n log n) time, O(n) space.

# Implementation

```python
import heapq
from typing import Dict, List, Tuple

Job = Tuple[int, float, float, int]  # (job_id, arrival, burst, priority)


def simulate_queue(jobs: List[Job]):
    """
    Non-preemptive single-server priority queue simulation.

    Selection: larger priority, then earlier arrival, then smaller job ID.

    Returns:
        results: dict job_id -> {"completion": ..., "waiting": ...}
        avg_waiting: float (0.0 if there are no jobs)
        order: list of job IDs in execution order
    """
    if not jobs:
        return {}, 0.0, []

    pending = sorted(jobs, key=lambda j: (j[1], j[0]))  # input not mutated
    n = len(pending)

    heap: List[Tuple[int, float, int, float]] = []
    results: Dict[int, Dict[str, float]] = {}
    order: List[int] = []

    t = pending[0][1]
    i = 0
    done = 0
    total_wait = 0

    while done < n:
        # Admit every job that has arrived by time t.
        while i < n and pending[i][1] <= t:
            jid, arr, burst, prio = pending[i]
            heapq.heappush(heap, (-prio, arr, jid, burst))
            i += 1

        if not heap:
            t = pending[i][1]  # idle: jump to next arrival
            continue

        _, arr, jid, burst = heapq.heappop(heap)
        start = t
        completion = start + burst
        waiting = start - arr

        results[jid] = {"completion": completion, "waiting": waiting}
        order.append(jid)
        total_wait += waiting
        t = completion
        done += 1

    return results, total_wait / n, order


if __name__ == "__main__":
    sample = [
        (1, 0, 5, 1),
        (2, 1, 3, 3),
        (3, 2, 2, 3),
        (4, 2, 4, 2),
        (5, 20, 1, 1),
    ]
    res, avg, order = simulate_queue(sample)
    print("Execution order:", order)
    for jid in sorted(res):
        r = res[jid]
        print(f"Job {jid}: completion={r['completion']}, waiting={r['waiting']}")
    print(f"Average waiting time: {avg:.4f}")
```

# Sample trace

- t=0: only job 1 has arrived; it runs 0 to 5 (waiting 0).
- t=5: jobs 2 (p3, arrival 1), 3 (p3, arrival 2) and 4 (p2) wait. Job 2 wins the arrival tie-break: runs 5 to 8 (waiting 4).
- t=8: job 3 runs 8 to 10 (waiting 6).
- t=10: job 4 runs 10 to 14 (waiting 8).
- t=14: heap empty, so jump to t=20; job 5 runs 20 to 21 (waiting 0).

Average waiting = (0 + 4 + 6 + 8 + 0) / 5 = **3.6**.
