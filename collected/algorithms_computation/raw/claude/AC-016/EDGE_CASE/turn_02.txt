# Problem restated

Simulate a **non-preemptive single-server queue**. Each job is `(id, arrival, burst, priority)`. When the server is free, it picks among jobs that have already arrived and are waiting, by this rule:

1. **Larger priority** first.
2. Ties: **earlier arrival**.
3. Ties: **smaller job ID**.

A started job runs to completion. If nothing is waiting, the server idles until the next arrival.

**Required output:** for every job, its completion time and waiting time (`start - arrival`), plus the average waiting time (0.0 for no jobs). The output format and tie-breaking are unchanged from the original solution.

**Constraints:** IDs are unique, times are non-negative, and burst may be 0. Only the standard library is used, with no randomness, network access, or interaction.

# Difficult cases handled

The complexity is O(n log n) (sort, plus n heap pushes and n pops). These structures stress it:

- **Heap at maximum size and maximum work.** Every job arrives at time 0, and priorities *ascend* with input order. Each push is strictly better than everything in the heap, so it sifts all the way to the root (worst-case push). Each pop then sifts down to a leaf (worst-case pop). The result is about n log n work with a known closed-form answer.
- **Long blocker.** One long job runs while n jobs pile up behind it, so the heap grows to n and drains in reverse arrival order.
- **Tie-break stress.** All keys are equal except the ID, with the input in descending ID order.
- **Boundary cases.** A job arriving *exactly* when the server frees up, idle gaps, zero-burst jobs, and priority beating arrival time.

The algorithm itself is unchanged. The only tweak is starting the clock at the earliest arrival instead of 0, which is equivalent for non-negative arrivals. The tests add an independent O(n²) brute-force reference for cross-checking.

# Implementation and tests

```python
import heapq
import unittest
from typing import Dict, List, Tuple

Job = Tuple[int, float, float, int]  # (job_id, arrival, burst, priority)


def simulate_queue(jobs: List[Job]):
    """
    Non-preemptive single-server priority queue simulation.

    Selection: larger priority, then earlier arrival, then smaller job ID.

    Returns:
        results: dict job_id -> {"completion": ..., "waiting": ...}
        avg_waiting: float (0.0 if there are no jobs)
        order: list of job IDs in execution order
    """
    if not jobs:
        return {}, 0.0, []

    pending = sorted(jobs, key=lambda j: (j[1], j[0]))  # input is not mutated
    n = len(pending)

    heap: List[Tuple[int, float, int, float]] = []
    results: Dict[int, Dict[str, float]] = {}
    order: List[int] = []

    t = pending[0][1]  # start at the earliest arrival
    i = 0
    done = 0
    total_wait = 0

    while done < n:
        # Admit every job that has arrived by time t (arrival == t counts).
        while i < n and pending[i][1] <= t:
            jid, arr, burst, prio = pending[i]
            heapq.heappush(heap, (-prio, arr, jid, burst))
            i += 1

        if not heap:
            t = pending[i][1]  # idle: jump to next arrival
            continue

        _, arr, jid, burst = heapq.heappop(heap)
        start = t
        completion = start + burst
        waiting = start - arr

        results[jid] = {"completion": completion, "waiting": waiting}
        order.append(jid)
        total_wait += waiting
        t = completion
        done += 1

    return results, total_wait / n, order


def brute_force(jobs: List[Job]):
    """O(n^2) reference implementing the same rules directly."""
    remaining = list(jobs)
    t = 0
    results, order, total = {}, [], 0
    while remaining:
        avail = [j for j in remaining if j[1] <= t]
        if not avail:
            t = min(j[1] for j in remaining)
            continue
        best = min(avail, key=lambda j: (-j[3], j[1], j[0]))
        remaining.remove(best)
        jid, arr, burst, _ = best
        results[jid] = {"completion": t + burst, "waiting": t - arr}
        order.append(jid)
        total += t - arr
        t += burst
    n = len(jobs)
    return results, (total / n if n else 0.0), order


class TestSimulator(unittest.TestCase):
    def test_empty(self):
        self.assertEqual(simulate_queue([]), ({}, 0.0, []))

    def test_original_sample(self):
        sample = [(1, 0, 5, 1), (2, 1, 3, 3), (3, 2, 2, 3),
                  (4, 2, 4, 2), (5, 20, 1, 1)]
        res, avg, order = simulate_queue(sample)
        self.assertEqual(order, [1, 2, 3, 4, 5])
        self.assertEqual(res[2], {"completion": 8, "waiting": 4})
        self.assertEqual(res[3], {"completion": 10, "waiting": 6})
        self.assertEqual(res[4], {"completion": 14, "waiting": 8})
        self.assertEqual(res[5], {"completion": 21, "waiting": 0})
        self.assertAlmostEqual(avg, 3.6)

    def test_arrival_exactly_at_completion(self):
        jobs = [(1, 0, 5, 1), (2, 5, 1, 9), (3, 1, 1, 5)]
        res, avg, order = simulate_queue(jobs)
        self.assertEqual(order, [1, 2, 3])  # job 2 arrives at t=5 and wins
        self.assertEqual(res[2], {"completion": 6, "waiting": 0})
        self.assertEqual(res[3], {"completion": 7, "waiting": 5})
        self.assertAlmostEqual(avg, 5 / 3)

    def test_idle_gap(self):
        res, avg, order = simulate_queue([(1, 10, 2, 1), (2, 0, 3, 1)])
        self.assertEqual(order, [2, 1])
        self.assertEqual(res[1], {"completion": 12, "waiting": 0})
        self.assertEqual(avg, 0.0)

    def test_zero_burst(self):
        res, avg, order = simulate_queue([(2, 0, 0, 1), (1, 0, 0, 1)])
        self.assertEqual(order, [1, 2])
        self.assertEqual(res[1], {"completion": 0, "waiting": 0})
        self.assertEqual(res[2], {"completion": 0, "waiting": 0})

    def test_priority_beats_arrival(self):
        jobs = [(1, 0, 10, 0), (2, 1, 1, 1), (3, 2, 1, 9)]
        _, _, order = simulate_queue(jobs)
        self.assertEqual(order, [1, 3, 2])

    def test_tie_arrival_then_id(self):
        jobs = [(1, 0, 10, 0), (5, 3, 1, 2), (4, 3, 1, 2), (6, 2, 1, 2)]
        res, _, order = simulate_queue(jobs)
        self.assertEqual(order, [1, 6, 4, 5])  # earlier arrival, then smaller ID
        self.assertEqual(res[4], {"completion": 12, "waiting": 8})

    def test_all_equal_except_id_descending_input(self):
        n = 1000
        jobs = [(i, 0, 1, 5) for i in range(n, 0, -1)]
        res, avg, order = simulate_queue(jobs)
        self.assertEqual(order, list(range(1, n + 1)))
        self.assertEqual(res[n], {"completion": n, "waiting": n - 1})
        self.assertAlmostEqual(avg, (n - 1) / 2)

    def test_worst_case_heap_all_at_zero(self):
        # Every push beats all prior entries (sift-up to root); pops sift to a leaf.
        n = 100_000
        jobs = [(i, 0, 1, i) for i in range(1, n + 1)]
        res, avg, order = simulate_queue(jobs)
        self.assertEqual(order, list(range(n, 0, -1)))
        for k in (1, 2, n // 2, n - 1, n):
            self.assertEqual(res[k], {"completion": n - k + 1, "waiting": n - k})
        self.assertAlmostEqual(avg, (n - 1) / 2)

    def test_worst_case_long_blocker(self):
        # Blocker runs past every arrival, so the heap grows to n, then drains.
        n = 100_000
        blocker = n + 5
        jobs = [(0, 0, blocker, 0)] + [(i, i, 1, i) for i in range(1, n + 1)]
        res, _, order = simulate_queue(jobs)
        self.assertEqual(order, [0] + list(range(n, 0, -1)))
        for i in (1, 7, n // 2, n):
            start = blocker + (n - i)
            self.assertEqual(res[i], {"completion": start + 1, "waiting": start - i})

    def test_matches_brute_force(self):
        # Deterministic LCG (no randomness module) to generate varied instances.
        state = 12345

        def rnd(m):
            nonlocal state
            state = (state * 1103515245 + 12345) % (2 ** 31)
            return state % m

        for _ in range(300):
            n = 1 + rnd(30)
            ids = list(range(1, n + 1))
            jobs = [(i, rnd(25), rnd(6), rnd(4)) for i in ids]
            self.assertEqual(simulate_queue(jobs), brute_force(jobs))

    def test_input_not_mutated(self):
        jobs = [(2, 5, 1, 1), (1, 0, 1, 1)]
        snapshot = list(jobs)
        simulate_queue(jobs)
        self.assertEqual(jobs, snapshot)


if __name__ == "__main__":
    unittest.main()
```

# Why these tests are meaningful

- **Worst-case heap test:** the expected results come from closed forms (job `k` waits `n - k`, average `(n - 1) / 2`), so 100,000 jobs are verified exactly with no reference implementation. The correct order is fully forced by priority.
- **Long-blocker test:** it checks the growth and drain of a full-size heap, with per-job formulas for start, completion and waiting.
- **Brute-force cross-check:** 300 deterministic instances with heavy ties (small priority, burst and arrival ranges) confirm the heap version matches a direct implementation of the three-level rule, including completion times, waits, average and execution order.
- **Boundary tests:** `arrival == t` admission, idle jumps and zero bursts pin down the edge behavior, and the original sample still gives an average of 3.6.
