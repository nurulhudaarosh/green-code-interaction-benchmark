## Problem

Given a set of indivisible items, each with a weight and a value, and a knapsack of fixed capacity, select a subset of items whose total weight does not exceed the capacity while maximizing total value. Return the **original indices** of the selected items. If multiple subsets achieve the same maximum value, return the one whose sorted list of indices is **lexicographically smallest**.

**Key constraints:**
- Each item may be used at most once (0/1 knapsack, not fractional or unbounded).
- Weights, values, and capacity are non-negative.
- Total weight of selected items ≤ capacity.
- Among all subsets achieving maximum value, output must be the lexicographically smallest index list (compared element-wise as sorted ascending sequences).

**Required output:** The maximum total value and the list of selected original indices (sorted ascending), deterministically.

**Algorithm:** Standard 0/1 knapsack DP over `dp[c]` = max value achievable with capacity `c`, iterating items in order and updating capacities **in descending order** (to avoid reusing an item within the same pass). To guarantee the lexicographically smallest index set among optimal solutions, process items from **last index to first** during reconstruction (or equivalently, break ties during DP by preferring to *not* include the higher index when values tie) — the cleanest approach is to run DP normally, then reconstruct by greedily deciding, for each item from the **first** index onward, whether excluding it still permits reaching the optimal value with the remaining items/capacity; if yes, exclude it (since excluding a smaller index first yields lexicographically smaller sets), else include it.

```python
from typing import List, Tuple


def knapsack01(weights: List[int], values: List[int], capacity: int) -> Tuple[int, List[int]]:
    """
    Solve 0/1 knapsack deterministically.

    Args:
        weights: list of item weights (non-negative integers)
        values: list of item values (non-negative integers)
        capacity: knapsack capacity (non-negative integer)

    Returns:
        (max_value, selected_indices) where selected_indices is sorted
        ascending and is the lexicographically smallest such list among
        all subsets achieving max_value.
    """
    n = len(weights)
    if n != len(values):
        raise ValueError("weights and values must have the same length")
    if capacity < 0:
        raise ValueError("capacity must be non-negative")

    # dp[c] = best value achievable with capacity exactly <= c
    dp = [0] * (capacity + 1)

    # keep[i][c] = True if item i was taken when this dp row was computed
    # (we store per-item full rows to allow exact reconstruction)
    keep = [[False] * (capacity + 1) for _ in range(n)]

    for i in range(n):
        w, v = weights[i], values[i]
        # iterate capacity descending so each item is used at most once
        for c in range(capacity, -1, -1):
            if w <= c and dp[c - w] + v > dp[c]:
                dp[c] = dp[c - w] + v
                keep[i][c] = True
            # else dp[c] unchanged, keep[i][c] stays False (item i not
            # taken to reach this specific dp[c] in this pass)

    max_value = dp[capacity]

    # Reconstruct forward (index 0 upward) to get the lexicographically
    # smallest index list: at each item, prefer excluding it if the
    # optimal value is still achievable without it using a fresh
    # feasibility check via a second DP pass (suffix dp), which is the
    # standard deterministic technique.

    # Build suffix DP: suffix_dp[i][c] = max value using items i..n-1
    # with capacity c.
    suffix_dp = [[0] * (capacity + 1) for _ in range(n + 1)]
    for i in range(n - 1, -1, -1):
        w, v = weights[i], values[i]
        for c in range(capacity + 1):
            best = suffix_dp[i + 1][c]
            if w <= c:
                cand = suffix_dp[i + 1][c - w] + v
                if cand > best:
                    best = cand
            suffix_dp[i][c] = best

    selected = []
    remaining_capacity = capacity
    remaining_value = suffix_dp[0][capacity]

    for i in range(n):
        w, v = weights[i], values[i]
        # Value achievable if we skip item i
        skip_value = suffix_dp[i + 1][remaining_capacity]
        if skip_value == remaining_value:
            # Skipping keeps optimum reachable -> skip for lexicographically
            # smallest index set
            continue
        else:
            # Must take item i to preserve optimal value
            selected.append(i)
            remaining_capacity -= w
            remaining_value -= v

    return max_value, selected


def _self_test() -> None:
    # Basic correctness
    w = [2, 3, 4, 5]
    v = [3, 4, 5, 6]
    cap = 5
    val, idxs = knapsack01(w, v, cap)
    assert val == 7, val
    assert idxs == [0, 1], idxs

    # Tie-breaking: two single items with equal value/weight ratio giving
    # same total value: prefer smaller index set lexicographically.
    w2 = [1, 1]
    v2 = [5, 5]
    cap2 = 1
    val2, idxs2 = knapsack01(w2, v2, cap2)
    assert val2 == 5, val2
    assert idxs2 == [0], idxs2

    # Empty capacity
    val3, idxs3 = knapsack01([1, 2], [10, 20], 0)
    assert val3 == 0 and idxs3 == [], (val3, idxs3)

    # Empty items
    val4, idxs4 = knapsack01([], [], 10)
    assert val4 == 0 and idxs4 == [], (val4, idxs4)

    # Zero-weight item always includable if it improves/ties value at
    # zero cost -> should be selected (smaller index list preference
    # only matters among equal-value sets; here it strictly helps).
    val5, idxs5 = knapsack01([0, 1], [3, 3], 1)
    assert val5 == 6, val5
    assert idxs5 == [0, 1], idxs5

    print("All self-tests passed.")


if __name__ == "__main__":
    _self_test()

    # Example usage
    weights = [2, 3, 4, 5]
    values = [3, 4, 5, 6]
    capacity = 5
    best_value, chosen_indices = knapsack01(weights, values, capacity)
    print(f"Max value: {best_value}")
    print(f"Selected original indices: {chosen_indices}")
```

**Notes on determinism and correctness:**
- No randomness, I/O, network access, or external dependencies are used — only the Python standard library (in fact, none is even needed beyond built-ins).
- The forward DP computes `dp[capacity]` as the true optimum.
- The suffix DP (`suffix_dp[i][c]`) computes the optimal value achievable using only items `i..n-1` with capacity `c`, enabling an exact feasibility check at each reconstruction step.
- Reconstruction proceeds from index `0` upward, skipping an item whenever doing so still permits reaching the overall optimal value with the remaining items and capacity — this greedy-skip rule is what guarantees the lexicographically smallest index list among all optimal subsets.
- Time complexity: O(n·capacity); space: O(n·capacity) for the suffix table (can be reduced if only the value, not reconstruction, is needed).
