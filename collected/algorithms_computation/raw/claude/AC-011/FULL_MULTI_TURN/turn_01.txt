## Problem

This is the classic **0/1 Knapsack** problem: given `n` indivisible items, each with a weight and a value, and a knapsack of fixed capacity `W`, choose a subset of items to maximize total value without exceeding total weight `W`. Each item can be taken at most once (0/1, not fractional). We must return the *original indices* of the selected items, and if multiple subsets achieve the same maximum value, return the **lexicographically smallest index list**.

**Key constraints:**
- Weights, values, and capacity are non-negative (typically integers, since DP indexes by weight).
- Each item used 0 or 1 times.
- Total weight of selected items ≤ capacity.
- Output must be deterministic: among all optimal-value subsets, pick the one whose sorted index list is lexicographically smallest.

**Required output:** the maximum achievable value, and the list of original 0-based (or 1-based, as specified) indices of chosen items, sorted ascending.

## Algorithm

Standard 0/1 knapsack DP: `dp[c]` = max value achievable with capacity `c`. Iterate items one at a time, updating `dp` for `c` from `W` down to `weight[i]` (descending order prevents reusing the same item twice, since each row only reads values from the previous item's state). Store a full 2D table (or item-by-item snapshots) to reconstruct which items were picked via backtracking, choosing "skip item" whenever skipping still achieves the optimal value (this naturally biases toward the lexicographically smallest index set when reconstructed correctly).

To guarantee lexicographic minimality, we process items in index order, keep the full DP table `dp[i][c]`, and during backtracking prefer *not* taking the current item whenever the value is unaffected — but since lexicographic tie-breaking on the *set* of indices (not order of choice) is subtle, we resolve it by, among equal-value reconstructions, always preferring to exclude the current (higher) index first when reconstructing from last item to first, then re-verifying by a forward pass for correctness.

```python
def knapsack01(items, capacity):
    """
    items: list of (weight, value) tuples, original index = position in list
    capacity: non-negative integer capacity

    Returns: (max_value, sorted_list_of_selected_original_indices)
    Ties broken by lexicographically smallest index list.
    """
    n = len(items)
    W = capacity

    if n == 0 or W <= 0:
        return 0, []

    # dp[i][c] = max value using first i items with capacity c
    dp = [[0] * (W + 1) for _ in range(n + 1)]

    for i in range(1, n + 1):
        w_i, v_i = items[i - 1]
        for c in range(W + 1):
            best = dp[i - 1][c]  # don't take item i-1
            if w_i <= c:
                cand = dp[i - 1][c - w_i] + v_i
                if cand > best:
                    best = cand
            dp[i][c] = best

    max_value = dp[n][W]

    # Reconstruct: to get lexicographically smallest index list among
    # optimal solutions, decide items in increasing index order (0..n-1),
    # greedily EXCLUDING an item if there exists an optimal completion
    # without it (since excluding a smaller index first, when both choices
    # lead to an optimal total, yields the lexicographically smaller set).
    selected = []
    c = W
    # feasible[i][c] = best achievable value using items i..n-1 with capacity c
    feasible = [[0] * (W + 1) for _ in range(n + 1)]
    for i in range(n - 1, -1, -1):
        w_i, v_i = items[i]
        for cc in range(W + 1):
            best = feasible[i + 1][cc]
            if w_i <= cc:
                cand = feasible[i + 1][cc - w_i] + v_i
                if cand > best:
                    best = cand
            feasible[i][cc] = best

    remaining_value = max_value
    c = W
    for i in range(n):
        w_i, v_i = items[i]
        # Try excluding item i: can we still reach remaining_value using items i+1..n-1?
        if feasible[i + 1][c] == remaining_value:
            continue  # exclude item i (prefer smaller index list -> skip if possible)
        else:
            # must include item i
            selected.append(i)
            c -= w_i
            remaining_value -= v_i

    return max_value, sorted(selected)


if __name__ == "__main__":
    # Deterministic demo
    items = [(2, 3), (3, 4), (4, 5), (5, 8)]
    capacity = 5
    value, indices = knapsack01(items, capacity)
    print("Max value:", value)
    print("Selected indices:", indices)
```

**Notes on determinism and correctness:**
- No randomness, network, or external I/O is used — pure standard-library Python (`list` operations only).
- The `feasible` table (suffix DP) lets us test, for each item in increasing index order, whether skipping it still permits reaching the overall optimal value using only later items. If yes, we skip it (favoring the smaller index staying *out*, which yields the lexicographically smallest selected set); if no, it must be included.
- Time complexity: O(n·W) for both DP passes; space: O(n·W).
- For large `W`, this can be optimized to O(W) space for computing `max_value` alone, but reconstruction with lexicographic tie-breaking requires either the full table or a two-pass suffix/prefix approach as shown.
