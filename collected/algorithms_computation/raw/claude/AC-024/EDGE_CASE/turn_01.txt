# Interval Room Assignment

## Problem

Given a list of intervals `[start, end)`, assign each one a room ID so that no two overlapping intervals share a room. A room can be reused when its previous interval ends **at or before** the next interval's start (so `[1,3)` and `[3,5)` can share a room). The number of rooms must be minimized, and the output is the room ID for each interval in its **original input order**.

## Key constraints and required output

- Intervals are half-open: touching endpoints (`end == next start`) do not conflict.
- The room count must be the minimum possible, which equals the maximum number of simultaneously overlapping intervals.
- Output: a list `rooms` where `rooms[i]` is the room ID of `intervals[i]`, with IDs `0..k-1`.
- Determinism: ties must be broken by fixed rules (no randomness), so the same input always yields the same output.
- Empty input returns an empty list.
- Zero-length intervals (`start == end`) occupy no time, so they never conflict with anything. The algorithm handles them naturally: the room is freed immediately for any start `>= end`.

## Algorithm

1. Create indices sorted by `(start, end, original_index)` for a fully deterministic order.
2. Keep a min-heap of `(end_time, room_id)` for rooms currently in use.
3. For each interval in sorted order:
   - If the heap's top room has `end_time <= start`, reuse it (pop it). Because the heap is keyed by `(end_time, room_id)`, ties on end time pick the smallest room ID.
   - Otherwise open a new room with the next unused ID.
   - Push `(interval_end, room_id)` back onto the heap and record the assignment at the original index.
4. Return the assignments.

Reusing the room that frees up earliest is optimal: if that room is not free, no room is, so a new one is genuinely required. The room count therefore equals the peak overlap.

**Complexity:** O(n log n) time, O(n) space.

## Implementation

```python
import heapq
from typing import List, Sequence, Tuple


def assign_rooms(intervals: Sequence[Tuple[int, int]]) -> List[int]:
    """Return room IDs (0-based) for each interval in original order.

    Intervals are half-open [start, end): an interval may reuse a room
    whose previous interval ended at or before its start.
    Uses the minimum possible number of rooms.
    """
    n = len(intervals)
    for s, e in intervals:
        if e < s:
            raise ValueError(f"Invalid interval ({s}, {e}): end < start")

    # Deterministic processing order: start, then end, then original index.
    order = sorted(range(n), key=lambda i: (intervals[i][0], intervals[i][1], i))

    result = [0] * n
    heap: List[Tuple[int, int]] = []  # (end_time, room_id)
    next_room = 0

    for i in order:
        start, end = intervals[i]
        if heap and heap[0][0] <= start:
            _, room = heapq.heappop(heap)  # reuse earliest-free room
        else:
            room = next_room               # open a new room
            next_room += 1
        result[i] = room
        heapq.heappush(heap, (end, room))

    return result


def _validate(intervals, rooms) -> None:
    """Check no overlaps within a room (used by the self-test)."""
    by_room = {}
    for (s, e), r in zip(intervals, rooms):
        by_room.setdefault(r, []).append((s, e))
    for lst in by_room.values():
        lst.sort()
        for (s1, e1), (s2, e2) in zip(lst, lst[1:]):
            assert e1 <= s2, f"Overlap: {(s1, e1)} and {(s2, e2)}"


if __name__ == "__main__":
    tests = [
        [],
        [(1, 3)],
        [(0, 30), (5, 10), (15, 20)],
        [(1, 3), (3, 5), (5, 7)],           # touching: one room
        [(1, 4), (2, 5), (3, 6), (4, 7)],   # peak overlap 3
        [(2, 2), (2, 2), (1, 3)],           # zero-length intervals
        [(7, 10), (2, 4), (2, 4), (4, 7)],  # unsorted input
    ]
    for t in tests:
        r = assign_rooms(t)
        _validate(t, r)
        # Minimality: rooms used equals peak overlap.
        events = sorted([(s, 1) for s, e in t if s < e] +
                        [(e, -1) for s, e in t if s < e])
        cur = peak = 0
        for _, d in events:
            cur += d
            peak = max(peak, cur)
        used = len(set(r))
        assert used >= peak and (used == peak or any(s == e for s, e in t))
        print(t, "->", r)
```

## Example

For `[(0, 30), (5, 10), (15, 20)]`, the output is `[0, 1, 1]`: the first interval takes room 0, the second overlaps it and opens room 1, and the third starts after room 1 frees up at time 10, so it reuses room 1. Two rooms is the minimum.

For `[(7, 10), (2, 4), (2, 4), (4, 7)]`, the output is `[0, 0, 1, 0]`, showing that the touching intervals `(2,4)`, `(4,7)`, `(7,10)` chain in room 0 while the duplicate `(2,4)` gets room 1. IDs map back to original positions.
