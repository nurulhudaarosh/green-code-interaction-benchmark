## Problem understanding

Given an integer sequence `a`, find a **strictly increasing subsequence** with the **maximum possible length**.

If multiple subsequences have the same maximum length, return the one whose sequence of **original indices** is lexicographically smallest.

For example:

```text
a = [3, 1, 2, 2, 4]
```

The maximum length is `3`. Possible optimal index sequences include:

```text
[1, 2, 4]   -> [1, 2, 4]
[1, 3, 4]   -> [1, 2, 4]
```

Since the index sequences are compared lexicographically, `[1, 2, 4]` is selected.

### Key constraints / requirements

* Input is an integer sequence.
* A subsequence preserves the original order.
* It must be **strictly increasing**: for consecutive selected elements, `a[i] < a[j]`.
* Indices are **0-based** in the implementation below.
* Among all maximum-length solutions, choose the **lexicographically smallest original-index sequence**.
* The algorithm must use **quadratic dynamic programming**.
* Tie-breaking must be explicit and deterministic.
* Standard library only; no network, APIs, external services, randomness, or human interaction.
* Time complexity: **O(n²)**.
* Space complexity: **O(n²)** in this explicit index-sequence implementation.

## Algorithm

For every position `i`:

1. Consider every earlier position `j < i`.
2. If `a[j] < a[i]`, then a subsequence ending at `j` can be extended by `i`.
3. Construct the candidate index sequence `dp[j] + (i,)`.
4. Keep the candidate with:

   * greater length, or
   * equal length but lexicographically smaller index sequence.
5. Finally, choose the best sequence among all `dp[i]` using the same two rules.

Storing the complete index sequence in each DP state makes the required tie-breaking explicit rather than relying on incidental iteration order.

```python
from typing import Sequence, Tuple


def longest_increasing_subsequence(
    a: Sequence[int],
) -> Tuple[int, list[int]]:
    """
    Find a maximum-length strictly increasing subsequence.

    Tie-breaking:
        Among all maximum-length subsequences, return the one whose
        original-index sequence is lexicographically smallest.

    Indices are 0-based.

    Returns:
        (maximum_length, index_sequence)
    """
    n = len(a)

    if n == 0:
        return 0, []

    # dp[i] = lexicographically smallest index sequence among the
    # longest strictly increasing subsequences ending at i.
    dp: list[tuple[int, ...]] = [() for _ in range(n)]

    for i in range(n):
        # Every single element forms a valid subsequence.
        best = (i,)

        for j in range(i):
            if a[j] < a[i]:
                candidate = dp[j] + (i,)

                # Prefer longer subsequences. For equal lengths,
                # explicitly apply lexicographic tie-breaking.
                if (
                    len(candidate) > len(best)
                    or (
                        len(candidate) == len(best)
                        and candidate < best
                    )
                ):
                    best = candidate

        dp[i] = best

    # Select the globally optimal subsequence.
    answer = dp[0]

    for i in range(1, n):
        candidate = dp[i]

        if (
            len(candidate) > len(answer)
            or (
                len(candidate) == len(answer)
                and candidate < answer
            )
        ):
            answer = candidate

    return len(answer), list(answer)


if __name__ == "__main__":
    tests = [
        [],
        [5],
        [1, 2, 3, 4],
        [4, 3, 2, 1],
        [3, 1, 2, 2, 4],
        [2, 1, 3, 2, 4],
        [1, 1, 1],
    ]

    for sequence in tests:
        length, indices = longest_increasing_subsequence(sequence)
        values = [sequence[i] for i in indices]

        print(
            f"a={sequence} "
            f"-> length={length}, indices={indices}, values={values}"
        )
```
