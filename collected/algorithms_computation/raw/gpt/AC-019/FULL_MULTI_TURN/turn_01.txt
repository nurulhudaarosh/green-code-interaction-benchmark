### Problem understanding

Given a matrix of **non-negative costs**, start at the top-left cell `(0, 0)` and reach the bottom-right cell `(m-1, n-1)`. At each step, you may move only:

* **Right**: `(r, c) → (r, c+1)`
* **Down**: `(r, c) → (r+1, c)`

Return:

1. The **minimum total cost** of a valid path.
2. One **deterministic optimal path**.

### Key constraints

* The matrix contains non-negative numeric costs.
* The matrix must be non-empty and rectangular.
* Only right/down moves are allowed.
* The returned path must be optimal.
* Ties must be resolved deterministically. Here, when two predecessor costs are equal, **prefer the upper cell (move down)**.
* No randomness, network access, APIs, external services, or user interaction.
* Standard library only.

### Algorithm

Use **dynamic programming**:

* `dp[r][c]` stores the minimum cost to reach `(r, c)`.
* `parent[r][c]` stores the predecessor coordinate used to obtain that minimum.
* For each cell, compare its top and left predecessors.
* On a tie, consistently choose the **top predecessor**.
* Backtrack from the bottom-right cell using `parent` to reconstruct the path.

**Time:** `O(m × n)`
**Space:** `O(m × n)`

```python
from typing import List, Tuple


def minimum_cost_grid_path(
    cost: List[List[int]]
) -> Tuple[int, List[Tuple[int, int]]]:
    """
    Find the minimum-cost path from the top-left to the bottom-right
    of a non-negative cost matrix.

    Allowed moves:
        - Right: (r, c) -> (r, c + 1)
        - Down:  (r, c) -> (r + 1, c)

    Deterministic tie-breaking:
        If the top and left predecessors have equal minimum cost,
        prefer the top predecessor (i.e., move down).

    Returns:
        (minimum_cost, path)

        minimum_cost:
            Total cost of the selected optimal path.

        path:
            List of (row, column) coordinates from start to destination.
    """

    # ---------- Validate input ----------
    if not cost:
        raise ValueError("Cost matrix must not be empty.")

    if not cost[0]:
        raise ValueError("Cost matrix must not contain an empty row.")

    columns = len(cost[0])

    if any(len(row) != columns for row in cost):
        raise ValueError("Cost matrix must be rectangular.")

    if any(value < 0 for row in cost for value in row):
        raise ValueError("All costs must be non-negative.")

    rows = len(cost)

    # ---------- DP tables ----------
    dp = [[0] * columns for _ in range(rows)]

    # parent[r][c] = predecessor coordinate
    # None for the starting cell.
    parent = [[None] * columns for _ in range(rows)]

    # ---------- Base case ----------
    dp[0][0] = cost[0][0]

    # ---------- First column ----------
    for r in range(1, rows):
        dp[r][0] = dp[r - 1][0] + cost[r][0]
        parent[r][0] = (r - 1, 0)

    # ---------- First row ----------
    for c in range(1, columns):
        dp[0][c] = dp[0][c - 1] + cost[0][c]
        parent[0][c] = (0, c - 1)

    # ---------- Fill DP table ----------
    for r in range(1, rows):
        for c in range(1, columns):
            from_top = dp[r - 1][c]
            from_left = dp[r][c - 1]

            # Deterministic tie-breaking:
            # On equality, choose the top predecessor.
            if from_top <= from_left:
                dp[r][c] = from_top + cost[r][c]
                parent[r][c] = (r - 1, c)
            else:
                dp[r][c] = from_left + cost[r][c]
                parent[r][c] = (r, c - 1)

    # ---------- Reconstruct path ----------
    path = []
    r, c = rows - 1, columns - 1

    while True:
        path.append((r, c))

        if (r, c) == (0, 0):
            break

        r, c = parent[r][c]

    path.reverse()

    return dp[rows - 1][columns - 1], path


# ---------------------------------------------------------
# Example
# ---------------------------------------------------------

if __name__ == "__main__":
    cost = [
        [1, 3, 1],
        [1, 5, 1],
        [4, 2, 1]
    ]

    minimum_cost, path = minimum_cost_grid_path(cost)

    print("Minimum cost:", minimum_cost)
    print("Path:", path)
```

For the example, the deterministic result is:

```text
Minimum cost: 7
Path: [(0, 0), (1, 0), (2, 0), (2, 1), (2, 2)]
```
