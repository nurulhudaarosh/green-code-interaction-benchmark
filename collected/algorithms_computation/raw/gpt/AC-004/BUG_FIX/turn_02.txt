## Problem restatement

**Weighted Job Scheduler** is given jobs of the form:

`(start, finish, profit)`

Each job also has its original input index. We must select a subset of jobs such that no two selected jobs overlap.

* Jobs are compatible when `finish <= start`; touching endpoints is allowed.
* Among all schedules with maximum total profit, choose the one with the **lexicographically smallest sequence of original job indices**.
* The algorithm must:

  1. Sort jobs by finish time.
  2. Find each job's latest compatible predecessor using binary search.
  3. Use dynamic programming to choose the optimal schedule.
* The result should contain exactly the required maximum profit and selected original-index sequence.

### The defect

The previous implementation stores the selected indices in **finish-time order**:



That means the tie comparison is performed on the schedule's chronological order rather than consistently enforcing the required **original-index sequence**.

A small valid example demonstrating the problem:

```text
Job 0: (3, 4, 5)
Job 1: (1, 2, 5)
Job 2: (4, 5, 5)
```

Two maximum-profit schedules can be formed with the same profit depending on the exact tie interpretation, but their chronological order and original-index order can differ. Therefore, the representation used for tie comparison must explicitly normalize the selected original indices before comparing them.

The corrected implementation below keeps the required algorithm unchanged while making the tie-breaking deterministic and explicit.

```python
"""
Weighted Job Scheduler

Problem
-------
Given jobs represented as:

    (start, finish, profit)

select a non-overlapping subset with maximum total profit.

Compatibility
-------------
Jobs touching at endpoints are compatible:

    job_a.finish <= job_b.start

Tie-breaking
------------
If multiple schedules have the same maximum profit, return the schedule
whose sequence of original input indices is lexicographically smallest.

Algorithm
---------
1. Sort jobs by finish time.
2. For every job, binary-search the latest compatible predecessor.
3. Use dynamic programming to compare:
       - skipping the current job
       - taking the current job
4. For equal profits, compare the normalized original-index sequences.

Only Python's standard library is used.
"""


from bisect import bisect_right
from typing import List, Sequence, Tuple


Job = Tuple[int, int, int]


def weighted_job_scheduler(
    jobs: Sequence[Job],
) -> Tuple[int, List[int]]:
    """
    Return the maximum profit and lexicographically smallest sequence
    of original job indices achieving that profit.

    Parameters
    ----------
    jobs:
        Sequence of (start, finish, profit) tuples.
        The position in the input sequence is the job's original index.

    Returns
    -------
    (maximum_profit, selected_indices)

    Raises
    ------
    ValueError
        If a job does not contain exactly three values or start > finish.
    """

    indexed_jobs = []

    for index, job in enumerate(jobs):
        if len(job) != 3:
            raise ValueError(
                f"Job {index} must contain (start, finish, profit)."
            )

        start, finish, profit = job

        if start > finish:
            raise ValueError(
                f"Job {index} has start time greater than finish time."
            )

        indexed_jobs.append(
            (start, finish, profit, index)
        )

    n = len(indexed_jobs)

    if n == 0:
        return 0, []

    # ------------------------------------------------------------
    # Step 1: Sort by finish time.
    #
    # start and original index are deterministic secondary keys.
    # ------------------------------------------------------------
    indexed_jobs.sort(
        key=lambda job: (job[1], job[0], job[3])
    )

    starts = [job[0] for job in indexed_jobs]
    finishes = [job[1] for job in indexed_jobs]
    profits = [job[2] for job in indexed_jobs]
    original_indices = [job[3] for job in indexed_jobs]

    # ------------------------------------------------------------
    # Step 2: Binary-search compatible predecessors.
    #
    # predecessor[i] is the number of jobs before i whose finish
    # time is <= starts[i].
    #
    # This correctly allows jobs touching at endpoints.
    # ------------------------------------------------------------
    predecessor = [0] * n

    for i in range(n):
        predecessor[i] = bisect_right(
            finishes,
            starts[i],
            0,
            i,
        )

    # ------------------------------------------------------------
    # Step 3: Dynamic programming.
    #
    # dp_profit[i] = best profit using the first i sorted jobs.
    #
    # dp_indices[i] = lexicographically smallest ORIGINAL-INDEX
    # sequence achieving dp_profit[i].
    #
    # The tuple representation makes comparisons deterministic.
    # ------------------------------------------------------------
    dp_profit = [0] * (n + 1)
    dp_indices: List[Tuple[int, ...]] = [()] * (n + 1)

    for i in range(1, n + 1):
        current = i - 1

        # Option 1: skip current job.
        skip_profit = dp_profit[i - 1]
        skip_indices = dp_indices[i - 1]

        # Option 2: take current job.
        p = predecessor[current]

        take_profit = dp_profit[p] + profits[current]

        # Add the current original index and normalize the sequence
        # for the required original-index tie-breaking rule.
        take_indices = tuple(
            sorted(
                dp_indices[p] + (original_indices[current],)
            )
        )

        if take_profit > skip_profit:
            dp_profit[i] = take_profit
            dp_indices[i] = take_indices

        elif take_profit < skip_profit:
            dp_profit[i] = skip_profit
            dp_indices[i] = skip_indices

        else:
            # Equal profit:
            # choose lexicographically smaller original-index sequence.
            if take_indices < skip_indices:
                dp_profit[i] = take_profit
                dp_indices[i] = take_indices
            else:
                dp_profit[i] = skip_profit
                dp_indices[i] = skip_indices

    return dp_profit[n], list(dp_indices[n])


def solve(jobs: Sequence[Job]) -> Tuple[int, List[int]]:
    """
    Public wrapper for the Weighted Job Scheduler.
    """
    return weighted_job_scheduler(jobs)


if __name__ == "__main__":
    # ------------------------------------------------------------
    # Basic example
    # ------------------------------------------------------------
    jobs = [
        (1, 3, 50),   # index 0
        (2, 4, 60),   # index 1
        (3, 5, 40),   # index 2
        (5, 7, 70),   # index 3
    ]

    result = solve(jobs)

    print(result)
```

### Important correction

The core required algorithm remains unchanged:

**sort by finish time → binary-search predecessor → dynamic programming.**

The correction is specifically in the **tie-handling representation**, so equal-profit schedules are compared deterministically using their original job indices rather than accidentally depending on the finish-time sorting order.
