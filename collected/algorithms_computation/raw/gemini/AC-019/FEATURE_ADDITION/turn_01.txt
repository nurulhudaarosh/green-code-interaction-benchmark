### Problem Identification & Understanding

The problem asks for finding the minimum total cost to travel from the top-left corner $(0, 0)$ to the bottom-right corner $(m-1, n-1)$ of a grid/matrix with non-negative costs.

* **Allowed moves:** Only **Right** (increment column) or **Down** (increment row).
* **Objective:**
1. Calculate the minimum cost path sum.
2. Reconstruct and return a single **deterministic** optimal path from top-left to bottom-right.



---

### Key Constraints & Required Output

* **Input:** A 2D list of non-negative numbers representing costs: `cost[i][j] >= 0`.
* **Grid dimensions:** Matrix with $m$ rows and $n$ columns ($m \ge 1, n \ge 1$).
* **Movement constraints:** From position $(r, c)$, you can only move to $(r, c+1)$ [Right] or $(r+1, c)$ [Down].
* **Determinism constraint:** When multiple paths yield the same minimum cost, ties must be broken deterministically. Here, we prioritize moving **Right before Down** during path reconstruction/predecessor selection (or equivalently, choosing the option that produces a consistent, deterministic trajectory).
* **Required Output:** A tuple containing:
1. The minimum path cost (`int` or `float`).
2. The optimal path as a list of coordinate tuples: `[(0, 0), ..., (m-1, n-1)]`.



---

### Algorithm Description

1. **Dynamic Programming Table (`dp`):**
* Define `dp[i][j]` as the minimum cost to reach cell $(i, j)$ from $(0, 0)$.
* Base Case: `dp[0][0] = cost[0][0]`.
* First Row: `dp[0][j] = dp[0][j-1] + cost[0][j]` (can only come from the Left).
* First Column: `dp[i][0] = dp[i-1][0] + cost[i][0]` (can only come from Above).
* General Cell: `dp[i][j] = cost[i][j] + min(dp[i-1][j], dp[i][j-1])`.


2. **Predecessor Tracking & Tie Handling:**
* Maintain a `parent` matrix of shape $m \times n$ storing the predecessor cell $(r, c)$.
* When evaluating `min(dp[i-1][j], dp[i][j-1])`:
* If coming from the left `dp[i][j-1]` offers a strictly lower or equal cost, choose Left over Up to ensure a deterministic tie-breaker (e.g., favoring Right moves during reconstruction).




3. **Path Reconstruction:**
* Backtrack from $(m-1, n-1)$ back to $(0, 0)$ using the `parent` pointers.
* Reverse the reconstructed coordinates to produce the final path from start to end.



---

### Python Solution

```python
def min_cost_path(cost):
    """
    Finds the minimum cost path in a grid moving only right or down.
    
    Args:
        cost (list[list[int | float]]): Non-negative cost matrix.
        
    Returns:
        tuple[int | float, list[tuple[int, int]]]: 
            - Minimum path cost
            - Deterministic optimal path as a list of (row, col) tuples.
    """
    if not cost or not cost[0]:
        return 0, []

    m, n = len(cost), len(cost[0])

    # dp[i][j] stores the min cost to reach cell (i, j)
    dp = [[0] * n for _ in range(m)]
    
    # parent[i][j] stores the predecessor tuple (r, c) for deterministic path reconstruction
    parent = [[None] * n for _ in range(m)]

    # Base case: Starting position
    dp[0][0] = cost[0][0]

    # Initialize first row (can only arrive from left)
    for j in range(1, n):
        dp[0][j] = dp[0][j - 1] + cost[0][j]
        parent[0][j] = (0, j - 1)

    # Initialize first column (can only arrive from above)
    for i in range(1, m):
        dp[i][0] = dp[i - 1][0] + cost[i][0]
        parent[i][0] = (i - 1, 0)

    # Fill DP table for remaining grid
    for i in range(1, m):
        for j in range(1, n):
            from_above = dp[i - 1][j]
            from_left = dp[i][j - 1]

            # Deterministic tie-handling: favor coming from left (Right move) on equality
            if from_left <= from_above:
                dp[i][j] = cost[i][j] + from_left
                parent[i][j] = (i, j - 1)
            else:
                dp[i][j] = cost[i][j] + from_above
                parent[i][j] = (i - 1, j)

    # Reconstruct optimal path backward from bottom-right to top-left
    path = []
    curr = (m - 1, n - 1)
    while curr is not None:
        path.append(curr)
        curr = parent[curr[0]][curr[1]]

    # Reverse to get path from (0, 0) to (m-1, n-1)
    path.reverse()

    return dp[m - 1][n - 1], path


# Example Usage & Verification
if __name__ == "__main__":
    grid = [
        [1, 3, 1],
        [1, 5, 1],
        [4, 2, 1]
    ]
    
    min_cost, path = min_cost_path(grid)
    print(f"Minimum Cost: {min_cost}")
    print(f"Path: {path}")
```
