### Restatement of Problem & Expected Behavior

Given $N$ indivisible items—each with a weight $w_i \ge 0$ and value $v_i \ge 0$—and a knapsack capacity $W$, the **0/1 Capacity-Constrained Knapsack Problem** requires selecting a subset of items to maximize total value subject to total weight $\le W$.

#### Expected Behavior & Constraints

1. **Return Value:** A sorted list of the **0-based original indices** of the chosen items.
2. **Deterministic Tie-Handling:** If multiple subsets yield the *same maximum value*, the returned subset must be the **lexicographically smallest** index list.
* Example: `[0, 3]` is lexicographically smaller than `[1, 2]`.
* An empty selection `[]` (value $0$) is lexicographically smaller than any non-empty selection `[i]` (value $0$).



---

### Defect Analysis

The previous implementation suffered from **two bugs** in tie handling:

1. **Failure to consider zero-value items / empty sets in tie-breaking:**
In the inner update loop, `elif new_val == dp[c] and new_val > 0:` ignored ties when `new_val == 0`. Consequently, zero-value choices (including the empty selection `[]`) were not systematically evaluated for lexicographical minimization.
2. **Suboptimal state tracking during DP updates:**
Building and comparing full index arrays inside the inner loop is both inefficient and vulnerable to incorrect intermediate updates.

#### Counterexample Demonstrating the Bug

Consider 0-value items:

* `weights = [1, 1]`
* `values = [0, 0]`
* `capacity = 1`
* **Expected Output:** `[]` (Total value = 0, weight = 0, index list `[]` is lexicographically smaller than `[0]`).
* **Previous Implementation Output:** `[0]` (When processing item 0, `new_val` is `0`, which failed `new_val > 0`, so it did not handle the tie properly against `[]`).

Similarly, for value ties between multi-item subsets:

* `weights = [2, 1, 1]`
* `values = [1, 1, 1]`
* `capacity = 2`
* Candidate subsets yielding max value = 2:
* Items `{0}` (weight 2, value 1) + `{1}` (weight 1, value 1) $\rightarrow$ invalid total weight 3.
* Items `{1, 2}` $\rightarrow$ weight 2, value 2, indices `[1, 2]`.
* Items `{0}` $\rightarrow$ weight 2, value 1.



---

### Corrected Python Implementation

To guarantee strict lexicographical ordering deterministically:

* Track `dp[c]` as a tuple: `(-total_value, chosen_indices_list)`.
* Minimizing this tuple automatically maximizes `total_value` (due to negation) and picks the **lexicographically smallest** `chosen_indices_list` on ties.

```python
def knapsack_01(weights: list[int], values: list[int], capacity: int) -> list[int]:
    """
    Solves the 0/1 Knapsack problem using descending dynamic programming updates.
    Returns the lexicographically smallest list of original 0-based indices
    that achieves the maximum total value under the capacity constraint.
    """
    n = len(weights)
    
    # dp[c] stores (-max_value, sorted_list_of_indices)
    # Using negative value allows tuple comparison to naturally prioritize 
    # higher values first, then lexicographically smaller index lists.
    dp = [(-0, []) for _ in range(capacity + 1)]

    for i in range(n):
        w = weights[i]
        v = values[i]
        
        if w > capacity:
            continue
            
        # Descending capacity update to prevent picking the same item multiple times
        for c in range(capacity, w - 1, -1):
            prev_val, prev_indices = dp[c - w]
            candidate = (prev_val - v, prev_indices + [i])
            
            # Tuple comparison naturally handles:
            # 1. Higher value (-value is smaller)
            # 2. Lexicographically smaller index set on value ties
            if candidate < dp[c]:
                dp[c] = candidate

    # Find the globally optimal tuple across all valid capacities [0..capacity]
    best_neg_val, best_indices = min(dp)
    
    return best_indices


# --- Verification ---
if __name__ == "__main__":
    # Test 1: Zero-value tie-breaker test
    w1, v1, cap1 = [1, 1], [0, 0], 1
    res1 = knapsack_01(w1, v1, cap1)
    print(f"Test 1 Result: {res1} (Expected: [])")
    assert res1 == [], f"Failed Test 1: got {res1}"

    # Test 2: Standard tie-breaker test
    w2, v2, cap2 = [2, 2, 1, 1], [3, 3, 2, 1], 3
    # Candidate value 5: indices [0, 2] (weight 3) vs [1, 2] (weight 3)
    res2 = knapsack_01(w2, v2, cap2)
    print(f"Test 2 Result: {res2} (Expected: [0, 2])")
    assert res2 == [0, 2], f"Failed Test 2: got {res2}"

    print("All tests passed successfully!")
```
