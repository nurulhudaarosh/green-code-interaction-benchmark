### Problem Overview

The goal is to solve the classic **0/1 Knapsack Problem**. Given a set of $N$ indivisible items—each having a specific weight and value—and a maximum weight capacity $W$, we need to select a subset of items to maximize the total value without exceeding the total capacity $W$.

### Key Constraints & Required Output

* **Item Indivisibility:** Each item can either be taken completely (1) or left behind (0).
* **Capacity Limit:** The sum of weights of selected items must be less than or equal to $W$.
* **Tie-Breaking Rule:** If multiple subsets yield the same maximum value, return the subset whose list of 0-based original indices is **lexicographically smallest**.
* **Output:** A sorted list of the original 0-based indices of the selected items.

### Algorithm Description

We use **Dynamic Programming (DP)**.

1. Maintain a 1D DP array `dp` of size $W + 1$, where `dp[w]` stores a tuple `(max_value, selected_indices)` for a given capacity `w`.
2. To strictly enforce the lexicographically smallest index list when values are tied:
* When comparing two index lists with the same total value, the list that is lexicographically smaller is preferred.


3. Process each item one by one. Iterate the capacity $w$ in **descending order** (from $W$ down to the item's weight) to ensure each item is used at most once.
4. For each capacity $w$, compare keeping the existing selection vs. taking the current item (combining `dp[w - weight]` with the current item index). Update `dp[w]` if taking the current item yields a higher total value, or an equal value with a lexicographically smaller list of indices.

### Python Implementation

```python
def knapsack_01(weights: list[int], values: list[int], capacity: int) -> list[int]:
    """
    Solves the 0/1 Knapsack problem and returns the lexicographically smallest
    list of original indices that achieves the maximum total value.
    """
    n = len(weights)
    
    # dp[w] stores a tuple: (max_value, list_of_selected_indices)
    dp = [(0, []) for _ in range(capacity + 1)]
    
    for i in range(n):
        w_i = weights[i]
        v_i = values[i]
        
        # Iterate backwards to avoid using the same item multiple times
        for w in range(capacity, w_i - 1, -1):
            prev_val, prev_indices = dp[w - w_i]
            candidate_val = prev_val + v_i
            candidate_indices = prev_indices + [i]
            
            current_val, current_indices = dp[w]
            
            # Update dp[w] if candidate offers strictly greater value,
            # or equal value with a lexicographically smaller index list.
            if candidate_val > current_val:
                dp[w] = (candidate_val, candidate_indices)
            elif candidate_val == current_val and candidate_val > 0:
                if candidate_indices < current_indices:
                    dp[w] = (candidate_val, candidate_indices)
                    
    # Find the maximum value achieved across all capacities <= capacity
    max_value = max(val for val, _ in dp)
    
    # Collect all index lists achieving the maximum value and pick the lexicographically smallest
    best_indices = None
    for val, indices in dp:
        if val == max_value:
            if best_indices is None or indices < best_indices:
                best_indices = indices
                
    return best_indices if best_indices is not None else []


# Example Usage
if __name__ == "__main__":
    weights = [2, 3, 4, 5]
    values = [3, 4, 5, 6]
    capacity = 5
    
    selected_indices = knapsack_01(weights, values, capacity)
    print("Selected original indices:", selected_indices)

```
