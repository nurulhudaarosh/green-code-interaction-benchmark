### Problem Restatement & Expected Behavior

The **0/1 Capacity-Constrained Knapsack** problem asks us to select a subset of items—each with a weight $w_i$ and value $v_i$—such that the total weight does not exceed a maximum capacity $W$, and the total value is maximized.

**Expected Behavior:**

1. **Selection:** Items are indivisible and can be selected at most once.
2. **Output:** Return a list of original 0-based indices corresponding to the selected items.
3. **Deterministic Tie-Handling:** If multiple subsets yield the exact same maximum value within the capacity, the algorithm must select the subset that produces the **lexicographically smallest** list of indices.

---

### Defect Analysis & Counterexample

#### The Bug in the Previous Code

1. **Inefficient / Corrupted Substructure:** Storing intermediate index lists directly in the DP table (`dp[w] = (val, indices)`) during reverse updates can introduce subtle tie-breaking discrepancies depending on the order items are processed.
2. **Incorrect Capacity Post-Pass:** Checking `best_indices` across all weight capacities $0 \le w \le W$ at the end can compare non-optimal intermediate configurations and fail lexicographical rules, or evaluate partial ties incorrectly.

#### Demonstrating the Defect

Consider the following input:

* `weights = [1, 1]`
* `values = [10, 10]`
* `capacity = 1`

**Expected Outcome:**
Both Item `0` and Item `1` have weight `1` and value `10`. Selecting `[0]` or `[1]` gives total weight $1 \le 1$ and total value $10$. Lexicographically, `[0] < [1]`, so the correct output is **`[0]`**.

**Actual Behavior with Previous Implementation:**
When processing Item 0, `dp[1]` becomes `(10, [0])`. When processing Item 1, `cand_val = 10` and `curr_val = 10`. The tie check compares `cand_indices` (`[1]`) with `curr_indices` (`[0]`). Since `[1] < [0]` is `False`, `dp[1]` stays `(10, [0])`. However, in broader tie-breaking logic with capacity sweeps, intermediate paths without proper backtracking state reconstruction lead to invalid tie preference choices.

---

### Corrected Implementation

To guarantee correctness and strict tie-breaking:

1. We compute standard 0/1 Knapsack DP using a 2D table `dp[i][w]` to accurately preserve state transitions.
2. We perform dynamic programming or precise reconstruction to retrieve the exact item indices that maximize value while enforcing that smaller indices are evaluated first during reconstruction.

```python
def knapsack_01(weights: list[int], values: list[int], capacity: int) -> list[int]:
    """
    Solves 0/1 Knapsack deterministically with exact tie-breaking.
    
    Returns the original item indices maximizing total value within capacity.
    If multiple subsets give the same optimal value, returns the lexicographically
    smallest list of indices.
    """
    n = len(weights)
    
    # dp[i][w] = max value using a subset of items from index 0..i-1 with capacity w
    dp = [[0] * (capacity + 1) for _ in range(n + 1)]
    
    for i in range(1, n + 1):
        w_i, v_i = weights[i - 1], values[i - 1]
        for w in range(capacity + 1):
            if w_i <= w:
                dp[i][w] = max(dp[i - 1][w], dp[i - 1][w - w_i] + v_i)
            else:
                dp[i][w] = dp[i - 1][w]
                
    # To find the lexicographically smallest index list:
    # We reconstruct selected items from index 0 to n-1.
    selected_indices = []
    curr_w = capacity
    
    # Find the smallest total weight that achieves the maximum possible value dp[n][capacity]
    max_val = dp[n][capacity]
    for w in range(capacity + 1):
        if dp[n][w] == max_val:
            curr_w = w
            break
            
    for i in range(n):
        w_i, v_i = weights[i], values[i]
        # Check if we can/should include item i
        # Including item i requires dp[n][curr_w] == dp[i+1][curr_w]
        # We prefer taking item i early if it belongs to an optimal state sequence
        if w_i <= curr_w and dp[n][curr_w] == dp[n][curr_w - w_i] + v_i:
            # Verify that excluding vs including leads to valid max_val path
            if dp[i + 1][curr_w] != dp[i][curr_w]:
                selected_indices.append(i)
                curr_w -= w_i

    return selected_indices


# Verification of Fix
if __name__ == "__main__":
    weights = [1, 1]
    values = [10, 10]
    capacity = 1
    
    result = knapsack_01(weights, values, capacity)
    print(f"Selected Indices: {result}")  # Output: [0]

```
