### Problem Understanding

The task is to simulate a **non-preemptive single-server queue** with custom priority rules:

1. **Higher priority first:** Jobs with larger numerical priority values are processed first.
2. **Tie-breaking:**
* Earlier arrival time wins.
* If arrival times are equal, smaller Job ID wins.


3. **Non-preemptive:** Once a job starts running on the server, it runs to completion without interruption.

---

### Key Constraints & Required Output

* **Key Constraints:**
* Single server processing one job at a time.
* Server remains idle if no jobs are available, jumping time forward to the next job's arrival.
* Deterministic execution (no randomness).
* Standard Python library only.


* **Required Output:**
* Individual completion time and waiting time ($\text{Wait Time} = \text{Start Time} - \text{Arrival Time}$) for each job.
* Average waiting time across all jobs.



---

### Algorithm Description

1. **Sort Arrivals:** Sort the input job list by `arrival_time`, then by `priority` (descending), and finally by `job_id` (ascending).
2. **Priority Heap:** Maintain a min-heap storing ready jobs. To ensure higher priorities are popped first, push tuples inverted as: `(-priority, arrival_time, job_id, duration)`.
3. **Simulation Loop:**
* Keep track of current time (`current_time`).
* Advance time and push newly arrived jobs into the heap.
* If the server is free and the heap is empty, jump `current_time` to the arrival time of the next unhandled job.
* Pop the top job from the heap, calculate its completion time ($\text{current\_time} + \text{duration}$) and waiting time ($\text{current\_time} - \text{arrival\_time}$), then advance `current_time` to its completion time.



---

### Python Implementation

```python
import heapq

def simulate_queue(jobs):
    """
    Simulates a non-preemptive single-server queue.
    
    jobs: List of tuples/dicts representing jobs.
          Format: (job_id, arrival_time, duration, priority)
          
    Returns:
        results: List of dicts with job execution metrics.
        avg_wait_time: Float average waiting time.
    """
    # Sort initial jobs by arrival time to handle arrival stream sequentially
    unarrived_jobs = sorted(jobs, key=lambda x: (x[1], -x[3], x[0]))
    
    ready_heap = []
    results = {}
    
    current_time = 0
    job_idx = 0
    num_jobs = len(jobs)
    
    while job_idx < num_jobs or ready_heap:
        # Push all jobs that have arrived by current_time into the heap
        while job_idx < num_jobs and unarrived_jobs[job_idx][1] <= current_time:
            j_id, arr_time, dur, prio = unarrived_jobs[job_idx]
            # Priority max-heap using tuple negation: (-prio, arr_time, j_id, dur)
            heapq.heappush(ready_heap, (-prio, arr_time, j_id, dur))
            job_idx += 1
            
        # If no jobs are ready, jump time forward to the next arrival
        if not ready_heap:
            current_time = unarrived_jobs[job_idx][1]
            continue
            
        # Select highest-priority available job
        prio_neg, arr_time, j_id, dur = heapq.heappop(ready_heap)
        
        start_time = current_time
        wait_time = start_time - arr_time
        completion_time = start_time + dur
        current_time = completion_time
        
        results[j_id] = {
            "job_id": j_id,
            "completion_time": completion_time,
            "waiting_time": wait_time
        }
    
    # Sort results by job ID for output consistency
    ordered_results = [results[j[0]] for j in jobs]
    total_wait_time = sum(res["waiting_time"] for res in ordered_results)
    avg_wait_time = total_wait_time / num_jobs if num_jobs > 0 else 0.0
    
    return ordered_results, avg_wait_time


# Example Usage
if __name__ == "__main__":
    # Sample jobs format: (job_id, arrival_time, duration, priority)
    sample_jobs = [
        (1, 0, 5, 2),
        (2, 1, 3, 5),
        (3, 2, 4, 5),
        (4, 10, 2, 1)
    ]
    
    job_metrics, avg_wait = simulate_queue(sample_jobs)
    
    print("Job Execution Results:")
    for metric in job_metrics:
        print(f"Job ID {metric['job_id']}: Completion Time = {metric['completion_time']}, Waiting Time = {metric['waiting_time']}")
    
    print(f"\nAverage Waiting Time: {avg_wait:.2f}")
```
