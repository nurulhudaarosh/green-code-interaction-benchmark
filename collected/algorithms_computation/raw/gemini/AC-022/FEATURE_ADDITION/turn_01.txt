### Problem Identification and Understanding

The goal is to compute the minimum edit distance between two strings $s_1$ and $s_2$ under four allowed operations, each with a unit cost of 1:

1. **Insertion**: Insert a character into the string.
2. **Deletion**: Delete a character from the string.
3. **Substitution**: Replace one character with another.
4. **Adjacent Transposition**: Swap two adjacent characters.

This variation is known as the **Optimal String Alignment (OSA)** distance (also referred to as restricted Damerau–Levenshtein distance), where an edit step allows swapping adjacent characters, but no substring may be edited more than once via transposition.

---

### Constraints and Output

* **Key Constraints**:
* Each operation (insert, delete, substitute, adjacent transpose) has a cost of $1$.
* Two identical characters aligned without modification cost $0$.
* Transposition applies only to adjacent characters: $s_1[i-1] == s_2[j]$ and $s_1[i] == s_2[j-1]$.
* Deterministic execution using only the Python standard library.


* **Required Output**:
* A non-negative integer representing the minimum total cost to transform $s_1$ into $s_2$.



---

### Algorithm

Dynamic programming table $dp$ of dimensions $(m + 1) \times (n + 1)$, where $m = \vert{}s_1\vert{}$ and $n = \vert{}s_2\vert{}$:

1. **Base Cases**:
* $dp[i][0] = i$ (deleting all $i$ characters from $s_1$)
* $dp[0][j] = j$ (inserting all $j$ characters of $s_2$)


2. **Transitions**:
For $1 \le i \le m$ and $1 \le j \le n$:
* Let $\text{sub\_cost} = 0$ if $s_1[i - 1] == s_2[j - 1]$, else $1$.
* $dp[i][j] = \min($      * $dp[i - 1][j] + 1$ (Deletion),      * $dp[i][j - 1] + 1$ (Insertion),      * $dp[i - 1][j - 1] + \text{sub\_cost}$ (Substitution / Match)    $)$
* **Transposition transition**:
If $i > 1$, $j > 1$, $s_1[i - 1] == s_2[j - 2]$, and $s_1[i - 2] == s_2[j - 1]$:

$$dp[i][j] = \min(dp[i][j], dp[i - 2][j - 2] + 1)$$




3. **Result**:
The value at $dp[m][n]$.

---

### Python Implementation

```python
def osa_distance(s1: str, s2: str) -> int:
    """
    Computes the edit distance using insertion, deletion, substitution,
    and adjacent transposition, each costing 1 (Optimal String Alignment distance).
    """
    m, n = len(s1), len(s2)
    
    # Initialize DP table of size (m + 1) x (n + 1)
    dp = [[0] * (n + 1) for _ in range(m + 1)]
    
    # Base cases: cost of transforming to/from empty prefixes
    for i in range(m + 1):
        dp[i][0] = i
    for j in range(n + 1):
        dp[0][j] = j
        
    # Populate the DP table
    for i in range(1, m + 1):
        for j in range(1, n + 1):
            cost = 0 if s1[i - 1] == s2[j - 1] else 1
            
            # Standard Levenshtein transitions
            dp[i][j] = min(
                dp[i - 1][j] + 1,        # Deletion
                dp[i][j - 1] + 1,        # Insertion
                dp[i - 1][j - 1] + cost  # Substitution / Match
            )
            
            # Adjacent transposition transition
            if (
                i > 1 
                and j > 1 
                and s1[i - 1] == s2[j - 2] 
                and s1[i - 2] == s2[j - 1]
            ):
                dp[i][j] = min(dp[i][j], dp[i - 2][j - 2] + 1)
                
    return dp[m][n]


if __name__ == "__main__":
    test_cases = [
        ("kitten", "sitting"),   # Standard substitution + insertion: 3
        ("ca", "abc"),           # Transposition + insertion: 2
        ("abcd", "abdc"),        # Adjacent swap: 1
        ("hello", "hello"),      # Exact match: 0
        ("", "abc"),             # All insertions: 3
        ("abc", ""),             # All deletions: 3
    ]
    for s1, s2 in test_cases:
        print(f"dist('{s1}', '{s2}') = {osa_distance(s1, s2)}")
```
