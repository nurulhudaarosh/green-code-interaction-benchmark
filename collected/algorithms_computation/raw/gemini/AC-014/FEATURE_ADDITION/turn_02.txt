### Problem Definition: One-Dimensional K-Cluster Partition

Given a sorted 1D array of $N$ numerical points $X = [x_1, x_2, \dots, x_N]$ (where $x_1 \le x_2 \le \dots \le x_N$) and an integer $K$ ($1 \le K \le N$), the objective is to partition the array $X$ into $K$ contiguous, non-empty clusters $C_1, C_2, \dots, C_K$ such that the total within-cluster variance (or sum of squared deviations from each cluster's mean) is minimized.

#### Objective Function

Maximize cohesive clustering by minimizing:


$$\text{Cost}(X, K) = \sum_{k=1}^{K} \sum_{x \in C_k} (x - \mu_k)^2$$


where $\mu_k = \frac{1}{\vert{}C_k\vert{}} \sum_{x \in C_k} x$ is the mean of cluster $C_k$.

---

### Existing Required Outputs

Standard implementations of the 1D $K$-Cluster Partitioning algorithm (e.g., via dynamic programming) return a structured result containing:

1. **`clusters`**: A list of $K$ sub-lists/arrays representing the continuous partitioning of input values $X$.
2. **`centroids`**: A list of length $K$ containing the mean ($\mu_k$) of each cluster.
3. **`total_cost`**: A float representing the minimum sum of squared errors (SSE) across all $K$ clusters.
4. **`cluster_indices`**: A list of tuples `(start_index, end_index)` indicating the inclusive bounds of each cluster relative to the input array $X$.

---

### Extended Feature: `operation_summary`

When enabled, the returned output includes an additional field `operation_summary` containing a deterministic counter of major computational decisions/operations performed during the DP execution.

#### Deterministic Operation Tracking

For this dynamic programming formulation:

* **Cost Matrix Evaluation**: Pre-computing or evaluating cluster costs for a interval $[i, j]$ counts as **1 operation**.
* **State Decision Evaluation**: Computing $DP[k][i] = \min_{j} (DP[k-1][j-1] + \text{Cost}(X[j \dots i]))$ for a specific split point $j$ counts as **1 decision operation**.

---

### Python Implementation

```python
from typing import List, Dict, Any, Tuple, Optional

def k_cluster_partition_1d(
    X: List[float], 
    K: int, 
    include_summary: bool = False
) -> Dict[str, Any]:
    """
    Partitions a sorted 1D array X into K contiguous clusters minimizing within-cluster SSE.
    
    :param X: Sorted list of numerical points.
    :param K: Number of clusters (1 <= K <= len(X)).
    :param include_summary: Optional flag to include operation_summary in the output.
    :return: Dictionary containing original outputs and optionally 'operation_summary'.
    """
    N = len(X)
    if N == 0 or K <= 0 or K > N:
        raise ValueError("Invalid parameters: Require 1 <= K <= N and non-empty X.")
    
    # Track deterministic operations
    op_count = 0
    
    # 1. Precompute prefix sums and prefix squared sums for O(1) interval cost lookup
    # P[i] = sum(X[0...i-1]), Q[i] = sum(X[0...i-1]^2)
    P = [0.0] * (N + 1)
    Q = [0.0] * (N + 1)
    for i in range(N):
        P[i + 1] = P[i] + X[i]
        Q[i + 1] = Q[i] + X[i] ** 2

    def get_cost(i: int, j: int) -> float:
        """Returns SSE for subarray X[i...j] in O(1) time."""
        nonlocal op_count
        op_count += 1
        count = j - i + 1
        s = P[j + 1] - P[i]
        sq_s = Q[j + 1] - Q[i]
        return sq_s - (s * s) / count

    # 2. Dynamic Programming Table Setup
    # dp[k][i] = min cost to partition X[0...i] into k clusters
    dp = [[float('inf')] * N for _ in range(K + 1)]
    parent = [[-1] * N for _ in range(K + 1)]

    # Base case: 1 cluster
    for i in range(N):
        dp[1][i] = get_cost(0, i)

    # DP Transitions
    for k in range(2, K + 1):
        for i in range(k - 1, N):
            for j in range(k - 1, i + 1):
                op_count += 1  # State decision operation evaluation
                cost = dp[k - 1][j - 1] + get_cost(j, i)
                if cost < dp[k][i]:
                    dp[k][i] = cost
                    parent[k][i] = j

    # 3. Backtrack to recover cluster boundaries
    clusters_bounds: List[Tuple[int, int]] = []
    curr_i = N - 1
    for k in range(K, 0, -1):
        if k == 1:
            clusters_bounds.append((0, curr_i))
        else:
            prev_split = parent[k][curr_i]
            clusters_bounds.append((prev_split, curr_i))
            curr_i = prev_split - 1

    clusters_bounds.reverse()

    # Build primary required output structures
    clusters = [X[start:end + 1] for start, end in clusters_bounds]
    centroids = [sum(cluster) / len(cluster) for cluster in clusters]
    total_cost = dp[K][N - 1]

    # Construct primary return dictionary
    result = {
        "clusters": clusters,
        "centroids": centroids,
        "total_cost": total_cost,
        "cluster_indices": clusters_bounds
    }

    # Add extended feature conditionally
    if include_summary:
        result["operation_summary"] = {
            "total_computational_operations": op_count,
            "complexity_order": "O(K * N^2)",
            "input_size_N": N,
            "target_clusters_K": K
        }

    return result

```
