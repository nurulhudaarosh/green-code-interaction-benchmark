### Problem Definition & Analysis

Given $n$ one-dimensional points $X = [x_1, x_2, \dots, x_n]$, the objective is to:

1. Sort the points in non-decreasing order such that $x_1 \le x_2 \le \dots \le x_n$.
2. Partition the sorted array into $k$ contiguous clusters (subarrays) $C_1, C_2, \dots, C_k$ to minimize the total sum of squared deviations (SSD) from each cluster's mean:

$$\min_{C_1, \dots, C_k} \sum_{m=1}^{k} \sum_{x_i \in C_m} (x_i - \mu_m)^2 \quad \text{where } \mu_m = \frac{1}{\vert{}C_m\vert{}} \sum_{x_i \in C_m} x_i$$

#### Key Constraints

* **Inputs:** Array of numerical values $X$ of length $n$, and the number of clusters $k$.
* **Edge Cases:** If $k \ge n$, each point forms its own cluster, resulting in a total cost of $0.0$.
* **Deterministic Execution:** The solution must be exact and optimal (unlike standard heuristic 1D $k$-means).

#### Required Output

* **Cost:** The minimum total sum of squared deviations across all $k$ clusters.
* **Boundary Indices:** The 0-based split indices defining the $k$ contiguous clusters in the sorted array.

---

### Algorithm Overview

1. **Sorting:** Sort the array $X$ in ascending order.
2. **Prefix Sums for $O(1)$ Interval Cost:**
For an interval $[i, j]$ (1-based index), the SSD cost $C(i, j)$ can be computed in $O(1)$ time using prefix sums of elements ($P_1$) and prefix sums of squared elements ($P_2$):

$$C(i, j) = \sum_{m=i}^{j} x_m^2 - \frac{1}{j - i + 1} \left( \sum_{m=i}^{j} x_m \right)^2 = (P_2[j] - P_2[i-1]) - \frac{(P_1[j] - P_1[i-1])^2}{j - i + 1}$$


3. **Dynamic Programming:**
Let $\text{dp}[m][j]$ be the minimum cost of partitioning the first $j$ elements into $m$ clusters.

$$\text{dp}[m][j] = \min_{m-1 \le i < j} \left( \text{dp}[m-1][i] + C(i+1, j) \right)$$


4. **Backtracking:** Maintain split point markers to reconstruct the exact boundary indices of the $k$ partitions.

---

### Python Implementation

```python
from typing import List, Tuple

def min_ssd_1d_clustering(points: List[float], k: int) -> Tuple[float, List[int]]:
    """
    Sorts 1D points and partitions them into k optimal contiguous clusters.
    
    Returns:
        total_cost: The minimum sum of squared deviations from cluster means.
        boundaries: List of partition boundary indices (end indices of clusters).
    """
    n = len(points)
    if n == 0 or k <= 0:
        return 0.0, []
    
    # Step 1: Sort points
    sorted_x = sorted(points)
    
    if k >= n:
        # Every point is its own cluster; cost is 0.0
        return 0.0, list(range(1, n + 1))
    
    # Step 2: Build prefix sums for O(1) interval cost evaluation
    # P1[i] = sum(sorted_x[0:i]), P2[i] = sum(x^2 for x in sorted_x[0:i])
    P1 = [0.0] * (n + 1)
    P2 = [0.0] * (n + 1)
    for i in range(n):
        P1[i + 1] = P1[i] + sorted_x[i]
        P2[i + 1] = P2[i] + sorted_x[i] ** 2

    def cost(i: int, j: int) -> float:
        """Returns the SSD cost for sorted_x[i:j] (0-indexed, half-open interval)."""
        count = j - i
        if count <= 1:
            return 0.0
        sum_x = P1[j] - P1[i]
        sum_sq = P2[j] - P2[i]
        return max(0.0, sum_sq - (sum_x ** 2) / count)

    # Step 3: DP Table Initialization
    # dp[m][j]: min cost to cluster sorted_x[:j] into m clusters
    dp = [[float('inf')] * (n + 1) for _ in range(k + 1)]
    parent = [[0] * (n + 1) for _ in range(k + 1)]
    
    # Base case: 1 cluster
    for j in range(1, n + 1):
        dp[1][j] = cost(0, j)
        parent[1][j] = 0

    # Fill DP table for m = 2..k clusters
    for m in range(2, k + 1):
        for j in range(m, n + 1):
            for i in range(m - 1, j):
                current_cost = dp[m - 1][i] + cost(i, j)
                if current_cost < dp[m][j]:
                    dp[m][j] = current_cost
                    parent[m][j] = i

    # Step 4: Backtrack boundary indices
    boundaries = []
    curr_j = n
    for m in range(k, 0, -1):
        boundaries.append(curr_j)
        curr_j = parent[m][curr_j]
    
    boundaries.reverse()
    total_cost = dp[k][n]
    
    return total_cost, boundaries

# --- Example Usage ---
if __name__ == "__main__":
    data = [4.0, 1.0, 2.0, 10.0, 12.0, 3.0]
    num_clusters = 2
    
    cost_val, split_indices = min_ssd_1d_clustering(data, num_clusters)
    sorted_data = sorted(data)
    
    print(f"Sorted Data: {sorted_data}")
    print(f"Optimal Cost: {cost_val:.4f}")
    print(f"Cluster Boundaries (End Indices): {split_indices}")

```
