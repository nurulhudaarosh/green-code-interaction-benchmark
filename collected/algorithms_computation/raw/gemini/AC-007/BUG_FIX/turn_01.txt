### Problem Overview

Given an undirected graph with $V$ vertices, $E$ weighted edges, and $K$ connected components, the goal is to find a **Minimum Spanning Forest (MSF)**. An MSF consists of a Minimum Spanning Tree (MST) for each connected component of the graph. When multiple edges have equal weights, tie-breaking must strictly favor edges with smaller original edge IDs to ensure determinism.

### Key Constraints & Requirements

* **Determinism:** Tie-breaking for equal-cost edges must strictly follow ascending order of their original 0-based edge IDs.
* **Forest Structure:** The graph may be disconnected; the solution must find an MST for each independent component.
* **Output Requirements:**
1. **Total Cost:** Sum of edge weights in the Minimum Spanning Forest.
2. **Selected Edge IDs:** List of original 0-based indices of edges included in the MSF.



---

### Algorithm

We use **Kruskal's Algorithm** paired with a **Disjoint-Set Union (DSU)** data structure:

1. **Edge Sorting:** Sort all edges primarily by weight in ascending order. Break ties by sorting by original edge ID in ascending order.
2. **DSU Initialization:** Maintain a DSU structure using path compression and union-by-rank to track connected components efficiently.
3. **Forest Construction:** Iterate through the sorted edges. For each edge connecting vertices $u$ and $v$, use the DSU to check if they belong to different components:
* If `find(u) != find(v)`, perform `union(u, v)`, add the edge weight to the total cost, and append the original edge ID to the result set.
* Otherwise, skip the edge to avoid creating cycles.



---

### Python Implementation

```python
class DSU:
    def __init__(self, n: int):
        self.parent = list(range(n))
        self.rank = [0] * n

    def find(self, i: int) -> int:
        if self.parent[i] == i:
            return i
        self.parent[i] = self.find(self.parent[i])  # Path compression
        return self.parent[i]

    def union(self, i: int, j: int) -> bool:
        root_i = self.find(i)
        root_j = self.find(j)
        
        if root_i != root_j:
            # Union by rank
            if self.rank[root_i] < self.rank[root_j]:
                root_i, root_j = root_j, root_i
            self.parent[root_j] = root_i
            if self.rank[root_i] == self.rank[root_j]:
                self.rank[root_i] += 1
            return True
        return False


def minimum_spanning_forest(num_vertices: int, edges: list[tuple[int, int, float | int]]) -> tuple[float | int, list[int]]:
    """
    Computes the Minimum Spanning Forest for an undirected weighted graph.

    :param num_vertices: Number of vertices in the graph (0 to num_vertices - 1).
    :param edges: List of tuples (u, v, weight) where original index represents Edge ID.
    :return: A tuple containing (total_cost, selected_edge_ids).
    """
    # Decorate edges with their original ID: (weight, edge_id, u, v)
    # Sorting tuple naturally handles weight ascending, then original edge_id ascending
    indexed_edges = [(weight, edge_id, u, v) for edge_id, (u, v, weight) in enumerate(edges)]
    indexed_edges.sort()

    dsu = DSU(num_vertices)
    total_cost = 0
    selected_edge_ids = []

    for weight, edge_id, u, v in indexed_edges:
        if dsu.union(u, v):
            total_cost += weight
            selected_edge_ids.append(edge_id)

    return total_cost, selected_edge_ids


# Example Usage
if __name__ == "__main__":
    # Graph with 6 vertices and disconnected components
    num_vertices = 6
    edges = [
        (0, 1, 4),  # Edge ID 0
        (0, 2, 4),  # Edge ID 1 (Same weight as ID 0, ID 0 processed first)
        (1, 2, 2),  # Edge ID 2
        (3, 4, 3),  # Edge ID 3
        (4, 5, 1),  # Edge ID 4
        (3, 5, 5),  # Edge ID 5
    ]

    cost, selected_ids = minimum_spanning_forest(num_vertices, edges)
    print(f"Total Cost: {cost}")
    print(f"Selected Edge IDs: {selected_ids}")
```
