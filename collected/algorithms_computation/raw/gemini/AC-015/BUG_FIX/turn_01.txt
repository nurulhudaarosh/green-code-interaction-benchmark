### Problem Statement

Given a directed graph $G = (V, E)$ with non-negative edge capacities, a designated source vertex $s$, and a sink vertex $t$, the goal is to compute:

1. The **maximum network flow** value from $s$ to $t$.
2. The exact **flow routed along each original edge** in the order they were provided in the input.

---

### Key Constraints & Structural Requirements

* **Capacity Constraint:** For every original directed edge $e = (u, v)$, $0 \le \text{flow}(e) \le \text{capacity}(e)$.
* **Flow Conservation:** For every vertex $v \in V \setminus \{s, t\}$, the total incoming flow must equal the total outgoing flow:

$$\sum_{(u, v) \in E} \text{flow}(u, v) = \sum_{(v, w) \in E} \text{flow}(v, w)$$


* **Skew Symmetry / Residual Consistency:** Pushing flow along an edge $e=(u,v)$ decreases its residual capacity and increases the residual capacity of its anti-edge $(v,u)$.
* **Deterministic Output:** The output flow for each edge must preserve the original order of the input edge list.

---

### Algorithmic Approach: Dinic's Algorithm

Dinic's algorithm computes maximum $s\text{-}t$ flow in $O(V^2 E)$ time using layered networks and blocking flows:

1. **Residual Graph Construction:** Maintain original forward edges alongside back-edges (initial capacity $0$) to track reversible flow. Store references to map residual flows back to original edge indices.
2. **BFS Phase (Level Graph):** Run a Breadth-First Search from $s$ to construct a level graph $L(v)$, representing the shortest distance (in edge count) from $s$ to $v$ along edges with positive residual capacity. If $t$ is unreachable, the flow is maximal.
3. **DFS Phase (Blocking Flow):** Advance along edges where $L(v) = L(u) + 1$ using Depth-First Search with **current-edge pointers** (to prevent re-exploring dead-end paths). Push bottleneck flow through valid paths until no more augmenting paths exist in the level graph.
4. **Iterate:** Repeat until BFS can no longer reach $t$.

---

### Deterministic Python Implementation

```python
from collections import deque
from typing import List, Tuple

class Edge:
    def __init__(self, to: int, rev: int, cap: int, original_idx: int = -1):
        self.to = to
        self.rev = rev
        self.cap = cap
        self.flow = 0
        self.original_idx = original_idx


class DinicMaxFlow:
    def __init__(self, num_nodes: int):
        self.n = num_nodes
        self.adj = [[] for _ in range(num_nodes)]
        self.level = [-1] * num_nodes
        self.ptr = [0] * num_nodes
        self.num_edges = 0

    def add_edge(self, u: int, v: int, capacity: int) -> None:
        """Adds a directed edge and its residual counterpart."""
        forward_edge = Edge(v, len(self.adj[v]), capacity, original_idx=self.num_edges)
        backward_edge = Edge(u, len(self.adj[u]), 0, original_idx=-1)
        
        self.adj[u].append(forward_edge)
        self.adj[v].append(backward_edge)
        self.num_edges += 1

    def _bfs(self, s: int, t: int) -> bool:
        self.level = [-1] * self.n
        self.level[s] = 0
        queue = deque([s])
        
        while queue:
            u = queue.popleft()
            for edge in self.adj[u]:
                if edge.cap - edge.flow > 0 and self.level[edge.to] < 0:
                    self.level[edge.to] = self.level[u] + 1
                    queue.append(edge.to)
                    
        return self.level[t] >= 0

    def _dfs(self, u: int, t: int, pushed: int) -> int:
        if pushed == 0 or u == t:
            return pushed

        for cid in range(self.ptr[u], len(self.adj[u])):
            self.ptr[u] = cid
            edge = self.adj[u][cid]
            tr = edge.to

            if self.level[u] + 1 != self.level[tr] or edge.cap - edge.flow == 0:
                continue

            tr_pushed = self._dfs(tr, t, min(pushed, edge.cap - edge.flow))
            if tr_pushed == 0:
                continue

            edge.flow += tr_pushed
            self.adj[tr][edge.rev].flow -= tr_pushed
            return tr_pushed

        return 0

    def compute_max_flow(self, s: int, t: int) -> Tuple[int, List[int]]:
        max_flow = 0
        while self._bfs(s, t):
            self.ptr = [0] * self.n
            while True:
                pushed = self._dfs(s, t, float('inf'))
                if pushed == 0:
                    break
                max_flow += pushed

        # Extract flows in the exact order of original input edges
        edge_flows = [0] * self.num_edges
        for u in range(self.n):
            for edge in self.adj[u]:
                if edge.original_idx != -1:
                    edge_flows[edge.original_idx] = edge.flow

        return max_flow, edge_flows


# --- Example Usage ---
if __name__ == "__main__":
    # Graph Topology:
    # 0 -> 1 (cap 10), 0 -> 2 (cap 10)
    # 1 -> 2 (cap 2),  1 -> 3 (cap 4), 1 -> 4 (cap 8)
    # 2 -> 4 (cap 9)
    # 3 -> 5 (cap 10)
    # 4 -> 3 (cap 6),  4 -> 5 (cap 10)

    nodes = 6
    source, sink = 0, 5
    edges = [
        (0, 1, 10),  # Edge 0
        (0, 2, 10),  # Edge 1
        (1, 2, 2),   # Edge 2
        (1, 3, 4),   # Edge 3
        (1, 4, 8),   # Edge 4
        (2, 4, 9),   # Edge 5
        (3, 5, 10),  # Edge 6
        (4, 3, 6),   # Edge 7
        (4, 5, 10),  # Edge 8
    ]

    dinic = DinicMaxFlow(nodes)
    for u, v, cap in edges:
        dinic.add_edge(u, v, cap)

    max_flow, flows = dinic.compute_max_flow(source, sink)

    print(f"Maximum Flow Value: {max_flow}\n")
    print("Edge-wise Flow Allocation (preserving original order):")
    for idx, (u, v, cap) in enumerate(edges):
        print(f"Edge {idx} ({u} -> {v}): Flow = {flows[idx]} / Capacity = {cap}")
```
