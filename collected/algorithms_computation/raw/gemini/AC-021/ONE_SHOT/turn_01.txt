### Problem Definition

Given an array of positive integers $A$ (0-indexed) and a target sum $T$:

1. Find a subset of indices $I \subseteq \{0, 1, \dots, \vert{}A\vert{}-1\}$ such that $\sum_{i \in I} A[i] = T$.
2. **Primary Tie-Breaker:** Minimize the subset size $\vert{}I\vert{}$ (fewest elements).
3. **Secondary Tie-Breaker:** Choose the lexicographically smallest list of 0-based indices $I$.

---

### Constraints & Output Requirements

* **Input:** A list of positive integers $A$ and a target sum $T \ge 0$.
* **Constraints:** $A[i] > 0$ for all elements. Standard dynamic programming memory bounds apply based on $T$.
* **Output:** The optimal list of 0-based indices in strictly increasing order, or `None` (or empty list if $T=0$) if no solution exists.

---

### Algorithm

We use **0/1 Knapsack Dynamic Programming with Lexicographical Reconstruction Tracking**:

1. **State:** $DP[s]$ represents the optimal tuple `(count, index_tuple)` to achieve a sum $s$.
* `count`: The minimum number of elements used to achieve sum $s$.
* `index_tuple`: The lexicographically smallest sequence of indices achieving sum $s$ with `count` elements.


2. **Initialization:** $DP[0] = (0, ())$ and $DP[s] = (\infty, \text{None})$ for $s > 0$.
3. **Transitions:** Process elements $A[i]$ sequentially from index $i = 0$ to $\vert{}A\vert{}-1$. For each target sum $s$ from $T$ down to $A[i]$:
* If state $s - A[i]$ is reachable, consider transition to state $s$ using index $i$.
* Candidate state for sum $s$: `(DP[s - A[i]].count + 1, DP[s - A[i]].index_tuple + (i,))`.
* Update $DP[s]$ if the candidate yields a smaller element count, or the same element count with a lexicographically smaller sequence of indices.



---

### Python Solution

```python
def min_subset_sum_indices(nums: list[int], target: int) -> list[int] | None:
    """
    Finds a subset of indices summing to target with:
    1. Minimum subset size.
    2. Lexicographically smallest list of indices.
    """
    if target == 0:
        return []
    
    # DP array initialized to infinity for element count
    # dp[s] = (count, index_tuple)
    dp = [(float('inf'), None)] * (target + 1)
    dp[0] = (0, ())
    
    for i, num in enumerate(nums):
        if num > target:
            continue
            
        for s in range(target, num - 1, -1):
            prev_count, prev_indices = dp[s - num]
            
            if prev_count != float('inf'):
                candidate_count = prev_count + 1
                candidate_indices = prev_indices + (i,)
                
                curr_count, curr_indices = dp[s]
                
                # Check if candidate is strictly better
                if candidate_count < curr_count:
                    dp[s] = (candidate_count, candidate_indices)
                elif candidate_count == curr_count:
                    if curr_indices is None or candidate_indices < curr_indices:
                        dp[s] = (candidate_count, candidate_indices)

    result_count, result_indices = dp[target]
    return list(result_indices) if result_count != float('inf') else None


# Example usage & validation
if __name__ == "__main__":
    A = [3, 34, 4, 12, 5, 2]
    T = 9
    
    indices = min_subset_sum_indices(A, T)
    print(f"Array: {A}, Target: {T}")
    print(f"Optimal Indices: {indices}")  # Output: [2, 4] -> A[2] + A[4] = 4 + 5 = 9 (size 2)

```
