### Problem Restatement & Base Requirements

**Problem:** Implement a `RectangleStatisticsEngine` for a static 2D grid of integers ($R \times C$). The engine pre-processes the grid to process submatrix queries specified by inclusive coordinates $(r_1, c_1)$ to $(r_2, c_2)$.

**Original Required Outputs:**

* **`sum`**: The total sum of all elements within the query rectangle, computed in $O(1)$ time using a precalculated 2D prefix-sum matrix.
* **`min`**: The minimum element value within the query rectangle, computed via deterministic row-major direct scanning.
* **`max`**: The maximum element value within the query rectangle, computed via deterministic row-major direct scanning.

**Default Behavior:**

* When `include_summary=False` (or unrequested), the engine MUST maintain backward compatibility and return the exact standard tuple `(sum, min, max)`.

---

### Extended Feature: `operation_summary`

When `include_summary=True` is specified:

* The query returns a 4-tuple: `(sum, min, max, operation_summary)`.
* **`operation_summary`** is a deterministic dictionary tracking the exact computational work performed during the query execution:
* **`prefix_sum_lookups`**: Constant `4` (the 4 table accesses required for the 2D prefix-sum formula).
* **`scanned_cells`**: Total number of cells evaluated in the query bounding box ($(r_2 - r_1 + 1) \times (c_2 - c_1 + 1)$).
* **`extrema_comparisons`**: Total conditional evaluations made ($2 \times \text{scanned\_cells}$ for min/max checks).
* **`min_updates`**: Exact number of times the running `rect_min` value was updated during row-major scanning.
* **`max_updates`**: Exact number of times the running `rect_max` value was updated during row-major scanning.



---

### Complete Python Implementation

```python
from typing import List, Tuple, Dict, Any, Union

class RectangleStatisticsEngine:
    """
    Pre-processes an integer matrix to answer submatrix queries for 
    sum, minimum, maximum, and optional operational statistics summaries.
    """
    def __init__(self, matrix: List[List[int]]):
        if not matrix or not matrix[0]:
            raise ValueError("Input matrix must be non-empty and 2-dimensional.")
            
        self.matrix = matrix
        self.R = len(matrix)
        self.C = len(matrix[0])
        
        # Verify uniform column length
        for row in matrix:
            if len(row) != self.C:
                raise ValueError("All rows in matrix must have identical lengths.")
        
        # 2D Prefix Sum construction (1-indexed prefix table)
        # pref[i][j] stores sum of matrix[0..i-1][0..j-1]
        self.pref = [[0] * (self.C + 1) for _ in range(self.R + 1)]
        for r in range(1, self.R + 1):
            for c in range(1, self.C + 1):
                self.pref[r][c] = (
                    self.matrix[r - 1][c - 1]
                    + self.pref[r - 1][c]
                    + self.pref[r][c - 1]
                    - self.pref[r - 1][c - 1]
                )

    def query(
        self, 
        r1: int, 
        c1: int, 
        r2: int, 
        c2: int, 
        include_summary: bool = False
    ) -> Union[Tuple[int, int, int], Tuple[int, int, int, Dict[str, int]]]:
        """
        Executes inclusive range query for rectangle defined by (r1, c1) to (r2, c2).
        
        Parameters:
            r1, c1: Top-left coordinate (0-indexed)
            r2, c2: Bottom-right coordinate (0-indexed)
            include_summary: If True, appends operation_summary dictionary to return tuple.
            
        Returns:
            Default (include_summary=False): 
                Tuple[int, int, int] -> (rect_sum, rect_min, rect_max)
            Extended (include_summary=True): 
                Tuple[int, int, int, Dict[str, int]] -> (rect_sum, rect_min, rect_max, operation_summary)
        """
        # Strict validation of coordinate bounds
        if not (0 <= r1 < self.R and 0 <= r2 < self.R and 0 <= c1 < self.C and 0 <= c2 < self.C):
            raise IndexError(f"Query coordinates ({r1}, {c1}), ({r2}, {c2}) are out of grid bounds ({self.R}x{self.C}).")
            
        if r1 > r2 or c1 > c2:
            raise ValueError(f"Invalid query rectangle: top-left ({r1}, {c1}) must be <= bottom-right ({r2}, {c2}).")

        # 1. Sum query via 2D Prefix Sum Table - O(1)
        rect_sum = (
            self.pref[r2 + 1][c2 + 1]
            - self.pref[r1][c2 + 1]
            - self.pref[r2 + 1][c1]
            + self.pref[r1][c1]
        )

        # 2. Extrema query via deterministic row-major direct scanning - O(H * W)
        rect_min = self.matrix[r1][c1]
        rect_max = self.matrix[r1][c1]

        scanned_cells = 0
        extrema_comparisons = 0
        min_updates = 0
        max_updates = 0

        # Explicit deterministic row-major traversal: top to bottom (r1..r2), left to right (c1..c2)
        for r in range(r1, r2 + 1):
            for c in range(c1, c2 + 1):
                val = self.matrix[r][c]
                scanned_cells += 1

                # Check minimum
                extrema_comparisons += 1
                if val < rect_min:
                    rect_min = val
                    min_updates += 1

                # Check maximum
                extrema_comparisons += 1
                if val > rect_max:
                    rect_max = val
                    max_updates += 1

        if include_summary:
            summary = {
                "prefix_sum_lookups": 4,
                "scanned_cells": scanned_cells,
                "extrema_comparisons": extrema_comparisons,
                "min_updates": min_updates,
                "max_updates": max_updates,
            }
            return rect_sum, rect_min, rect_max, summary

        # Backward-compatible default return
        return rect_sum, rect_min, rect_max


# Verification
if __name__ == "__main__":
    matrix = [
        [10, -2,  3,  4],
        [ 5,  6, -2,  8],
        [ 9,  1,  0, 12]
    ]

    engine = RectangleStatisticsEngine(matrix)

    # 1. Default query mode (backward compatible)
    res_default = engine.query(0, 1, 2, 2)
    print("Default Output:", res_default)
    assert res_default == (6, -2, 6)

    # 2. Extended query mode with operational summary
    res_sum, res_min, res_max, summary = engine.query(0, 1, 2, 2, include_summary=True)
    print("\nExtended Output:")
    print(f"Statistics -> Sum: {res_sum}, Min: {res_min}, Max: {res_max}")
    print("Operation Summary:", summary)
    
    # Validation checks
    assert (res_sum, res_min, res_max) == (6, -2, 6)
    assert summary["scanned_cells"] == 6
    assert summary["extrema_comparisons"] == 12
    assert summary["prefix_sum_lookups"] == 4
```
