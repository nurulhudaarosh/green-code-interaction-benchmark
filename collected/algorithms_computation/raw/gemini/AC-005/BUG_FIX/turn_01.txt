### Problem Analysis

Given an integer sequence $A = [a_0, a_1, \dots, a_{n-1}]$, we need to find a strictly increasing subsequence $A[i_0], A[i_1], \dots, A[i_{k-1}]$ (with $0 \le i_0 < i_1 < \dots < i_{k-1} < n$ and $A[i_0] < A[i_1] < \dots < A[i_{k-1}]$) such that:

1. The length $k$ is maximized (Longest Increasing Subsequence, LIS).
2. The index sequence $(i_0, i_1, \dots, i_{k-1})$ is lexicographically smallest among all valid index sequences of maximum length $k$.

### Key Constraints & Output

* **Input:** An integer sequence $A$ of length $n$.
* **Constraints:** Sequential processing, deterministic execution.
* **Output:** A list/tuple of indices $(i_0, i_1, \dots, i_{k-1})$ representing the optimal index sequence.

---

### Algorithm Description

We use a quadratic dynamic programming ($O(n^2)$) approach with explicit tracking:

1. **DP Definitions:**
* `dp[i]`: Length of the longest strictly increasing subsequence ending at index $i$.
* `parent[i]`: The predecessor index in the sequence ending at $i$ that yields the lexicographically smallest index path.
* `best_path[i]`: The actual lexicographically smallest index path ending at index $i$.


2. **Transition:**
* For each $i$ from $0$ to $n-1$:
* Initialize `dp[i] = 1`, `parent[i] = -1`, and `best_path[i] = (i,)`.
* For each $j < i$ with $A[j] < A[i]$:
* If `dp[j] + 1 > dp[i]`: Update `dp[i] = dp[j] + 1`, `parent[i] = j`, and `best_path[i] = best_path[j] + (i,)`.
* If `dp[j] + 1 == dp[i]`: Compare `best_path[j] + (i,)` with `best_path[i]`. If `best_path[j] + (i,)` is lexicographically smaller, update `parent[i] = j` and `best_path[i] = best_path[j] + (i,)`.






3. **Global Selection:**
* Iterate through all indices $i \in [0, n-1]$ to find the index $i^*$ that maximizes `dp[i]`.
* For ties in maximum length, choose the index $i^*$ that yields the lexicographically smallest `best_path[i*]`.



---

### Python Implementation

```python
def lexicographically_smallest_lis_indices(arr: list[int]) -> list[int]:
    """
    Finds the lexicographically smallest index sequence corresponding to 
    a strictly increasing subsequence of maximum length.
    
    Time Complexity: O(n^2)
    Space Complexity: O(n^2)
    """
    n = len(arr)
    if n == 0:
        return []

    dp = [1] * n
    best_path = [(i,) for i in range(n)]

    for i in range(n):
        for j in range(i):
            if arr[j] < arr[i]:
                candidate_length = dp[j] + 1
                candidate_path = best_path[j] + (i,)

                if candidate_length > dp[i]:
                    dp[i] = candidate_length
                    best_path[i] = candidate_path
                elif candidate_length == dp[i]:
                    if candidate_path < best_path[i]:
                        best_path[i] = candidate_path

    max_len = max(dp)
    optimal_path = None

    for i in range(n):
        if dp[i] == max_len:
            if optimal_path is None or best_path[i] < optimal_path:
                optimal_path = best_path[i]

    return list(optimal_path)


# Example usage
if __name__ == "__main__":
    nums = [10, 22, 9, 33, 21, 50, 41, 60, 80]
    indices = lexicographically_smallest_lis_indices(nums)
    values = [nums[i] for i in indices]
    
    print(f"Original Array: {nums}")
    print(f"Optimal Indices: {indices}")
    print(f"Subsequence Values: {values}")

```
