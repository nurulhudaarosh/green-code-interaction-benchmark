The problem requires finding all prime numbers within a closed interval $[L, R]$, determining the difference (gap) between every pair of consecutive primes in that range, and returning the maximum gap found.

### Key Constraints & Required Output

* **Constraints:** Range boundaries $L$ and $R$ where $1 \le L \le R$. The interval width $R - L + 1$ is bounded, making a segmented sieve memory-efficient and fast even when $R$ is up to $10^{12}$ or higher.
* **Required Output:** A single integer representing the largest gap between two consecutive primes in $[L, R]$. If there are fewer than 2 primes in $[L, R]$, return `0`.

---

### Algorithm Description

1. **Base Primes Generation:** Compute base primes up to $\lfloor\sqrt{R}\rfloor$ using a standard Sieve of Eratosthenes.
2. **Segmented Sieve:**
* Create a boolean array `is_prime` of size $R - L + 1$, initialized to `True`.
* For each base prime $p$, compute the smallest multiple of $p$ that is $\ge L$ and $\ge 2p$.
* Mark all multiples of $p$ in $[L, R]$ as non-prime (`False`).
* Handle edge cases: if $L = 1$, explicitly mark index `0` ($1$) as non-prime.


3. **Max Gap Calculation:** Collect all indices remaining `True` to form the list of prime numbers in $[L, R]$. Iterate through consecutive pairs to compute $p_{i+1} - p_i$ and return the maximum gap.

---

### Python Implementation

```python
import math

def max_prime_gap(L: int, R: int) -> int:
    """
    Finds all prime numbers in the closed interval [L, R] using a segmented sieve
    and returns the largest gap between two consecutive primes in the range.
    """
    if R < 2 or L > R:
        return 0
    
    # Adjust lower bound to minimum valid prime candidate
    effective_L = max(L, 2)
    if effective_L > R:
        return 0

    limit = math.isqrt(R)
    
    # Step 1: Base sieve up to sqrt(R)
    base_is_prime = [True] * (limit + 1)
    base_is_prime[0] = base_is_prime[1] = False
    for i in range(2, math.isqrt(limit) + 1):
        if base_is_prime[i]:
            for j in range(i * i, limit + 1, i):
                base_is_prime[j] = False

    base_primes = [p for p in range(2, limit + 1) if base_is_prime[p]]

    # Step 2: Segmented sieve on [L, R]
    segment_len = R - L + 1
    segment_is_prime = [True] * segment_len

    # Handle L = 1 or L = 0 explicitly
    if L < 2:
        for i in range(min(2 - L, segment_len)):
            segment_is_prime[i] = False

    for p in base_primes:
        # Find first multiple of p >= L and >= 2*p
        start = max(p * p, ((L + p - 1) // p) * p)
        for j in range(start, R + 1, p):
            segment_is_prime[j - L] = False

    # Step 3: Collect primes and find maximum gap
    primes_in_range = [L + i for i in range(segment_len) if segment_is_prime[i]]

    if len(primes_in_range) < 2:
        return 0

    max_gap = 0
    for i in range(len(primes_in_range) - 1):
        gap = primes_in_range[i + 1] - primes_in_range[i]
        if gap > max_gap:
            max_gap = gap

    return max_gap


# Example usage:
if __name__ == "__main__":
    L, R = 100, 200
    print(f"Max prime gap in [{L}, {R}]: {max_prime_gap(L, R)}")
```
