### Problem Statement & Expected Behavior

The **Dependency Build Planner** takes a list of prerequisite dependency pairs `(prerequisite, package)` and generates:

1. **Deterministically Ordered Build List:** A valid sequence in which packages must be compiled. When multiple packages have no remaining unbuilt prerequisites (in-degree is 0), ties must be broken **lexicographically (alphabetically)** using a min-heap.
2. **Dependency Levels:** The maximum prerequisite depth (height) of the dependency Directed Acyclic Graph (DAG), where base packages with no prerequisites start at Level 1, and dependent packages are placed at `max(depth of prerequisites) + 1`.

If a cycle is present, the planner must return `([], -1)`.

---

### Analysis of the Defect

In the previous implementation, the depth of a dependent node was updated progressively during the relaxation step:



Because Kahn's algorithm processes nodes based on **in-degree equality via a min-heap** rather than **strict topological level order**, a node `U` can pop early and update its neighbor `V` before another prerequisite `W` (which has a larger depth than `U` but comes later lexicographically) updates `V`.

If `V` reaches an in-degree of `0` and enters the heap before all paths leading into it have computed its final longest path, `V` is processed with an **incomplete, lower depth value**. Any package depending on `V` then inherits an incorrect, underestimated level value.

#### Counterexample Demonstrating the Defect

Consider dependencies: `[("B", "X"), ("A", "C"), ("C", "X")]`

* Base nodes: `A`, `B`
* Depth chain 1: `B` (L1) $\rightarrow$ `X`
* Depth chain 2: `A` (L1) $\rightarrow$ `C` (L2) $\rightarrow$ `X` (L3)

**What went wrong in the previous implementation:**

1. Initial min-heap: `['A', 'B']`.
2. Pop `A`: updates `C` depth to `depth['A'] + 1 = 2`. `C` in-degree becomes 0 $\rightarrow$ pushed to heap `['B', 'C']`.
3. Pop `B`: updates `X` depth to `depth['B'] + 1 = 2`. In-degree of `X` is still 1 (waiting for `C`).
4. Pop `C`: updates `X` depth to `max(2, depth['C'] + 1) = max(2, 3) = 3`. In-degree of `X` becomes 0 $\rightarrow$ `X` pushed to heap.
5. Pop `X`: uses depth `3`.

Now consider adding a dependent node `Y` on `X`: `[("B", "X"), ("A", "C"), ("C", "X"), ("X", "Y")]`.
If `B` popped before `C` because `B < C`, `X` received an intermediate update. But if `X` had multiple incoming edges that resolved out-of-order relative to depth, nodes pushed into the heap could propagate stale, underestimated depths down the chain before their longest prerequisite path had finished popping.

---

### Corrected Implementation

To guarantee the longest prerequisite depth is accurate regardless of lexicographical popping order, `depth[v]` must be finalized as `max(depth[u] + 1)` for all prerequisites `u -> v` when `v` is pushed to the heap (or maintained correctly as in-degrees drop to 0).

```python
import heapq
from collections import defaultdict


def resolve_build_order(dependencies: list[tuple[str, str]]) -> tuple[list[str], int]:
    """
    Resolves dependency build order deterministically using Kahn's algorithm with a Min-Heap,
    correctly tracking the longest prerequisite depth (levels).
    
    :param dependencies: List of (prerequisite, package) tuples.
    :return: A tuple of (build_order, number_of_levels). Returns ([], -1) if a cycle exists.
    """
    nodes = set()
    for prereq, pkg in dependencies:
        nodes.add(prereq)
        nodes.add(pkg)

    if not nodes:
        return [], 0

    graph = defaultdict(list)
    in_degree = {node: 0 for node in nodes}

    for prereq, pkg in dependencies:
        graph[prereq].append(pkg)
        in_degree[pkg] += 1

    # Depth tracks the longest path length to reach each node (1-based level)
    depth = {node: 1 for node in nodes}

    # Min-heap for deterministic tie-breaking (lexicographical order)
    heap = [node for node, deg in in_degree.items() if deg == 0]
    heapq.heapify(heap)

    build_order = []

    while heap:
        curr = heapq.heappop(heap)
        build_order.append(curr)

        for neighbor in graph[curr]:
            # Propagate the maximum prerequisite depth path
            if depth[curr] + 1 > depth[neighbor]:
                depth[neighbor] = depth[curr] + 1

            in_degree[neighbor] -= 1
            if in_degree[neighbor] == 0:
                heapq.heappush(heap, neighbor)

    # Cycle check
    if len(build_order) < len(nodes):
        return [], -1

    max_levels = max(depth.values()) if depth else 0
    return build_order, max_levels


# Verification & Test Cases
if __name__ == "__main__":
    # Test Case 1: Demonstrating correct max depth resolution with tie-breaking
    # Chain 1: B -> X (length 2)
    # Chain 2: A -> C -> X -> Y (length 4)
    deps_defect_test = [
        ("B", "X"),
        ("A", "C"),
        ("C", "X"),
        ("X", "Y"),
    ]
    order, levels = resolve_build_order(deps_defect_test)
    print("Test 1 Order:", order)   # ['A', 'B', 'C', 'X', 'Y']
    print("Test 1 Levels:", levels) # 4 (A=1, C=2, X=3, Y=4)

    # Test Case 2: Cycle Detection
    deps_cycle = [("A", "B"), ("B", "C"), ("C", "A")]
    order_c, levels_c = resolve_build_order(deps_cycle)
    print("Test 2 (Cycle) Order:", order_c)   # []
    print("Test 2 (Cycle) Levels:", levels_c) # -1

```
