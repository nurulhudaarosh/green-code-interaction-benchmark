### Problem & Output Requirements

Given a set of packages and their direct dependencies (prerequisites), the task is to generate a deterministic valid build order and calculate the minimum number of parallel build stages (dependency levels) required to build all packages. If a dependency cycle is detected, the build is impossible.

* **Key Constraints:**
* **Determinism:** When multiple packages are ready to be built concurrently (in-degree is 0), they must be selected in lexicographical order (sorted alphabetically by name).
* **Cycle Handling:** If a cyclic dependency exists, return an empty build order `[]` and `-1` for levels.
* **Standard Library Only:** Must rely solely on built-in Python modules.


* **Required Output:**
* `build_order`: A list of strings representing the deterministic, topologically sorted order of packages.
* `levels`: An integer representing the length of the longest dependency path (maximum depth).



---

### Algorithm

1. **In-Degree & Graph Setup:** Construct an adjacency list mapping each package to the packages that depend on it. Track the in-degree (number of prerequisite dependencies) for every package.
2. **Min-Heap for Determinism:** Initialize a min-heap (`heapq`) containing all packages with an initial in-degree of 0. This ensures tie-breaking always selects the lexicographically smallest package first.
3. **Level / Depth Tracking:** Maintain a dictionary tracking the maximum depth for each package (`depth[pkg]`). A package's depth is $\max(\text{depth of all prerequisites}) + 1$.
4. **Kahn's Algorithm Processing:**
* Pop the smallest package `u` from the min-heap and append it to the build order.
* For each package `v` that depends on `u`, update `depth[v] = max(depth[v], depth[u] + 1)`.
* Decrement the in-degree of `v`. If the in-degree reaches 0, push `v` into the min-heap.


5. **Cycle Detection & Result:** If the processed build order length matches the total number of packages, return `(build_order, max(depth.values()))`. Otherwise, return `([], -1)`.

---

### Python Implementation

```python
import heapq
from typing import Dict, List, Tuple

def get_deterministic_build_order(dependencies: Dict[str, List[str]]) -> Tuple[List[str], int]:
    """
    Computes a deterministic build order and the number of dependency levels.
    
    :param dependencies: Dictionary mapping a package to its list of direct prerequisites.
                         e.g., {'A': ['B', 'C']} means A depends on B and C.
    :return: A tuple of (build_order_list, dependency_levels_count)
             Returns ([], -1) if a dependency cycle is detected.
    """
    # Collect all unique packages (both keys and listed dependencies)
    all_packages = set(dependencies.keys())
    for prereqs in dependencies.values():
        all_packages.update(prereqs)
        
    if not all_packages:
        return [], 0

    # Initialize graph structures
    adj = {pkg: [] for pkg in all_packages}
    in_degree = {pkg: 0 for pkg in all_packages}
    depth = {pkg: 1 for pkg in all_packages}

    # Build adjacency list and compute in-degrees
    for pkg, prereqs in dependencies.items():
        in_degree[pkg] += len(prereqs)
        for prereq in prereqs:
            adj[prereq].append(pkg)

    # Priority queue (min-heap) to ensure lexicographical tie-breaking
    min_heap = [pkg for pkg, deg in in_degree.items() if deg == 0]
    heapq.heapify(min_heap)

    build_order = []

    # Kahn's algorithm using Min-Heap
    while min_heap:
        curr = heapq.heappop(min_heap)
        build_order.append(curr)

        for neighbor in adj[curr]:
            # Track longest dependency chain
            depth[neighbor] = max(depth[neighbor], depth[curr] + 1)
            in_degree[neighbor] -= 1
            if in_degree[neighbor] == 0:
                heapq.heappush(min_heap, neighbor)

    # If build_order doesn't include all packages, a cycle exists
    if len(build_order) != len(all_packages):
        return [], -1

    total_levels = max(depth.values()) if depth else 0
    return build_order, total_levels

    # Test Case 1: Standard DAG with multiple independent choices
    deps_1 = {
        "app": ["lib_a", "lib_b"],
        "lib_a": ["core"],
        "lib_b": ["core"],
        "core": []
    }
    order1, levels1 = get_deterministic_build_order(deps_1)

    # Expected: [] Levels: -1
```
