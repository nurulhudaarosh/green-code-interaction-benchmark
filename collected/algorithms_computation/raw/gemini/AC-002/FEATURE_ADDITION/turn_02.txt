### Restatement of the Problem & Original Output Requirements

The **Dependency Build Planner** takes a set of software packages and their prerequisite dependencies $(A, B)$, where package $A$ depends on package $B$.

The function must compute:

1. `build_order`: A list of package names organized in a valid, deterministic order. When multiple packages have zero remaining prerequisites, ties must be broken by selecting the lexicographically smallest package name first.
2. `num_levels`: The maximum height/depth of the dependency DAG (the length of the longest dependency path).
3. **Cycle Handling**: If a circular dependency exists in the graph, `build_order` must evaluate to an empty list `[]`, and `num_levels` must return `-1`.

### Concrete Feature Addition: `operation_summary`

When requested (via an optional parameter `return_summary=True`), the output expands to include an `operation_summary` field without altering any existing requirements or field signatures when set to `False`.

The `operation_summary` tracks key deterministic computational steps executed during the execution:

* **Package and Dependency Ingestions**: Edges and vertices processed during graph construction.
* **Heap Operations**: Pushes and pops performed during Kahn's topological sort.
* **Degree & Level Updates**: Graph traversal operations during dependency resolution.

---

### Python Solution

```python
import heapq
from typing import List, Tuple, Dict, Set, Optional, Union, Any


def get_deterministic_build_order(
    packages: List[str], 
    dependencies: List[Tuple[str, str]],
    return_summary: bool = False
) -> Union[Tuple[List[str], int], Tuple[List[str], int, Dict[str, Any]]]:
    """
    Computes a deterministic build order, dependency levels, and an optional operation summary.
    
    :param packages: List of package names.
    :param dependencies: List of (package, prerequisite) tuples where package depends on prerequisite.
    :param return_summary: If True, returns an additional `operation_summary` dict.
    :return: (build_order, num_levels) or (build_order, num_levels, operation_summary) if return_summary is True.
    """
    # Counters for operational summary
    ingest_ops = 0
    heap_ops = 0
    edge_traversals = 0
    level_updates = 0

    # 1. Deduplicate and discover all packages
    all_packages: Set[str] = set(packages)
    ingest_ops += len(packages)

    for pkg, dep in dependencies:
        all_packages.add(pkg)
        all_packages.add(dep)
        ingest_ops += 2

    in_degree: Dict[str, int] = {pkg: 0 for pkg in all_packages}
    graph: Dict[str, List[str]] = {pkg: [] for pkg in all_packages}
    
    # 2. Build adjacency list: prerequisite -> target
    for pkg, dep in dependencies:
        graph[dep].append(pkg)
        in_degree[pkg] += 1
        ingest_ops += 1

    # 3. Min-heap for zero in-degree nodes (lexicographical sorting)
    initial_zero_nodes = [pkg for pkg, deg in in_degree.items() if deg == 0]
    heapq.heapify(initial_zero_nodes)
    heap_ops += len(initial_zero_nodes)

    level: Dict[str, int] = {pkg: 1 for pkg in initial_zero_nodes}
    build_order: List[str] = []
    
    min_heap = initial_zero_nodes
    
    # 4. Kahn's algorithm with min-heap
    while min_heap:
        curr = heapq.heappop(min_heap)
        heap_ops += 1
        build_order.append(curr)
        curr_level = level[curr]
        
        for neighbor in graph[curr]:
            edge_traversals += 1
            in_degree[neighbor] -= 1
            
            # Compute depth level
            new_level = curr_level + 1
            if new_level > level.get(neighbor, 1):
                level[neighbor] = new_level
                level_updates += 1
            
            if in_degree[neighbor] == 0:
                heapq.heappush(min_heap, neighbor)
                heap_ops += 1

    # Cycle Detection
    has_cycle = len(build_order) != len(all_packages)
    
    final_build_order = [] if has_cycle else build_order
    final_levels = -1 if has_cycle else (max(level.values()) if level else 0)

    if not return_summary:
        return final_build_order, final_levels

    # Operation Summary Computation
    total_operations = ingest_ops + heap_ops + edge_traversals + level_updates
    operation_summary = {
        "status": "CYCLE_DETECTED" if has_cycle else "SUCCESS",
        "total_operations": total_operations,
        "metrics": {
            "ingest_operations": ingest_ops,
            "heap_operations": heap_ops,
            "edge_traversals": edge_traversals,
            "level_updates": level_updates,
        },
        "graph_stats": {
            "total_packages": len(all_packages),
            "total_dependencies": len(dependencies),
        }
    }

    return final_build_order, final_levels, operation_summary


# Demonstration & Verification
if __name__ == "__main__":
    pkgs = ["A", "B", "C", "D", "E"]
    deps = [("A", "B"), ("A", "C"), ("B", "D"), ("C", "D")]

    # 1. Original behavior (return_summary=False)
    order, levels = get_deterministic_build_order(pkgs, deps)
    print("--- Default Output ---")
    print("Build Order:", order)
    print("Levels:", levels)

    # 2. Enhanced behavior with operation_summary (return_summary=True)
    order, levels, summary = get_deterministic_build_order(pkgs, deps, return_summary=True)
    print("\n--- Output with Operation Summary ---")
    print("Build Order:", order)
    print("Levels:", levels)
    print("Operation Summary:")
    for key, val in summary.items():
        print(f"  {key}: {val}")
```
