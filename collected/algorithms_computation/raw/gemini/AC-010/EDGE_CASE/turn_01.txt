### Problem Identification & Understanding

The Matrix Chain Multiplication problem aims to find the optimal order to multiply a chain of $n$ matrices $A_1, A_2, \dots, A_n$ given their dimensions $p_0, p_1, \dots, p_n$ (where matrix $A_i$ has dimensions $p_{i-1} \times p_i$). Matrix multiplication is associative, so the product order affects the total scalar multiplications required.

For two matrices of size $p_{i-1} \times p_k$ and $p_k \times p_j$, the cost to multiply them is $p_{i-1} \cdot p_k \cdot p_j$. The goal is to minimize this total scalar multiplication cost and construct the corresponding parenthesization string.

---

### Key Constraints & Required Output

* **Input:** A list or array of matrix dimension bounds $P = [p_0, p_1, \dots, p_n]$ of length $n+1$, representing $n$ matrices.
* **Tie-Breaking Constraint:** If multiple split points $k$ yield the same minimal cost, select the **smallest split index $k$**.
* **Output:**
1. The minimum total scalar multiplication cost (integer).
2. The parenthesization structure as a string (e.g., `((A1 A2) A3)` or `((A1(A2 A3))A4)`).



---

### Algorithm Overview

This problem is solved using **Interval Dynamic Programming**:

1. Define $m[i][j]$ as the minimum number of scalar multiplications needed to compute $A_i \dots A_j$ (where $1 \le i \le j \le n$).
2. Base cases: $m[i][i] = 0$ for all $1 \le i \le n$.
3. Subproblem relation: For chain length $L = 2 \dots n$ and start index $i$:

$$m[i][j] = \min_{i \le k < j} \{ m[i][k] + m[k+1][j] + p_{i-1} \cdot p_k \cdot p_j \}$$


4. Track split points: Store the optimal $k$ in $s[i][j]$. When checking candidate split points $k$, update $s[i][j]$ only if a strictly lower cost is found to naturally enforce the smallest split index tie-breaking rule.
5. Recursively reconstruct the string representation from $s[i][j]$.

---

### Deterministic Python Implementation

```python
def matrix_chain_order(p: list[int]) -> tuple[int, str]:
    """
    Computes the minimum scalar multiplication cost and parenthesization 
    for a chain of matrices defined by dimensions p.
    """
    n = len(p) - 1
    if n <= 0:
        return 0, ""
    if n == 1:
        return 0, "A1"

    # m[i][j] stores the minimum multiplication cost for A_i..A_j
    # s[i][j] stores the optimal split point k
    m = [[0] * (n + 1) for _ in range(n + 1)]
    s = [[0] * (n + 1) for _ in range(n + 1)]

    # L is the chain length
    for L in range(2, n + 1):
        for i in range(1, n - L + 2):
            j = i + L - 1
            m[i][j] = float('inf')
            
            for k in range(i, j):
                cost = m[i][k] + m[k + 1][j] + p[i - 1] * p[k] * p[j]
                
                # Use strictly less (<) to prefer the smallest split index k on equal cost
                if cost < m[i][j]:
                    m[i][j] = cost
                    s[i][j] = k

    def build_parenthesis(i: int, j: int) -> str:
        if i == j:
            return f"A{i}"
        k = s[i][j]
        left = build_parenthesis(i, k)
        right = build_parenthesis(k + 1, j)
        return f"({left}{right})"

    min_cost = m[1][n]
    parenthesization = build_parenthesis(1, n)
    return min_cost, parenthesization


# Example Usage
if __name__ == "__main__":
    dimensions = [40, 20, 30, 10, 30]
    cost, structure = matrix_chain_order(dimensions)
    print(f"Minimum Cost: {cost}")
    print(f"Optimal Structure: {structure}")

```
