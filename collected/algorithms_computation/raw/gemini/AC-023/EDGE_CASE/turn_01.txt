### Problem Identification & Understanding

The problem asks us to evaluate a dynamic graph connectivity property across multiple weight thresholds $q$. For a given undirected graph with weighted edges, we consider only those edges whose weight is less than or equal to $q$. For each threshold $q$, we need to compute:

1. The total number of connected components in the graph.
2. The size (number of vertices) of the largest connected component.

---

### Key Constraints & Required Output

* **Vertices ($V$) & Edges ($E$):** $N$ vertices, indexed from $0$ to $N-1$ (or $1$ to $N$), and $M$ weighted edges.
* **Queries ($Q$):** A list of thresholds $[q_1, q_2, \dots, q_k]$.
* **Output:** For each query threshold $q_i$, return a tuple `(num_components, max_component_size)`.

---

### Algorithm Description

Instead of constructing the graph from scratch for each query, we can process the queries efficiently in offline order using a **Disjoint Set Union (DSU) / Union-Find** data structure with path compression and union by rank/size.

1. **Sort Edges:** Sort all graph edges in non-decreasing order of their weights.
2. **Sort Queries:** Sort all query thresholds in non-decreasing order while maintaining their original indices.
3. **Incremental Union:**
* Initialize a DSU where each vertex starts as its own connected component of size 1.
* Maintain `num_components = N` and `max_component_size = 1`.
* Iterate through the sorted queries. For each threshold $q$, iteratively add and union all edges with `weight <= q`.
* When two distinct components are merged, decrease `num_components` by 1 and update `max_component_size` with the size of the newly formed component.


4. **Record Results:** Save the current state `(num_components, max_component_size)` for the query and restore the original query order before returning.

---

### Python Implementation

```python
class DisjointSetUnion:
    """Disjoint Set Union (DSU) tracking component count and max size."""
    def __init__(self, n: int):
        self.parent = list(range(n))
        self.size = [1] * n
        self.num_components = n
        self.max_component_size = 1 if n > 0 else 0

    def find(self, i: int) -> int:
        if self.parent[i] == i:
            return i
        self.parent[i] = self.find(self.parent[i])  # Path compression
        return self.parent[i]

    def union(self, i: int, j: int) -> bool:
        root_i = self.find(i)
        root_j = self.find(j)

        if root_i != root_j:
            # Union by size
            if self.size[root_i] < self.size[root_j]:
                root_i, root_j = root_j, root_i
            
            self.parent[root_j] = root_i
            self.size[root_i] += self.size[root_j]
            
            self.num_components -= 1
            if self.size[root_i] > self.max_component_size:
                self.max_component_size = self.size[root_i]
            return True
        return False


def query_components_by_threshold(n: int, edges: list[tuple[int, int, int]], queries: list[int]) -> list[tuple[int, int]]:
    """
    Evaluates graph components for each weight threshold query.
    
    :param n: Number of vertices (0 to n-1)
    :param edges: List of tuples (u, v, weight)
    :param queries: List of query thresholds q
    :return: List of tuples (num_components, max_component_size) matching query order
    """
    # Sort edges by weight
    sorted_edges = sorted(edges, key=lambda e: e[2])
    
    # Pair queries with their original indices and sort by threshold
    indexed_queries = sorted(enumerate(queries), key=lambda x: x[1])
    
    dsu = DisjointSetUnion(n)
    results = [None] * len(queries)
    
    edge_idx = 0
    num_edges = len(sorted_edges)

    for orig_idx, threshold in indexed_queries:
        # Incrementally add edges with weight <= threshold
        while edge_idx < num_edges and sorted_edges[edge_idx][2] <= threshold:
            u, v, w = sorted_edges[edge_idx]
            dsu.union(u, v)
            edge_idx += 1
        
        results[orig_idx] = (dsu.num_components, dsu.max_component_size)

    return results


# Example Usage
if __name__ == "__main__":
    n = 5
    # Edges format: (u, v, weight)
    edges = [
        (0, 1, 2),
        (1, 2, 4),
        (2, 3, 1),
        (3, 4, 5)
    ]
    queries = [0, 2, 3, 5]

    res = query_components_by_threshold(n, edges, queries)
    for q, (comps, max_size) in zip(queries, res):
        print(f"Threshold <= {q}: Components = {comps}, Max Size = {max_size}")
```
