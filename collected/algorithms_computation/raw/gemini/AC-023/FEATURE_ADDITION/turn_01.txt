### Problem Understanding

Given an undirected graph with weighted edges, we need to evaluate multiple offline queries. Each query provides a weight threshold $q$. For each threshold $q$, we form a subgraph containing only edges with weight less than or equal to $q$. For this subgraph, we must compute:

1. The total number of connected components.
2. The size of the largest connected component.

### Key Constraints & Required Output

* **Input:**
* Vertices $V$ (indexed $0$ to $n - 1$ or $1$ to $n$) and a list of weighted edges $(u, v, w)$.
* A list of queries, where each query is a weight threshold $q$.


* **Constraints:**
* Graphs can be disconnected initially; isolated vertices count as components of size 1.
* Time efficiency requires processing queries faster than recomputing components from scratch for every query.


* **Output:**
* For each query (in its original order), return a tuple `(num_components, max_component_size)`.



---

### Algorithm Description

1. **Disjoint Set Union (DSU):** Maintain component structure, component count, and component sizes dynamically.
* Initialize $n$ components, each of size 1. Track `num_components = n` and `max_size = 1` (or 0 if $n = 0$).


2. **Offline Processing (Sorting):**
* Sort all edges by weight in non-decreasing order.
* Store original query indices and sort queries by their threshold $q$ in non-decreasing order.


3. **Two-Pointer / Incremental Union:**
* Iterate through the sorted queries.
* For each query $q$, process and unite all edges with weight $w \le q$ using DSU.
* Record the current `num_components` and `max_size` for that query.


4. **Reorder Results:** Map results back to the original query order.

---

### Python 3 Implementation

```python
class DSU:
    def __init__(self, n: int):
        self.parent = list(range(n))
        self.size = [1] * n if n > 0 else []
        self.num_components = n
        self.max_size = 1 if n > 0 else 0

    def find(self, i: int) -> int:
        path = []
        while self.parent[i] != i:
            path.append(i)
            i = self.parent[i]
        for node in path:
            self.parent[node] = i
        return i

    def union(self, i: int, j: int) -> bool:
        root_i = self.find(i)
        root_j = self.find(j)

        if root_i != root_j:
            # Union by size
            if self.size[root_i] < self.size[root_j]:
                root_i, root_j = root_j, root_i
            
            self.parent[root_j] = root_i
            self.size[root_i] += self.size[root_j]
            
            if self.size[root_i] > self.max_size:
                self.max_size = self.size[root_i]
                
            self.num_components -= 1
            return True
        return False


def analyze_graph_thresholds(
    n: int, 
    edges: list[tuple[int, int, float]], 
    queries: list[float]
) -> list[tuple[int, int]]:
    """
    Evaluates connected components and maximum component size for edge weight thresholds.

    :param n: Number of vertices (0 to n-1)
    :param edges: List of tuples (u, v, weight)
    :param queries: List of weight thresholds q
    :return: List of tuples (num_components, max_component_size) corresponding to each query
    """
    # Sort edges by weight
    sorted_edges = sorted(edges, key=lambda x: x[2])
    
    # Store queries with their original indices and sort by threshold q
    sorted_queries = sorted(enumerate(queries), key=lambda x: x[1])
    
    dsu = DSU(n)
    results = [(0, 0)] * len(queries)
    
    edge_idx = 0
    num_edges = len(sorted_edges)
    
    for original_idx, q in sorted_queries:
        # Add all edges with weight <= q
        while edge_idx < num_edges and sorted_edges[edge_idx][2] <= q:
            u, v, w = sorted_edges[edge_idx]
            dsu.union(u, v)
            edge_idx += 1
            
        results[original_idx] = (dsu.num_components, dsu.max_size)
        
    return results


# Example Usage
if __name__ == "__main__":
    num_nodes = 5
    # Edges: (u, v, weight)
    graph_edges = [
        (0, 1, 3.0),
        (1, 2, 1.0),
        (2, 3, 5.0),
        (3, 4, 2.0)
    ]
    # Threshold queries
    thresholds = [0.5, 1.5, 3.0, 5.0]
    
    ans = analyze_graph_thresholds(num_nodes, graph_edges, thresholds)
    for q, res in zip(thresholds, ans):
        print(f"Threshold q = {q}: {res[0]} components, max size = {res[1]}")
```
