### Problem & Requirements

Given an undirected graph with $n$ vertices (labeled 0 to $n-1$) and weighted edges, along with a list of weight thresholds, we need to answer $q$ queries offline:
For each weight threshold $Q$, consider only graph edges with weight $\le Q$. We must determine:

1. The total number of connected components.
2. The size of the largest connected component.

**Key Constraints:**

* The graph has $n$ vertices.
* Offline queries: Queries can be processed in any convenient order.

**Required Output:**
For each query threshold, return a tuple or pair `(number_of_components, max_component_size)`.

---

### Approach & Algorithm

1. **Disjoint Set Union (DSU):**
* Maintain a DSU data structure tracking parent pointers, size of each component, total number of components (initially $n$), and the size of the largest component (initially 1 for $n \ge 1$).
* When unioning two components of sizes $S_1$ and $S_2$, the new component size is $S_1 + S_2$. Decrement the component count by 1 and update `max_component_size = max(max_component_size, S_1 + S_2)`.


2. **Offline Processing (Two Pointers / Sorting):**
* Sort all edges in non-decreasing order of weight.
* Pair each query threshold with its original index and sort queries in non-decreasing order of threshold weight.
* Iterate through sorted queries. For each query threshold $Q$, incrementally add and union all edges with weight $\le Q$.
* Record the DSU state `(num_components, max_size)` for that query index.
* Re-sort the recorded answers by original query indices to return them in the input order.



---

### Python Solution

```python
class UnionFind:
    def __init__(self, n: int):
        self.parent = list(range(n))
        self.size = [1] * n
        self.num_components = n
        self.max_size = 1 if n > 0 else 0

    def find(self, i: int) -> int:
        if self.parent[i] == i:
            return i
        self.parent[i] = self.find(self.parent[i])
        return self.parent[i]

    def union(self, i: int, j: int) -> None:
        root_i = self.find(i)
        root_j = self.find(j)
        
        if root_i != root_j:
            # Union by size
            if self.size[root_i] < self.size[root_j]:
                root_i, root_j = root_j, root_i
            
            self.parent[root_j] = root_i
            self.size[root_i] += self.size[root_j]
            
            self.num_components -= 1
            if self.size[root_i] > self.max_size:
                self.max_size = self.size[root_i]


def component_stats_per_threshold(n: int, edges: list[tuple[int, int, int]], queries: list[int]) -> list[tuple[int, int]]:
    """
    n: number of vertices (0 to n-1)
    edges: list of tuples (u, v, weight)
    queries: list of weight thresholds Q

    Returns:
    List of tuples (num_components, max_component_size) for each query in original order.
    """
    # Sort edges by weight
    sorted_edges = sorted(edges, key=lambda e: e[2])
    
    # Sort queries keeping track of original indices
    indexed_queries = sorted(enumerate(queries), key=lambda x: x[1])
    
    uf = UnionFind(n)
    ans = [(0, 0)] * len(queries)
    
    edge_idx = 0
    num_edges = len(sorted_edges)
    
    for original_idx, q_val in indexed_queries:
        # Add all edges with weight <= threshold q_val
        while edge_idx < num_edges and sorted_edges[edge_idx][2] <= q_val:
            u, v, w = sorted_edges[edge_idx]
            uf.union(u, v)
            edge_idx += 1
            
        ans[original_idx] = (uf.num_components, uf.max_size)
        
    return ans

```
