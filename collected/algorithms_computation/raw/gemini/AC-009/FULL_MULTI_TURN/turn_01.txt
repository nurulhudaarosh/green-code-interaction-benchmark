### Problem Identification & Understanding

The problem asks us to find the minimum number of coins required to sum up to a specified target amount, given a set of available coin denominations. Coins of each denomination can be used an unlimited number of times. Along with the minimum count, we must return the actual combination of coins used. If the target amount cannot be formed by any combination of the given denominations, we must return a count of `-1` and an empty list `[]`.

---

### Key Constraints & Required Output

* **Inputs:**
* `coins`: A list of positive integers representing available coin denominations.
* `amount`: A non-negative integer target sum.


* **Constraints:**
* Unlimited supply for each coin denomination.
* If `amount == 0`, the output requires 0 coins and an empty list `[]`.
* Deterministic reconstruction: When multiple combinations yield the minimum coin count, choose a deterministic tie-breaker (e.g., preference for larger or smaller coins).


* **Output:**
* A tuple `(min_coins, combination)` where:
* `min_coins` is an integer representing the minimum number of coins needed (or `-1` if impossible).
* `combination` is a list of integers representing the specific coins used (or `[]` if impossible).





---

### Algorithm Description

We use **1D Dynamic Programming (Unbounded Coin Change)** paired with **Deterministic Path Reconstruction**:

1. **DP Array Setup:** Maintain an array `dp` of size `amount + 1` initialized to infinity ($\infty$), where `dp[i]` stores the minimum number of coins needed to make amount `i`. Set `dp[0] = 0`.
2. **Parent Tracking Array:** Maintain a parallel array `parent` of size `amount + 1` initialized to `-1` to keep track of the coin denomination used to reach each amount `i`.
3. **State Transitions:** Iteratively compute values for $i$ from $1$ to $\text{amount}$. For each coin denomination $c \le i$:
* If $\text{dp}[i - c] + 1 < \text{dp}[i]$, update $\text{dp}[i] = \text{dp}[i - c] + 1$ and set $\text{parent}[i] = c$.
* *Determinism:* Sorting the coin denominations ensures consistent and deterministic tie-breaking when multiple coin choices lead to the same minimum count.


4. **Reconstruction:** If `dp[amount]` remains $\infty$, return `(-1, [])`. Otherwise, start at `curr = amount` and trace back using `parent[curr]`, appending the coin values to a list until `curr == 0`.

---

### Python Solution

```python
def min_coin_change(coins: list[int], amount: int) -> tuple[int, list[int]]:
    """
    Finds the minimum number of coins to reach a target amount and returns both
    the count and the exact combination of coins used.
    
    Returns:
        tuple[int, list[int]]: (min_coin_count, list_of_coins_used)
    """
    if amount < 0:
        return -1, []
    if amount == 0:
        return 0, []
    
    # Filter non-positive coins and sort for deterministic behavior
    valid_coins = sorted([c for c in coins if c > 0])
    if not valid_coins:
        return -1, []

    # dp[i] holds the minimum number of coins needed for amount i
    dp = [float('inf')] * (amount + 1)
    # parent[i] holds the coin used to reach amount i
    parent = [-1] * (amount + 1)
    
    dp[0] = 0

    for i in range(1, amount + 1):
        for coin in valid_coins:
            if coin > i:
                break  # Since valid_coins is sorted, no larger coin can fit
            if dp[i - coin] + 1 < dp[i]:
                dp[i] = dp[i - coin] + 1
                parent[i] = coin

    # If amount cannot be reached
    if dp[amount] == float('inf'):
        return -1, []

    # Reconstruct the optimal combination
    combination = []
    curr = amount
    while curr > 0:
        coin_used = parent[curr]
        combination.append(coin_used)
        curr -= coin_used

    return int(dp[amount]), combination


# Example Usage
if __name__ == "__main__":
    sample_coins = [1, 2, 5]
    sample_amount = 11
    count, combination = min_coin_change(sample_coins, sample_amount)
    print(f"Amount: {sample_amount}")
    print(f"Minimum Coins: {count}")
    print(f"Combination: {combination}")

```
