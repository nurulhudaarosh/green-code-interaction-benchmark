### Problem & Key Constraints

The goal is to solve the Travelling Salesperson Problem (TSP) on a complete symmetric distance graph with up to 14 cities (indexed $0$ to $N-1$).

* **Graph:** Complete, undirected/symmetric matrix $D$, where $D[i][j]$ is the distance between city $i$ and city $j$.
* **Route:** Must start at city 0, visit every other city exactly once, and return to city 0 (a Hamiltonian cycle).
* **Objective:** Find a route with the minimum total edge weight.
* **Tie-Breaking Rule:** When multiple paths yield the same minimum cost, break ties deterministically by preferring the path with the smaller predecessor at each step during path reconstruction.
* **Required Output:** Total minimum tour length and the sequence of cities visited (starting and ending at $0$).

---

### Algorithm Description

We use the **Held-Karp Dynamic Programming algorithm**, which runs in $O(N^2 \cdot 2^N)$ time and $O(N \cdot 2^N)$ space—optimal for $N \le 14$.

1. **State Representation:**
Let $\text{dp}[S][u]$ be the minimum cost to start at city 0, visit all cities in the bitmask subset $S$, and end at city $u \in S$. Here, $S$ is a bitmask where the $i$-th bit is 1 if city $i$ has been visited.
2. **Base Case:**
* For subset $S = \{0\} = 1 \ll 0$, set $\text{dp}[1][0] = 0$.
* All other states are initialized to $\infty$.


3. **Transitions:**
* Iterate through all subset sizes $k = 2 \dots N$, and for each bitmask $S$ containing city 0:
* For each target city $v \in S$ ($v \neq 0$):

$$\text{dp}[S][v] = \min_{u \in S \setminus \{v\}} \left( \text{dp}[S \setminus \{v\}][u] + D[u][v] \right)$$




4. **Optimal Tour Value:**
* The minimum total cost is:

$$\text{Cost} = \min_{u \neq 0} \left( \text{dp}[(1 \ll N) - 1][u] + D[u][0] \right)$$




5. **Path Reconstruction with Tie-Breaking:**
* Track the predecessor `parent[S][u]` that yielded the optimal cost for state $(S, u)$.
* When evaluating candidate predecessors $u$, if costs are tied, choose the predecessor with the smaller index $u$.



---

### Deterministic Python Implementation

```python
def solve_tsp(dist_matrix):
    """
    Solves the TSP using Held-Karp Dynamic Programming.
    
    :param dist_matrix: List[List[int/float]], symmetric matrix of sizes N x N (N <= 14).
    :return: Tuple (min_cost, path) where path is a list of city indices starting and ending at 0.
    """
    N = len(dist_matrix)
    if N == 0:
        return 0, []
    if N == 1:
        return 0, [0, 0]

    num_states = 1 << N
    INF = float('inf')

    # dp[S][u] = min cost to start at 0, visit all cities in bitmask S, ending at u
    dp = [[INF] * N for _ in range(num_states)]
    # parent[S][u] stores predecessor of u in subset S for path reconstruction
    parent = [[-1] * N for _ in range(num_states)]

    # Base case: starting at city 0
    dp[1][0] = 0

    # Iterate over all subset sizes from 2 to N
    for size in range(2, N + 1):
        for S in range(1, num_states):
            # Must include city 0 and match current size
            if not (S & 1) or bin(S).count('1') != size:
                continue

            # Target last city v in subset S (v != 0)
            for v in range(1, N):
                if not (S & (1 << v)):
                    continue

                prev_S = S ^ (1 << v)
                best_cost = INF
                best_pred = -1

                # Search for best predecessor u in prev_S
                for u in range(N):
                    if prev_S & (1 << u):
                        cost = dp[prev_S][u] + dist_matrix[u][v]
                        # Tie-breaking: strict < naturally prefers smaller u when iterating 0..N-1
                        if cost < best_cost:
                            best_cost = cost
                            best_pred = u

                dp[S][v] = best_cost
                parent[S][v] = best_pred

    # Complete the cycle by returning to city 0 from the last city u
    full_mask = num_states - 1
    min_total_cost = INF
    last_city = -1

    for u in range(1, N):
        cost = dp[full_mask][u] + dist_matrix[u][0]
        if cost < min_total_cost:
            min_total_cost = cost
            last_city = u

    # Reconstruct the path backwards
    path = []
    curr_mask = full_mask
    curr_city = last_city

    while curr_city != -1:
        path.append(curr_city)
        next_city = parent[curr_mask][curr_city]
        curr_mask ^= (1 << curr_city)
        curr_city = next_city

    path.reverse()
    path.append(0)  # Close the loop at city 0

    return min_total_cost, path


# Example Usage:
if __name__ == "__main__":
    # Sample symmetric 4-city distance matrix
    dist = [
        [0, 10, 15, 20],
        [10, 0, 35, 25],
        [15, 35, 0, 30],
        [20, 25, 30, 0]
    ]

    min_cost, tour = solve_tsp(dist)
    print(f"Minimum Tour Cost: {min_cost}")
    print(f"Optimal Path: {' -> '.join(map(str, tour))}")

```
