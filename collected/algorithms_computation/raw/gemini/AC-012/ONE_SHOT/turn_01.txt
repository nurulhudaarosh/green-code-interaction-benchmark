### Problem Definition

Given two strings $S_1$ and $S_2$, we need to find:

1. The length of the Longest Common Subsequence (LCS).
2. A single reconstructed LCS string determined by a deterministic tie-breaking rule: when dynamic programming (DP) values for multiple transitions are equal, the reconstruction step must prefer advancing in $S_1$ (i.e., taking the transition that decrements/increments the index in $S_1$).

### Key Constraints & Required Output

* **Time Complexity:** $O(\vert{}S_1\vert{} \cdot \vert{}S_2\vert{})$ time.
* **Space Complexity:** $O(\vert{}S_1\vert{} \cdot \vert{}S_2\vert{})$ space to hold the DP table for reconstruction.
* **Tie-Breaking Rule:** When computing or backtracking, if moving along $S_1$ or $S_2$ yields the exact same DP score for an optimal path, prefer moving along $S_1$.
* **Output:** A tuple/pair containing `(lcs_length, lcs_string)`.

---

### Algorithm Description

1. **DP Table Construction:**
Define `dp[i][j]` as the length of the LCS of prefixes $S_1[0 \dots i-1]$ and $S_2[0 \dots j-1]$.
* If $S_1[i-1] == S_2[j-1]$, then `dp[i][j] = dp[i-1][j-1] + 1`.
* Otherwise, `dp[i][j] = max(dp[i-1][j], dp[i][j-1])`.


2. **Deterministic Backtracking:**
Start at indices $(i, j) = (\vert{}S_1\vert{}, \vert{}S_2\vert{})$ and backtrack toward $(0, 0)$:
* If $S_1[i-1] == S_2[j-1]$, the current character belongs to the LCS. Append $S_1[i-1]$, and transition to $(i-1, j-1)$.
* Otherwise, if $S_1[i-1] \neq S_2[j-1]$:
* Check if `dp[i-1][j] >= dp[i][j-1]`.
* If true (including equality), prefer moving in $S_1$ by transitioning to $(i-1, j)$.
* Otherwise, transition to $(i, j-1)$.




3. **Reconstruction:** Reverse the collected characters to get the final LCS string.

---

### Python Solution

```python
def solve_lcs(s1: str, s2: str) -> tuple[int, str]:
    """
    Computes the LCS length and reconstructs a deterministic LCS string.
    Prefers advancing (decrementing index) in s1 on equal DP scores.
    """
    m, n = len(s1), len(s2)
    
    # Initialize DP table of size (m+1) x (n+1)
    dp = [[0] * (n + 1) for _ in range(m + 1)]
    
    # Fill DP table
    for i in range(1, m + 1):
        for j in range(1, n + 1):
            if s1[i - 1] == s2[j - 1]:
                dp[i][j] = dp[i - 1][j - 1] + 1
            else:
                dp[i][j] = max(dp[i - 1][j], dp[i][j - 1])
                
    lcs_length = dp[m][n]
    
    # Backtrack to reconstruct the sequence
    i, j = m, n
    lcs_chars = []
    
    while i > 0 and j > 0:
        if s1[i - 1] == s2[j - 1]:
            lcs_chars.append(s1[i - 1])
            i -= 1
            j -= 1
        # Tie-breaking rule: prefer s1 (i-1) if scores are equal
        elif dp[i - 1][j] >= dp[i][j - 1]:
            i -= 1
        else:
            j -= 1
            
    lcs_string = "".join(reversed(lcs_chars))
    return lcs_length, lcs_string


# --- Verification Example ---
if __name__ == "__main__":
    string1 = "ABCDGH"
    string2 = "AEDFHR"
    length, res = solve_lcs(string1, string2)
    print(f"LCS Length: {length}")
    print(f"Reconstructed LCS: {res}")
```
