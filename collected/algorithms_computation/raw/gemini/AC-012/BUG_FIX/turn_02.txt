### Problem Restatement & Expected Behavior

**Problem:** Given two strings $S_1$ and $S_2$, compute the length of their Longest Common Subsequence (LCS) and reconstruct one LCS string deterministically.

**Expected Tie-Handling Behavior:**
When choosing between moving in $S_1$ ($i - 1$) vs. moving in $S_2$ ($j - 1$) during reconstruction when the characters do not match and scores are equal (`dp[i-1][j] == dp[i][j-1]`), the backtracking procedure must prefer advancing in $S_1$ (decrementing $i$).

---

### Demonstrating the Bug

In the previous implementation, the condition during forward DP generation was:



When $S_1[i-1] == S_2[j-1]$, the DP table was directly taking `dp[i-1][j-1] + 1` without checking if a non-matching path from `dp[i-1][j]` or `dp[i][j-1]` yielded an equal score.

If `dp[i-1][j] == dp[i-1][j-1] + 1`, a match occurs at $S_1[i-1] == S_2[j-1]$, but the tie-breaking rule specifies that when DP scores are equal, we **must prefer advancing in $S_1$** (moving $i \to i-1$) over taking the diagonal matching step if they yield equal optimal scores.

#### Example:

Consider $S_1 = \text{"ABA"}$ and $S_2 = \text{"BA"}$.

* DP table matrix ($4 \times 3$):
* `dp[3][2]` (at $S_1[2] = \text{'A'}$ and $S_2[1] = \text{'A'}$):
* Diagonal match gives score $1 + \text{dp}[2][1] = 1 + 1 = 2$.
* Moving up ($i-1$) to `dp[2][2]` gives score $2$ (since "AB" and "BA" have LCS length 2).




* **Defect:** Standard backtracking checks `s1[i-1] == s2[j-1]` first and immediately takes the diagonal step, ignoring the fact that moving up (`dp[i-1][j] == dp[i][j]`) has an equal score. To strictly respect "prefer advancing in $S_1$ on equal DP scores," moving up ($i \to i-1$) must take precedence.

---

### Corrected Implementation

To strictly enforce the deterministic rule—preferring $i \to i-1$ whenever `dp[i-1][j] == dp[i][j]`— we check if moving up in $S_1$ preserves the optimal score **before** taking the character match transition.

```python
def lcs_with_reconstruction(s1: str, s2: str) -> tuple[int, str]:
    m, n = len(s1), len(s2)
    
    # Step 1: Compute standard DP table
    dp = [[0] * (n + 1) for _ in range(m + 1)]
    
    for i in range(1, m + 1):
        for j in range(1, n + 1):
            if s1[i - 1] == s2[j - 1]:
                dp[i][j] = dp[i - 1][j - 1] + 1
            else:
                dp[i][j] = max(dp[i - 1][j], dp[i][j - 1])
                
    lcs_length = dp[m][n]
    
    # Step 2: Backtrack with strict precedence:
    # 1. Prefer advancing in s1 (i -> i - 1) if dp[i - 1][j] == dp[i][j]
    # 2. Otherwise, match characters if s1[i - 1] == s2[j - 1]
    # 3. Otherwise, advance in s2 (j -> j - 1)
    i, j = m, n
    lcs_chars = []
    
    while i > 0 and j > 0:
        if dp[i - 1][j] == dp[i][j]:
            # Deterministic rule: prefer advancing in s1 on equal scores
            i -= 1
        elif s1[i - 1] == s2[j - 1]:
            # Match character and move diagonally
            lcs_chars.append(s1[i - 1])
            i -= 1
            j -= 1
        else:
            # Advance in s2
            j -= 1
            
    lcs_string = "".join(reversed(lcs_chars))
    return lcs_length, lcs_string


# Demonstration
if __name__ == "__main__":
    s1, s2 = "ABA", "BA"
    length, res = lcs_with_reconstruction(s1, s2)
    print(f"S1: {s1}, S2: {s2}")
    print(f"LCS Length: {length}")
    print(f"Reconstructed LCS: {res}")

```
