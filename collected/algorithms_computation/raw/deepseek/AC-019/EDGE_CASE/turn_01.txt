## Problem Identification and Understanding

**Problem:** Given a non-negative cost matrix, find the minimum cost path from the top-left corner to the bottom-right corner, moving only right or down. Return both the minimum cost and one deterministic optimal path.

**Key Constraints:**
- Movement allowed: only right or down
- Matrix contains non-negative costs
- Must handle ties deterministically (e.g., prefer "up" over "left" when costs are equal)
- Path should be one valid optimal path (not necessarily unique)

**Required Output:**
1. Minimum total cost
2. One optimal path as a sequence of coordinates

**Algorithm Description:**
1. Use dynamic programming where `dp[i][j]` represents the minimum cost to reach cell `(i,j)`
2. Initialize first row and column (only one way to reach them)
3. For each cell, choose the minimum between coming from above or from the left
4. Store predecessor coordinates for path reconstruction
5. For deterministic tie handling: when costs are equal, prefer coming from above (up)
6. Reconstruct path by backtracking from bottom-right to top-left

**Time Complexity:** O(m×n)  
**Space Complexity:** O(m×n)

## Python Implementation

```python
def find_min_cost_path(cost_matrix):
    """
    Find minimum cost path from top-left to bottom-right in a cost matrix.
    Movement allowed: only right or down.
    
    Args:
        cost_matrix: 2D list of non-negative integers
        
    Returns:
        tuple: (minimum_cost, optimal_path)
        where optimal_path is a list of (row, col) tuples
    """
    if not cost_matrix or not cost_matrix[0]:
        return 0, []
    
    rows = len(cost_matrix)
    cols = len(cost_matrix[0])
    
    # Handle single cell case
    if rows == 1 and cols == 1:
        return cost_matrix[0][0], [(0, 0)]
    
    # Initialize DP table and predecessor tracking
    dp = [[0] * cols for _ in range(rows)]
    # predecessor[i][j] stores (prev_row, prev_col) or None for start
    predecessor = [[None] * cols for _ in range(rows)]
    
    # Base case: starting position
    dp[0][0] = cost_matrix[0][0]
    
    # Initialize first row (can only come from left)
    for j in range(1, cols):
        dp[0][j] = dp[0][j-1] + cost_matrix[0][j]
        predecessor[0][j] = (0, j-1)
    
    # Initialize first column (can only come from above)
    for i in range(1, rows):
        dp[i][0] = dp[i-1][0] + cost_matrix[i][0]
        predecessor[i][0] = (i-1, 0)
    
    # Fill the rest of the DP table
    for i in range(1, rows):
        for j in range(1, cols):
            cost_from_above = dp[i-1][j]
            cost_from_left = dp[i][j-1]
            
            # Deterministic tie handling: prefer coming from above (up)
            if cost_from_above <= cost_from_left:
                dp[i][j] = cost_from_above + cost_matrix[i][j]
                predecessor[i][j] = (i-1, j)
            else:
                dp[i][j] = cost_from_left + cost_matrix[i][j]
                predecessor[i][j] = (i, j-1)
    
    # Reconstruct path by backtracking
    path = []
    current = (rows - 1, cols - 1)
    
    while current is not None:
        path.append(current)
        current = predecessor[current[0]][current[1]]
    
    # Reverse path to get from start to end
    path.reverse()
    
    return dp[rows-1][cols-1], path


def print_matrix_and_path(cost_matrix, min_cost, path):
    """Helper function to visualize the result."""
    print("Cost Matrix:")
    for row in cost_matrix:
        print("  ", row)
    
    print(f"\nMinimum Cost: {min_cost}")
    print(f"Path: {' -> '.join(f'({r},{c})' for r, c in path)}")
    
    # Show path values
    path_values = [cost_matrix[r][c] for r, c in path]
    print(f"Path values: {' + '.join(map(str, path_values))} = {sum(path_values)}")
```

## Explanation of Key Design Decisions

1. **Predecessor tracking:** Instead of storing the entire path in each DP cell, we store only the predecessor coordinates. This saves memory and makes reconstruction straightforward.

2. **Deterministic tie handling:** When `cost_from_above <= cost_from_left`, we choose the path from above. This ensures that for any matrix with ties, the algorithm always produces the same path.

3. **Edge cases:** The solution handles:
   - Empty matrix
   - Single row/column
   - Single cell

4. **Path reconstruction:** We backtrack from bottom-right to top-left using the predecessor table, then reverse the result.

5. **No external dependencies:** Uses only Python's standard library (no imports needed).

The solution is deterministic, meaning the same input always produces the same output, including which optimal path is selected when multiple paths have the same minimum cost.
