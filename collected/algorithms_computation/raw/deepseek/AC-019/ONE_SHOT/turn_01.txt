## Problem Identification

**Problem:** Given a non-negative cost matrix, find the minimum cost path from the top-left cell (0,0) to the bottom-right cell (m-1, n-1), moving only right or down. Return both the minimum cost and one deterministic optimal path.

**Key Constraints:**
- Movement allowed only right or down
- Cost matrix contains non-negative values
- Must return one deterministic optimal path (consistent tie-breaking)
- Path must start at (0,0) and end at (m-1, n-1)

**Required Output:**
1. Minimum total cost
2. One optimal path as a list of coordinates

**Algorithm:**
- Use dynamic programming where `dp[i][j]` represents minimum cost to reach cell (i,j)
- Store predecessor coordinates for path reconstruction
- Handle ties deterministically (prefer up/left based on fixed rule)

## Python Implementation

```python
def min_cost_path(cost_matrix):
    """
    Find minimum cost path from top-left to bottom-right moving only right or down.
    Returns (min_cost, path) where path is list of (row, col) tuples.
    """
    if not cost_matrix or not cost_matrix[0]:
        return 0, []
    
    m, n = len(cost_matrix), len(cost_matrix[0])
    
    # dp[i][j] = minimum cost to reach cell (i, j)
    dp = [[0] * n for _ in range(m)]
    
    # predecessor[i][j] = (prev_i, prev_j) or None for start
    predecessor = [[None] * n for _ in range(m)]
    
    # Initialize first cell
    dp[0][0] = cost_matrix[0][0]
    
    # Initialize first row (can only come from left)
    for j in range(1, n):
        dp[0][j] = dp[0][j-1] + cost_matrix[0][j]
        predecessor[0][j] = (0, j-1)
    
    # Initialize first column (can only come from above)
    for i in range(1, m):
        dp[i][0] = dp[i-1][0] + cost_matrix[i][0]
        predecessor[i][0] = (i-1, 0)
    
    # Fill the rest of the DP table
    for i in range(1, m):
        for j in range(1, n):
            from_top = dp[i-1][j]
            from_left = dp[i][j-1]
            
            # Deterministic tie-breaking: prefer from_top when equal
            # (This choice is arbitrary but must be consistent)
            if from_top <= from_left:
                dp[i][j] = from_top + cost_matrix[i][j]
                predecessor[i][j] = (i-1, j)
            else:
                dp[i][j] = from_left + cost_matrix[i][j]
                predecessor[i][j] = (i, j-1)
    
    # Reconstruct path from bottom-right to top-left
    path = []
    current = (m-1, n-1)
    
    while current is not None:
        path.append(current)
        current = predecessor[current[0]][current[1]]
    
    # Reverse to get path from start to end
    path.reverse()
    
    return dp[m-1][n-1], path


def print_matrix_and_path(cost_matrix, min_cost, path):
    """Helper to visualize the matrix and path."""
    print("Cost Matrix:")
    for row in cost_matrix:
        print("  ", row)
    
    print(f"\nMinimum Cost: {min_cost}")
    print(f"Optimal Path: {path}")
    
    # Create a visual representation of the path
    m, n = len(cost_matrix), len(cost_matrix[0])
    path_set = set(path)
    
    print("\nPath visualization (X = path cell):")
    for i in range(m):
        row_str = "  "
        for j in range(n):
            if (i, j) in path_set:
                row_str += f"[{cost_matrix[i][j]:2d}]"
            else:
                row_str += f" {cost_matrix[i][j]:2d} "
        print(row_str)
```

## Algorithm Explanation

1. **DP Table Construction:**
   - `dp[i][j]` stores the minimum cost to reach cell (i,j) from (0,0)
   - `predecessor[i][j]` stores which cell we came from to reach (i,j)

2. **Base Cases:**
   - Start cell: `dp[0][0] = cost_matrix[0][0]`
   - First row: can only come from left
   - First column: can only come from above

3. **Recurrence Relation:**
   - For cell (i,j), we can come from either:
     - Top: `dp[i-1][j]`
     - Left: `dp[i][j-1]`
   - Choose the minimum, add current cell's cost

4. **Deterministic Tie Handling:**
   - When `from_top == from_left`, we consistently choose `from_top`
   - This ensures the same path is returned for identical inputs

5. **Path Reconstruction:**
   - Start from bottom-right cell
   - Follow predecessor pointers back to start
   - Reverse the path to get start-to-end order

**Time Complexity:** O(m × n)  
**Space Complexity:** O(m × n) for DP table and predecessor tracking

The solution is deterministic, uses only standard library, and handles all edge cases including single cells, 1×N, and N×1 matrices.
