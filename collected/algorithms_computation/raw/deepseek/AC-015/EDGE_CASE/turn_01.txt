## Problem Identification and Understanding

**Problem:** Given a directed capacitated network (a directed graph where each edge has a non-negative capacity), compute the **maximum s-t flow** from a source vertex `s` to a sink vertex `t`, and report the flow on each **original edge**.

**Key Constraints:**
1. The graph is **directed** and each edge has a non-negative integer capacity.
2. Flow conservation must hold at every vertex except `s` and `t`.
3. For each edge `(u, v)`: `0 ≤ flow(u, v) ≤ capacity(u, v)`.
4. Anti-parallel edges must be handled correctly (they need separate edge objects; using a single residual edge pair per original edge is not sufficient when both `(u,v)` and `(v,u)` exist).
5. The output must preserve the **original edge order** as given in the input.

**Required Output:**
- The value of the maximum flow.
- The flow on each original edge, in the same order as the input.

**Algorithm:** Dinic's blocking-flow algorithm.
- Uses BFS to build a level graph (shortest-distance layers from `s`).
- Uses DFS to find blocking flows within the level graph, with the `iter` pointer to avoid re-scanning dead edges.
- Repeats until `t` is unreachable in the residual graph.
- Time complexity: `O(V² · E)` general; `O(E·√V)` for unit-capacity networks.

**Anti-parallel handling:** Each original edge gets its own residual pair, so `(u,v)` and `(v,u)` coexist without conflicting. The residual edge stores a reference to the original edge's index so we can report the original flow as `capacity - residual_capacity`.

## Python Implementation

```python
import sys
from collections import deque

INF = float('inf')


class Dinic:
    def __init__(self, n):
        self.n = n
        self.graph = [[] for _ in range(n)]
        # Each entry: [to, cap, rev_index, orig_edge_id]
        # orig_edge_id = -1 for reverse edges, >= 0 for forward edges
        self.orig_caps = []   # capacity of each original edge
        self.orig_edges = []  # (u, v, edge_ref) for each original edge

    def add_edge(self, u, v, cap, orig_id):
        """Add an original edge u->v with capacity cap and id orig_id."""
        fwd = [v, cap, len(self.graph[v]), orig_id]
        rev = [u, 0,   len(self.graph[u]), -1]
        self.graph[u].append(fwd)
        self.graph[v].append(rev)

    def bfs(self, s, t):
        self.level = [-1] * self.n
        self.level[s] = 0
        q = deque([s])
        while q:
            u = q.popleft()
            for to, cap, rev, _ in self.graph[u]:
                if cap > 0 and self.level[to] < 0:
                    self.level[to] = self.level[u] + 1
                    q.append(to)
        return self.level[t] >= 0

    def dfs(self, u, t, f):
        if u == t:
            return f
        while self.iter[u] < len(self.graph[u]):
            e = self.graph[u][self.iter[u]]
            to, cap, rev, _ = e
            if cap > 0 and self.level[to] == self.level[u] + 1:
                d = self.dfs(to, t, min(f, cap))
                if d > 0:
                    e[1] -= d
                    self.graph[to][rev][1] += d
                    return d
            self.iter[u] += 1
        return 0

    def max_flow(self, s, t):
        flow = 0
        while self.bfs(s, t):
            self.iter = [0] * self.n
            while True:
                f = self.dfs(s, t, INF)
                if f == 0:
                    break
                flow += f
        return flow


def solve(n, edges, s, t):
    """
    n: number of vertices (0-indexed)
    edges: list of (u, v, capacity)
    s, t: source and sink
    Returns: (max_flow_value, [flow_on_each_original_edge_in_order])
    """
    din = Dinic(n)
    for idx, (u, v, cap) in enumerate(edges):
        din.add_edge(u, v, cap, idx)
        din.orig_caps.append(cap)
        din.orig_edges.append((u, v))

    maxflow = din.max_flow(s, t)

    # Recover flow on each original edge: flow = capacity - remaining_residual_capacity
    result = []
    for idx in range(len(edges)):
        u = din.orig_edges[idx][0]
        # Find the forward edge object with orig_id == idx
        found = None
        for e in din.graph[u]:
            if e[3] == idx:
                found = e
                break
        assert found is not None, f"Original edge {idx} not found"
        remaining = found[1]
        result.append(din.orig_caps[idx] - remaining)

    return maxflow, result


def main():
    data = sys.stdin.read().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))
    s = int(next(it))
    t = int(next(it))
    edges = []
    for _ in range(m):
        u = int(next(it))
        v = int(next(it))
        c = int(next(it))
        edges.append((u, v, c))

    maxflow, flows = solve(n, edges, s, t)
    print(maxflow)
    for f in flows:
        print(f)


if __name__ == "__main__":
    main()
```

**Input (stdin):**
```
n m s t

```

**Output (stdout):**
```

<flow_on_edge_1>

<flow_on_edge_m>
```

## Example

**Input:**
```
4 5 0 3
0 1 3
0 2 2
1 2 1
1 3 2
2 3 4
```

**Output:**
```
5
3
2
1
2
3
```

**Verification:**
- Max flow = 5.
- Edges in order: `0→1` carries 3, `0→2` carries 2, `1→2` carries 1, `1→3` carries 2, `2→3` carries 3.
- Flow conservation at vertex 1: inflow = 3 (from 0→1), outflow = 1 (1→2) + 2 (1→3) = 3 ✓
- Flow conservation at vertex 2: inflow = 2 (0→2) + 1 (1→2) = 3, outflow = 3 (2→3) ✓
- Sink inflow: 2 (1→3) + 3 (2→3) = 5 = source outflow 3 + 2 = 5 ✓
- All flows within capacities ✓

## Notes on Correctness and Determinism

1. **Determinism:** No randomness, no hash-order dependence (`iter` pointers walk adjacency lists in insertion order), no external calls.
2. **Anti-parallel edges:** Each original edge has its own forward/backward residual pair, so `(u,v)` and `(v,u)` never interfere.
3. **Self-loops** are harmless (capacity stays in residual, DFS never takes them because level condition fails).
4. **Original edge order preserved:** Each forward residual edge stores its `orig_id`, and we read flows back in index order.
5. **Complexity:** Dinic runs in `O(V²E)` worst case; fine for typical judge constraints (e.g., `V ≤ 500`, `E ≤ 10⁴`).
