# Maximum s-t Flow via Dinic's Algorithm

## Problem Identification

**Given:**
- A directed graph with `n` nodes and `m` directed edges
- Each edge `(u, v)` has a non-negative integer capacity `cap`
- A source node `s` and sink node `t`

**Goal:**
1. Compute the **maximum flow** value from `s` to `t`
2. Report the **flow on each original edge** in the **original input order**

**Key Constraints:**
- Flow conservation: for every node except `s` and `t`, inflow = outflow
- Capacity constraint: `0 ≤ flow(e) ≤ cap(e)` for every edge
- Skew symmetry (in residual network): `flow(u,v) = -flow(v,u)`
- Output must preserve original edge ordering
- Deterministic (no randomness), standard library only

**Required Output:**
- First line: the maximum flow value
- Following `m` lines: the flow value on each original edge, in input order

---

## Algorithm: Dinic's Blocking-Flow

**Why Dinic's?** It runs in `O(V²E)` (general) and `O(E√V)` (unit-capacity networks), which is efficient and deterministic — unlike Ford–Fulkerson with arbitrary augmentation paths.

**Steps:**
1. Build a **residual graph**: each original directed edge `(u,v,cap)` becomes two residual arcs:
   - forward arc `u → v` with capacity `cap`
   - backward arc `v → u` with capacity `0`
   - Store each arc's reverse-arc index (paired via XOR with `1`).
2. **BFS (level graph):** assign each node a level = shortest distance from `s` in residual graph. Stop early if `t` is unreachable → no augmenting path exists.
3. **DFS (blocking flow):** repeatedly push flow along level-increasing paths (using `iter` pointer to skip exhausted edges) until no more `s→t` path exists in the level graph.
4. **Repeat** BFS + DFS until BFS fails.
5. For each original edge, the flow = `original_capacity − residual_capacity_on_forward_arc`.

---

## Python Implementation

```python
import sys
from collections import deque

def main():
    data = sys.stdin.buffer.read().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))
    s = int(next(it))
    t = int(next(it))

    # Edge list in residual form: to[], cap[], next index is i^1
    to = []
    cap = []
    # head[v] = index of first residual arc out of v (linked-list style)
    head = [-1] * n
    # We'll store (to, cap) pairs; reverse arc is i^1

    def add_edge(u, v, c):
        # forward arc
        to.append(v)
        cap.append(c)
        to.append(u)
        cap.append(0)

    # Record original edges for output
    orig_u = []
    orig_v = []
    orig_cap = []
    orig_arc_index = []  # forward arc index for each original edge

    # Build adjacency via lists of arc indices
    adj = [[] for _ in range(n)]

    for _ in range(m):
        u = int(next(it))
        v = int(next(it))
        c = int(next(it))
        orig_u.append(u)
        orig_v.append(v)
        orig_cap.append(c)
        fwd_idx = len(to)
        orig_arc_index.append(fwd_idx)
        add_edge(u, v, c)
        adj[u].append(fwd_idx)
        adj[v].append(fwd_idx ^ 1)

    # Dinic's algorithm
    INF = float('inf')
    level = [-1] * n
    iter_ptr = [0] * n

    def bfs():
        for i in range(n):
            level[i] = -1
        level[s] = 0
        q = deque([s])
        while q:
            u = q.popleft()
            for eid in adj[u]:
                if cap[eid] > 0 and level[to[eid]] < 0:
                    level[to[eid]] = level[u] + 1
                    q.append(to[eid])
        return level[t] >= 0

    def dfs(u, f):
        if u == t:
            return f
        while iter_ptr[u] < len(adj[u]):
            eid = adj[u][iter_ptr[u]]
            v = to[eid]
            if cap[eid] > 0 and level[v] == level[u] + 1:
                d = dfs(v, f if f < cap[eid] else cap[eid])
                if d > 0:
                    cap[eid] -= d
                    cap[eid ^ 1] += d
                    return d
            iter_ptr[u] += 1
        return 0

    max_flow = 0
    while bfs():
        for i in range(n):
            iter_ptr[i] = 0
        while True:
            f = dfs(s, INF)
            if f == 0:
                break
            max_flow += f

    # Output
    out = [str(max_flow)]
    for i in range(m):
        fwd = orig_arc_index[i]
        flow_val = orig_cap[i] - cap[fwd]
        out.append(str(flow_val))
    sys.stdout.write("\n".join(out) + "\n")

if __name__ == "__main__":
    main()
```

---

## How It Works

| Component | Purpose |
|-----------|---------|
| **Residual arcs** (`to`, `cap`) | Paired `i` and `i^1`; forward stores remaining capacity, backward stores pushed flow |
| **`adj[v]`** | List of residual-arc indices incident to `v` (both forward and reverse) |
| **BFS** | Builds level graph; returns `False` when `t` is unreachable → terminate |
| **DFS with `iter_ptr`** | Finds one augmenting path per call, advancing pointer so each arc is scanned once per phase → `O(VE)` per phase |
| **Recovery of original flow** | `flow = original_capacity − remaining_capacity_on_forward_arc` |

---

## Complexity

- **BFS:** `O(E)` per phase
- **DFS blocking flow:** `O(VE)` per phase
- **Number of phases:** `O(V)` → total `O(V²E)`
- **Space:** `O(V + E)`

---

## Example

**Input:**
```
4 5 0 3
0 1 10
0 2 10
1 2 2
1 3 8
2 3 10
```

**Output:**
```
18
10
8
2
8
10
```

The max flow is `18`; each line reports the flow on the corresponding original edge. Note that `0→1` and `0→2` are saturated, `1→2` carries `2`, `1→3` carries `8`, and `2→3` carries `10`. Flow conservation holds at nodes 1 and 2.
