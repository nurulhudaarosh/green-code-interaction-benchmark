## Original Problem Restatement

**Minimum-Cardinality Subset Sum**:

Given a list of positive integers `nums` and a target integer `target`, find a subset of `nums` (each element used at most once) whose values sum exactly to `target`, subject to:

1. **Feasibility**: The chosen elements sum exactly to `target`.
2. **Minimum cardinality**: Among all valid subsets, the chosen subset has the fewest elements.
3. **Lexicographic tie-break**: Among all minimum-cardinality valid subsets, the chosen subset's sorted list of 0-based indices is lexicographically smallest.
4. **Output**: The sorted list of chosen indices (ascending), or `None` if no valid subset exists. If `target == 0`, the empty list `[]` is returned (cardinality 0 is trivially minimal).

**Existing required outputs** (unchanged):
- The optimal subset as a sorted list of 0-based indices, or `None` if infeasible, or `[]` if `target == 0`.
- Deterministic behavior: no randomness, stable across runs.

## New Feature: `operation_summary`

Add an **optional** feature (enabled via a flag) that returns an additional `operation_summary` field containing a deterministic summary of the computation. For this task, the summary reports the **number of major computational decisions/operations** made by the algorithm.

**Design of the counter**:
- Count each DP transition attempt where `s >= num` for an item (i.e., each inner-loop iteration of the DP update).
- Count each reconstruction decision (each index inspected during greedy reconstruction).
- Count the initial feasibility check.

**Backward compatibility**:
- When the feature is disabled (default), the function returns **exactly** what it did before: the list of indices or `None`.
- When enabled, it returns a tuple/dict containing both the original result and the `operation_summary`.

**No change to original requirements**: The subset, tie-breaking, and determinism are unaffected. Only an additional, opt-in output is added.

## Corrected Implementation

```python
def subset_sum_lex_min(nums, target, return_summary=False):
    """
    Minimum-Cardinality Subset Sum with lexicographically smallest index list.

    Given `nums` (positive ints) and `target`, return the sorted list of
    0-based indices of a subset summing exactly to `target`, such that:
      1) it has the fewest elements possible, and
      2) among those, its sorted index list is lexicographically smallest.
    Returns None if no such subset exists. Returns [] if target == 0.

    If `return_summary=True`, also return a dict with an `operation_summary`
    field reporting deterministic operation counts.

    Original behavior is preserved exactly when `return_summary=False`.
    """
    n = len(nums)

    # Deterministic operation counters
    ops = {
        "dp_transition_attempts": 0,   # inner-loop iterations during DP build
        "reconstruction_steps": 0,     # index inspections during reconstruction
        "feasibility_checks": 0,       # final "is target reachable?" checks
    }

    # --- Trivial cases (still counted deterministically) ---
    if target == 0:
        ops["feasibility_checks"] += 1
        result = []
        if return_summary:
            return result, {"operation_summary": ops}
        return result

    if target < 0:
        ops["feasibility_checks"] += 1
        result = None
        if return_summary:
            return result, {"operation_summary": ops}
        return result

    IMPOSSIBLE = 255  # max cardinality <= n <= 200, fits in a byte

    # suf[i][s] = min cardinality using items i..n-1 to reach sum s.
    suf = [bytearray([IMPOSSIBLE]) * (target + 1) for _ in range(n + 1)]
    suf[n][0] = 0

    for i in range(n - 1, -1, -1):
        # Start with "skip item i"
        suf[i][:] = suf[i + 1][:]
        num = nums[i]
        if num > target:
            continue
        # Read from suf[i+1] (source), write to suf[i] (dest) — safe.
        for s in range(target, num - 1, -1):
            ops["dp_transition_attempts"] += 1
            prev = suf[i + 1][s - num]
            if prev != IMPOSSIBLE:
                cand = prev + 1
                if cand < suf[i][s]:
                    suf[i][s] = cand

    # Feasibility check on the full set
    ops["feasibility_checks"] += 1
    if suf[0][target] == IMPOSSIBLE:
        result = None
        if return_summary:
            return result, {"operation_summary": ops}
        return result

    # Greedy forward reconstruction: pick the smallest feasible index at each step.
    remaining = target
    needed = suf[0][target]
    result = []
    for i in range(n):
        if needed == 0:
            break
        ops["reconstruction_steps"] += 1
        num = nums[i]
        if num <= remaining and suf[i + 1][remaining - num] == needed - 1:
            result.append(i)
            remaining -= num
            needed -= 1

    if return_summary:
        return result, {"operation_summary": ops}
    return result


if __name__ == "__main__":
    tests = [
        ([3, 34, 4, 12, 5, 2], 9, [2, 4]),
        ([1, 2, 3], 100, None),
        ([1, 2, 3], 0, []),
        ([1, 1, 1, 1], 2, [0, 1]),
        ([1, 2, 2, 1], 3, [0, 1]),
        ([1, 1, 1, 1, 1], 5, [0, 1, 2, 3, 4]),
        ([2, 3, 5, 7], 10, [1, 3]),
        ([5, 1, 1, 1, 1], 5, [0]),
        ([1, 5, 1, 1, 1], 5, [1]),
    ]

    print("=== Original behavior (return_summary=False) ===")
    for nums, target, expected in tests:
        got = subset_sum_lex_min(nums, target)
        status = "OK" if got == expected else "FAIL"
        print(f"{status}: nums={nums}, target={target} -> {got} (expected {expected})")

    print("\n=== New feature (return_summary=True) ===")
    for nums, target, expected in tests:
        got, summary = subset_sum_lex_min(nums, target, return_summary=True)
        status = "OK" if got == expected else "FAIL"
        print(f"{status}: nums={nums}, target={target} -> {got} | {summary}")
```

## What Changed vs. What Stayed the Same

**Stayed the same (original requirements preserved):**
- The subset selection logic (minimum cardinality, lexicographically smallest sorted index list).
- Deterministic behavior with no randomness.
- Return value when `return_summary=False`: exactly the list of indices, `[]`, or `None`.
- Standard-library-only implementation.

**Added (new optional feature):**
- A `return_summary` flag (default `False`) that preserves original behavior when disabled.
- When enabled, returns `(result, {"operation_summary": ops})` where `ops` is a deterministic dict counting:
  - `dp_transition_attempts`: number of inner-loop iterations in the suffix DP build.
  - `reconstruction_steps`: number of index inspections during greedy reconstruction.
  - `feasibility_checks`: number of explicit feasibility checks (trivial-case checks plus the final DP check).
