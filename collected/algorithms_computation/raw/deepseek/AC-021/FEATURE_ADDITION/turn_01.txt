**Problem restatement**

Given a list of positive integers `nums` and a target `T`, decide whether some subset of `nums` sums exactly to `T`.

- If no subset sums to `T`, report impossibility.
- Among all subsets that sum to `T`, choose one with the **fewest elements**.
- Among those, choose the one whose sorted list of indices is **lexicographically smallest**.
- Return the chosen indices in increasing order.

**Key constraints**

- `nums[i] > 0`
- Standard 0/1 subset-sum: each element may be used at most once.
- Need both cardinality minimization and lexicographic tie-breaking by index list.
- Reconstruction must be deterministic.

**Algorithm**

Use dynamic programming over sums.

Let `dp[s]` store the best solution for sum `s`, where “best” means:

1. minimum number of elements, and
2. among those, lexicographically smallest index sequence.

Process indices from `0` to `n-1`. For each number `x = nums[i]`, update sums downward from `T` to `x`, so each item is used at most once.

For a candidate new solution to sum `s` using item `i`:
- previous sum is `s - x`
- if `dp[s - x]` is reachable, candidate indices are `dp[s - x] + [i]`
- compare candidate with existing `dp[s]` by `(len, indices)` lexicographically.

Because indices are processed in increasing order, and we append `i`, each stored index list is increasing. Lexicographic comparison of increasing index lists then matches the required tie-break.

Finally, return `dp[T]` if reachable, otherwise report no solution.

```python
from typing import List, Optional


def subset_sum_fewest_lex_smallest(nums: List[int], target: int) -> Optional[List[int]]:
    """
    Return indices of a subset of nums summing exactly to target.

    Selection rules:
      1. fewest elements
      2. lexicographically smallest index list among those

    Returns None if no such subset exists.
    """
    if target < 0:
        return None
    if target == 0:
        return []

    n = len(nums)

    # dp[s] = best index list for sum s, or None if unreachable.
    # best = (minimum length, lexicographically smallest list)
    dp: List[Optional[List[int]]] = [None] * (target + 1)
    dp[0] = []

    for i, x in enumerate(nums):
        if x <= 0:
            continue
        # Traverse downward so item i is used at most once.
        for s in range(target, x - 1, -1):
            if dp[s - x] is None:
                continue

            candidate = dp[s - x] + [i]

            if dp[s] is None:
                dp[s] = candidate
            else:
                current = dp[s]
                # Compare by length first, then lexicographically.
                if len(candidate) < len(current) or (
                    len(candidate) == len(current) and candidate < current
                ):
                    dp[s] = candidate

    return dp[target]


if __name__ == "__main__":
    # Deterministic examples
    examples = [
        ([3, 34, 4, 12, 5, 2], 9),
        ([1, 2, 3, 4, 5], 10),
        ([2, 3, 7, 8, 10], 11),
        ([1, 1, 1, 1], 3),
        ([5, 6, 7], 20),
    ]

    for nums, target in examples:
        result = subset_sum_fewest_lex_smallest(nums, target)
        if result is None:
            print(f"nums={nums}, target={target} -> no solution")
        else:
            chosen = [nums[i] for i in result]
            print(
                f"nums={nums}, target={target} -> indices={result}, "
                f"values={chosen}, sum={sum(chosen)}"
            )
```

**Complexity**

- Time: `O(n * target * L)` in the worst case, where `L` is the maximum stored index-list length. The extra factor comes from copying and comparing lists.
- Space: `O(target * L)` for the DP table.
