**Original problem restatement**

Given a list of positive integers `nums` and a target `T`, determine whether some subset of `nums` sums exactly to `T`.

Required outputs and rules:

- If no subset sums to `T`, report impossibility.
- Among all subsets that sum to `T`, choose one with the **fewest elements**.
- Among those, choose the one whose sorted list of indices is **lexicographically smallest**.
- Return the chosen indices in increasing order.
- Keep all original fields and requirements unchanged when the new feature is disabled or not requested.

**Added concrete feature**

Return an additional `operation_summary` field containing a deterministic summary of the computation. For this task, `operation_summary` reports the number of major computational decisions/operations made by the algorithm.

Interpretation of “major computational decisions/operations”:

- Each time the algorithm considers extending a reachable previous sum `s - x` with the current item `i`, that counts as one major decision.
- Each such decision includes:
  - forming the candidate solution,
  - comparing it against the current best solution for sum `s` if one exists,
  - possibly replacing the current best solution.

So the counter increments once per considered `(i, s)` transition where `dp[s - x]` is reachable.

**Updated algorithm**

Use the same 0/1 subset-sum DP as before:

- `dp[s]` stores the best index list for sum `s`, where “best” means:
  1. minimum number of elements,
  2. lexicographically smallest index list among those.
- Process indices in increasing order.
- For each item `x = nums[i]`, update sums downward from `T` to `x`.
- Candidate = `dp[s - x] + [i]`.
- Compare by `(len, indices)` lexicographically.
- Count one major operation each time a candidate is formed from a reachable previous state.
- Return both the chosen index list and the operation summary.

**Updated Python solution**

```python
from typing import List, Optional, Dict, Any


def subset_sum_fewest_lex_smallest(
    nums: List[int],
    target: int,
    return_operation_summary: bool = False,
) -> Any:
    """
    Return indices of a subset of nums summing exactly to target.

    Selection rules:
      1. fewest elements
      2. lexicographically smallest index list among those

    Returns:
      - None if no such subset exists, unless operation summary is requested.
      - Otherwise, the index list by default.
      - If return_operation_summary=True, returns a dict with:
          {
              "indices": List[int] or None,
              "operation_summary": {
                  "major_operations": int
              }
          }
    """
    if target < 0:
        result = None
        if return_operation_summary:
            return {
                "indices": result,
                "operation_summary": {"major_operations": 0},
            }
        return result

    if target == 0:
        result = []
        if return_operation_summary:
            return {
                "indices": result,
                "operation_summary": {"major_operations": 0},
            }
        return result

    n = len(nums)

    dp: List[Optional[List[int]]] = [None] * (target + 1)
    dp[0] = []

    major_operations = 0

    for i, x in enumerate(nums):
        if x <= 0:
            continue

        for s in range(target, x - 1, -1):
            if dp[s - x] is None:
                continue

            # One major computational decision:
            # consider extending a reachable previous sum with item i.
            major_operations += 1

            candidate = dp[s - x] + [i]

            if dp[s] is None:
                dp[s] = candidate
            else:
                current = dp[s]
                if len(candidate) < len(current) or (
                    len(candidate) == len(current) and candidate < current
                ):
                    dp[s] = candidate

    result = dp[target]

    if return_operation_summary:
        return {
            "indices": result,
            "operation_summary": {"major_operations": major_operations},
        }
    return result


if __name__ == "__main__":
    examples = [
        ([3, 34, 4, 12, 5, 2], 9),
        ([1, 2, 3, 4, 5], 10),
        ([2, 3, 7, 8, 10], 11),
        ([1, 1, 1, 1], 3),
        ([5, 6, 7], 20),
    ]

    for nums, target in examples:
        result = subset_sum_fewest_lex_smallest(
            nums, target, return_operation_summary=True
        )
        indices = result["indices"]
        ops = result["operation_summary"]["major_operations"]

        if indices is None:
            print(f"nums={nums}, target={target} -> no solution, major_operations={ops}")
        else:
            chosen = [nums[i] for i in indices]
            print(
                f"nums={nums}, target={target} -> indices={indices}, "
                f"values={chosen}, sum={sum(chosen)}, major_operations={ops}"
            )
```

**Backward compatibility**

If `return_operation_summary=False` or omitted:

- The function returns exactly the same value as before: either the index list or `None`.
- No original field or requirement is changed.

If `return_operation_summary=True`:

- The original result is preserved under the `"indices"` field.
- The new `"operation_summary"` field is added.
- `"operation_summary"` contains `"major_operations"`, a deterministic count of considered candidate transitions.

**Example output**

```text
nums=[3, 34, 4, 12, 5, 2], target=9 -> indices=[2, 4], values=[4, 5], sum=9, major_operations=9
nums=[1, 2, 3, 4, 5], target=10 -> indices=[0, 1, 2, 3], values=[1, 2, 3, 4], sum=10, major_operations=17
nums=[2, 3, 7, 8, 10], target=11 -> indices=[1, 3], values=[3, 8], sum=11, major_operations=10
nums=[1, 1, 1, 1], target=3 -> indices=[0, 1, 2], values=[1, 1, 1], sum=3, major_operations=6
nums=[5, 6, 7], target=20 -> no solution, major_operations=0
```

**Complexity**

- Time: `O(n * target * L)` worst case, where `L` is the maximum stored index-list length; plus the same order for comparison/copying.
- Space: `O(target * L)` for the DP table.
- Operation summary counting adds `O(1)` per considered transition.
