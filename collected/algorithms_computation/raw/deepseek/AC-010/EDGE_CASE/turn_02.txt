# Matrix Chain Planner - Complete Solution

## Problem Restatement
Given matrix dimensions p₀, p₁, ..., pₙ where matrix i has dimensions pᵢ₋₁ × pᵢ, find:
1. The minimum number of scalar multiplications needed to multiply all matrices
2. A parenthesization that achieves this minimum cost

**Tie-breaking rule**: When multiple split positions yield the same minimum cost, choose the smallest split index.

## Complete Solution with Test Cases

```python
def matrix_chain_order(p):
    """
    Find minimum scalar multiplication cost and parenthesization for matrix chain.
    
    Args:
        p: List of dimensions where matrix i has dimensions p[i-1] x p[i]
    
    Returns:
        tuple: (min_cost, parenthesization_string)
    """
    n = len(p) - 1  # number of matrices
    
    # Edge cases
    if n == 0:
        return 0, ""
    if n == 1:
        return 0, "M1"
    
    # dp[i][j] = minimum cost to multiply matrices i through j (0-indexed)
    dp = [[0] * n for _ in range(n)]
    
    # split[i][j] = optimal split position for matrices i through j
    split = [[0] * n for _ in range(n)]
    
    # length of chain (number of matrices)
    for length in range(2, n + 1):
        for i in range(n - length + 1):
            j = i + length - 1
            dp[i][j] = float('inf')
            
            # Try all possible split positions
            for k in range(i, j):
                cost = dp[i][k] + dp[k+1][j] + p[i] * p[k+1] * p[j+1]
                
                # Use smallest split index when costs are equal (tie-breaking)
                if cost < dp[i][j]:
                    dp[i][j] = cost
                    split[i][j] = k
                # If equal cost, keep smaller k (already smaller due to loop order)
    
    # Build parenthesization string
    def build_parenthesization(i, j):
        if i == j:
            return f"M{i+1}"
        k = split[i][j]
        left = build_parenthesization(i, k)
        right = build_parenthesization(k+1, j)
        return f"({left} × {right})"
    
    min_cost = dp[0][n-1]
    parenthesization = build_parenthesization(0, n-1)
    
    return min_cost, parenthesization


def solve_matrix_chain():
    """
    Read input, compute minimum cost and parenthesization, print results.
    """
    try:
        # Read dimensions
        line = input().strip()
        while line == '':
            line = input().strip()
        
        p = list(map(int, line.split()))
        
        # Validate input
        if len(p) < 2:
            print("0")
            print("")
            return
        
        min_cost, parenthesization = matrix_chain_order(p)
        
        print(min_cost)
        print(parenthesization)
        
    except EOFError:
        return

def run_tests():

        # Split at 1: ((M1 × M2) × M3) cost = 1000 + 0 + 10*10*10 = 2000
        # Smallest split = 0, so parenthesization = (M1 × (M2 × M3))
        # Wait, let me recalculate with 0-indexing carefully:
        # For n=3 matrices: M1(10x10), M2(10x10), M3(10x10)
        # Split k=0 (0-indexed): (M1 × (M2 × M3)) = 0 + 1000 + 10*10*10 = 2000
        # Split k=1: ((M1 × M2) × M3) = 1000 + 0 + 10*10*10 = 2000
        # Smallest k=0, so result should be (M1 × (M2 × M3))
        
        # Test 6: More complex with ties
        ([5, 5, 5, 5, 5], 500, "((M1 × (M2 × M3)) × M4)"),
        # For 4 matrices of size 5x5:
        # Many splits give cost 500, choose smallest split at each level
        
        # Test 7: Repeated dimensions with different values
        ([2, 3, 2, 3, 2], 48, "(((M1 × M2) × M3) × M4)"),

            def normalize(s):
                return s.replace(" ", "").replace("×", "*")
            
            paren_match = (normalize(parenthesization) == normalize(expected_parenthesization))
            
            if cost_match and paren_match:

            print(f"  Error: {e}")
            failed += 1
        
        print("-" * 70)
    
    print(f"\nSUMMARY: {passed} passed, {failed} failed")
```

## Key Implementation Features

### 1. **Tie-Breaking with Smallest Split Index**


### 2. **Handling Repeated Values**
The algorithm naturally handles repeated dimension values through dynamic programming:
- All possible splits are evaluated
- Equal costs are handled by the tie-breaking rule
- The DP table correctly computes minimum costs regardless of value patterns

### 3. **Edge Cases**
- Empty input (n=0): returns 0 cost and empty string
- Single matrix (n=1): returns 0 cost and "M1"
