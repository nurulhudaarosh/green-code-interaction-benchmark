def matrix_chain_order(p):
    """
    Find optimal parenthesization for matrix chain multiplication.
    
    Args:
        p: List of dimensions where matrix i has dimensions p[i-1] × p[i]
        
    Returns:
        tuple: (minimum_cost, parenthesization_string)
    """
    n = len(p) - 1  # number of matrices
    
    if n == 0:
        return 0, ""
    if n == 1:
        return 0, "M1"
    
    # dp[i][j] = minimum cost to multiply matrices i..j (1-indexed)
    dp = [[0] * (n + 1) for _ in range(n + 1)]
    split = [[0] * (n + 1) for _ in range(n + 1)]
    
    # length of chain to consider
    for length in range(2, n + 1):
        for i in range(1, n - length + 2):
            j = i + length - 1
            dp[i][j] = float('inf')
            
            # Try all possible split positions
            for k in range(i, j):
                cost = dp[i][k] + dp[k+1][j] + p[i-1] * p[k] * p[j]
                
                # Choose smaller cost, or if equal, choose smaller k
                if cost < dp[i][j]:
                    dp[i][j] = cost
                    split[i][j] = k
                elif cost == dp[i][j] and k < split[i][j]:
                    split[i][j] = k
    
    # Build parenthesization string
    def build_parenthesization(i, j):
        if i == j:
            return f"M{i}"
        k = split[i][j]
        left = build_parenthesization(i, k)
        right = build_parenthesization(k+1, j)
        return f"({left}{right})"
    
    min_cost = dp[1][n]
    parenthesization = build_parenthesization(1, n)
    
    return min_cost, parenthesization


def matrix_chain_multiply(p):
    """
    Wrapper function that returns the formatted output.
    
    Args:
        p: List of dimensions
        
    Returns:
        str: Formatted output string
    """
    if len(p) < 2:
        return "0\n"
    
    cost, paren = matrix_chain_order(p)
    return f"{cost}\n{paren}\n"

This implementation:

1. **Uses interval DP** over all matrix-chain ranges (length from 2 to n)
2. **Enforces deterministic tie-handling** by choosing the smallest split index k when costs are equal
3. **Builds parenthesization** recursively from the split table
4. **Returns exactly** the minimum cost and parenthesization string as required
5. **Handles edge cases** (0, 1, or 2 matrices)
6. **Uses only standard library** - no external dependencies

The key insight for tie-breaking is in the recurrence:


This ensures that for any subproblem i..j, if multiple split positions give the same cost, we always choose the smallest k. This deterministic choice propagates through all levels of the recursion, guaranteeing a unique, well-defined output for any input.
