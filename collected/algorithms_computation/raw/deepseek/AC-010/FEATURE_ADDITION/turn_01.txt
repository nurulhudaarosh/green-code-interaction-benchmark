I'll implement a solution for the matrix chain multiplication problem that finds the minimum scalar multiplication cost and optimal parenthesization.

```python
import sys

def matrix_chain_order(dims):
    """
    Find the minimum scalar multiplication cost and optimal parenthesization
    for multiplying matrices with dimensions p0..pn.
    
    Args:
        dims: List of dimensions [p0, p1, ..., pn] where matrix i has dimensions p[i-1] x p[i]
    
    Returns:
        (min_cost, parenthesization_string)
    """
    n = len(dims) - 1  # number of matrices
    
    # dp[i][j] = minimum cost to multiply matrices i through j (0-indexed)
    dp = [[0] * n for _ in range(n)]
    
    # split[i][j] = optimal split index for matrices i through j
    split = [[0] * n for _ in range(n)]
    
    # length is the chain length (number of matrices in the subproblem)
    for length in range(2, n + 1):
        for i in range(n - length + 1):
            j = i + length - 1
            dp[i][j] = float('inf')
            
            # Try all possible split points k from i to j-1
            for k in range(i, j):
                cost = dp[i][k] + dp[k+1][j] + dims[i] * dims[k+1] * dims[j+1]
                
                # Use smaller split index when costs are equal (strictly less for deterministic)
                if cost < dp[i][j]:
                    dp[i][j] = cost
                    split[i][j] = k
    
    # Build parenthesization string
    def build_parenthesization(i, j):
        if i == j:
            return f"M{i+1}"
        else:
            k = split[i][j]
            left = build_parenthesization(i, k)
            right = build_parenthesization(k+1, j)
            return f"({left}{right})"
    
    if n == 0:
        return (0, "")
    elif n == 1:
        return (0, "M1")
    else:
        return (dp[0][n-1], build_parenthesization(0, n-1))

def main():
    # Read input
    input_data = sys.stdin.read().strip().split()
    if not input_data:
        return
    
    # First number is n (number of matrices)
    n = int(input_data[0])
    
    # Next n+1 numbers are dimensions
    dims = list(map(int, input_data[1:n+2]))
    
    # Verify we have the correct number of dimensions
    if len(dims) != n + 1:
        print("Error: Invalid input format")
        return
    
    # Find optimal multiplication order
    min_cost, parenthesization = matrix_chain_order(dims)
    
    # Output results
    print(f"Minimum scalar multiplications: {min_cost}")
    print(f"Optimal parenthesization: {parenthesization}")

if __name__ == "__main__":
    main()
```

**Key Components:**

1. **Problem Understanding**: Given dimensions `[p0, p1, ..., pn]` where matrix `i` has size `p[i-1] × p[i]`, find the minimum scalar multiplication cost and optimal parenthesization.

2. **Constraints Handled**: 
   - Equal-cost choices use the smallest split index (enforced by using `<` rather than `<=`)
   - Works for n matrices where n ≥ 1
   - Uses only standard library

3. **Algorithm**: Interval DP with:
   - `dp[i][j]`: minimum cost for multiplying matrices i through j
   - `split[i][j]`: optimal split point for matrices i through j
   - Recurrence: `dp[i][j] = min(dp[i][k] + dp[k+1][j] + dims[i] * dims[k+1] * dims[j+1])`
   - Time complexity: O(n³)
   - Space complexity: O(n²)

4. **Input Format**: First number is n, followed by n+1 dimensions
5. **Output**: Minimum cost and parenthesization (e.g., `(M1(M2M3))`)
