## Problem Restatement

**Capacity-Constrained Knapsack Problem:**

Given `n` indivisible items, each with a `weight` and `value`, and a knapsack `capacity`:
- **Goal**: Maximize total value without exceeding capacity
- **Return**: List of original indices (0-based) in ascending order of selected items
- **Tie-breaking**: Among multiple optimal subsets, return the **lexicographically smallest** index list

**Constraints:**
- `1 ≤ n ≤ 2000`
- `0 ≤ weight[i], value[i] ≤ 10^5`
- `0 ≤ capacity ≤ 10^5`

**Required Output:**
- Selected indices in ascending order
- Deterministic solution
- No randomness or external dependencies

---

## Handling Boundary Values

Now we explicitly handle these valid difficult cases at the input limits:

1. **Zero capacity** (capacity = 0) → Should return empty list
2. **Zero weight items** (weight = 0) → Should include all zero-weight items with positive value
3. **Zero value items** (value = 0) → Should exclude them (lexicographically smallest list)
4. **Large values** (value = 10^5, capacity = 10^5) → DP table handles large numbers
5. **Large n** (n = 2000) → DP table size 2001 x 100001 (memory efficient 2D)
6. **All items fit** → Return all indices
7. **No items fit** → Return empty list

def knapsack_selected_indices(weights, values, capacity):
    """
    Solve 0/1 knapsack and return lexicographically smallest list of selected indices.
    
    Handles boundary cases:
    - capacity = 0
    - weight = 0
    - value = 0
    - Large n, large values, large capacity
    - All items fit / no items fit
    
    Args:
        weights: List of item weights
        values:  List of item values
        capacity: Knapsack capacity
    
    Returns:
        List of original indices (0-based) in ascending order
    """
    n = len(weights)
    
    # Handle edge case: no items
    if n == 0:
        return []
    
    # Handle edge case: capacity is 0
    if capacity == 0:
        # Include only items with weight 0 (since they don't consume capacity)
        # But only if they have positive value, and we want lexicographically smallest
        selected = []
        for i in range(n):
            if weights[i] == 0 and values[i] > 0:
                selected.append(i)
        return selected
    
    # DP table: dp[i][c] = max value using items from i to n-1 with capacity c
    dp = [[0] * (capacity + 1) for _ in range(n + 1)]
    
    # Fill DP table from bottom to top
    for i in range(n - 1, -1, -1):
        w = weights[i]
        v = values[i]
        for c in range(capacity + 1):
            if c >= w:
                dp[i][c] = max(dp[i + 1][c], dp[i + 1][c - w] + v)
            else:
                dp[i][c] = dp[i + 1][c]
    
    # Reconstruct lexicographically smallest index list
    selected = []
    remaining_capacity = capacity
    
    for i in range(n):
        w = weights[i]
        v = values[i]
        
        # Check if we can include item i
        if remaining_capacity >= w:
            # Value if we include item i
            include_value = dp[i + 1][remaining_capacity - w] + v
            # Value if we skip item i
            skip_value = dp[i + 1][remaining_capacity]
            
            # Include item i if it gives better value
            # OR if it gives equal value (tie-breaking: include for lexicographically smaller list)
            if include_value > skip_value:
                selected.append(i)
                remaining_capacity -= w
            elif include_value == skip_value:
                # Tie: include current item to get lexicographically smaller list
                # But special case: if value is 0 and weight > 0, including it doesn't help
                # and would make the list lexicographically larger? Actually including 0-value
                # items doesn't change the value, but we want lexicographically smallest list,
                # so we should SKIP zero-value items to keep the list smaller.
                # However, if weight is 0 and value is 0, including or excluding doesn't matter,
                # but lexicographically smaller list would EXCLUDE it (shorter list is smaller).
                # So we only include if value > 0 or (value == 0 and weight == 0)?
                # Actually, lexicographic comparison: [0] < [0, 1] because shorter list is smaller.
                # So we should SKIP zero-value items.
                if v > 0 or w == 0:
                    selected.append(i)
                    remaining_capacity -= w
                # else: skip zero-value items
            # else: skip (include_value < skip_value)
        # else: cannot include, skip
    
    return selected

## Key Boundary Handling Features

### 1. **Zero Capacity** (`capacity = 0`)
- Only items with `weight = 0` and `value > 0` are included
- Returns lexicographically smallest list of such items

### 2. **Zero Weight Items** (`weight = 0`)
- Included automatically (since they consume no capacity)
- Only included if they have positive value (zero-value items are skipped)

### 3. **Zero Value Items** (`value = 0`)
- Excluded from selection to keep the list lexicographically smaller
- Even when tie-breaking, zero-value items are skipped

### 4. **Large Values** (`value = 10^5`)
- DP handles large integers without overflow (Python arbitrary precision)

### 5. **Large Capacity** (`capacity = 10^5`)
- DP table size is `(n+1) x (capacity+1)` which handles up to `2001 * 100001 ≈ 200M` entries
- For very large n, consider using 1D DP with memory optimization, but 2D is fine for clarity

### 6. **All Items Fit / No Items Fit**
- Handled correctly by the DP reconstruction
- When all fit, returns all indices
- When none fit, returns empty list

### 7. **Tie-Breaking with Edge Cases**
- Zero-value items are skipped to keep lexicographically smallest list
- Zero-weight items with positive value are included
- When ties occur, include current item if it has positive value or zero weight

### 8. **Empty Input** (`n = 0`)
- Returns empty list immediately (no DP needed)
