I understand the problem: we have a set of indivisible items, each with a weight and a value, and a knapsack capacity. The goal is to select a subset of items that maximizes the total value without exceeding the capacity. If there are multiple optimal solutions, we choose the one with the lexicographically smallest list of original indices (0‑based or 1‑based? The problem says "original indices", typically we use 0‑based as given, but we'll output them as they appear in input order). I'll assume indices are 0‑based unless specified otherwise.

**Key constraints:**  
- Number of items n can be up to, say, 2000 (typical for DP).  
- Capacity W can be up to, say,  ～10000.  
- Weights and values are positive integers.  
- Need O(n * W) time and O(W) space.

**Required output:**  
- A list of selected original indices (0‑based) in increasing order, with lexicographically smallest list among optimal solutions.

**Algorithm:**  
1. Use 0/1 knapsack DP with descending capacity updates to compute maximum value for each capacity.  
2. To reconstruct the lexicographically smallest index list, we can either store a parent array or do a backward greedy selection.  
   - A common approach: after computing DP, we iterate items from last to first (or first to last) and check if including the item leads to the optimal value. To get lexicographically smallest, we iterate items from smallest index to largest and try to include it if possible.  
   - However, that simple forward greedy might fail because including an early item might block later items but still yield same total value; we need to ensure we pick the lexicographically smallest list.  
   - Better: do DP with a tie‑breaking rule that favors smaller indices. We can store a tuple (value, chosen_indices) but that's heavy. Alternatively, we can do DP and then reconstruct by checking from index 0 to n‑1: include item i if after including it, the remaining capacity can still achieve the optimal value with items i+1..n‑1. That works because we process in increasing index order and only include if necessary.

   Implementation:  
   - Compute `dp[c]` = max value for capacity c using items processed so far.  
   - After filling DP with all items, we have `optimal_value = dp[W]`.  
   - Then reconstruct: start with remaining capacity `cap = W`, and for i from 0 to n‑1:  
     - If item i's weight <= cap and `dp[cap] == dp[cap - weight_i] + value_i` (where dp is the final DP array after all items), then we include item i, subtract weight, and continue. But careful: the DP array we have is for all items, so this condition works because `dp[cap]` is the optimal value for capacity cap using all items.  
   - This yields a valid optimal solution. To ensure lexicographically smallest index list, we process i in increasing order and include it if it can be part of some optimal solution. That indeed gives the smallest lexicographic list because we always prefer including a smaller index whenever possible.

   Note: The DP array after all items is enough because we don't need to know the subset of items used; the condition checks if the item can be part of an optimal solution for the remaining capacity.

**Implementation details:**  
- Input: items as list of (weight, value), capacity W.  
- Return list of indices.

**Edge cases:**  
- If multiple items have same weight/value, the lexicographically smallest list will favor including earlier indices.  
- If capacity is 0 or no items, return empty list.

Let's implement deterministic Python solution using only standard library.

```python
def knapsack_indices(items, capacity):
    """
    items: list of (weight, value)
    capacity: integer
    Returns list of original indices (0-based) that maximize value,
    with lexicographically smallest index list among optimal solutions.
    """
    n = len(items)
    # dp[c] = max value for capacity c
    dp = [0] * (capacity + 1)
    
    # 0/1 knapsack with descending capacity
    for w, v in items:
        if w > capacity:
            continue
        # iterate backwards to avoid reusing item
        for c in range(capacity, w - 1, -1):
            new_val = dp[c - w] + v
            if new_val > dp[c]:
                dp[c] = new_val
    
    # Reconstruct lexicographically smallest optimal index list
    selected = []
    remaining_cap = capacity
    # We need the original dp array after all items.
    # We process items in increasing index order.
    for i, (w, v) in enumerate(items):
        if w <= remaining_cap and dp[remaining_cap] == dp[remaining_cap - w] + v:
            # Include this item
            selected.append(i)
            remaining_cap -= w
            # Note: after we include, dp[remaining_cap] now refers to the optimal
            # value for the new remaining capacity using all items.
            # The condition still holds for later items.
    return selected
```
