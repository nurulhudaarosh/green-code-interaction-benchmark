## Problem Restatement

**Longest Increasing Route**  
Given an integer sequence, find a **strictly increasing subsequence** of **maximum length**.  
Among all such subsequences, return the one whose **original index sequence** (1-based) is **lexicographically smallest**.  

**Expected Behavior:**
- Output: first line = maximum length, second line = space-separated indices.
- Deterministic tie-breaking: when multiple predecessors give the same length, choose the one yielding the lexicographically smallest index sequence.
