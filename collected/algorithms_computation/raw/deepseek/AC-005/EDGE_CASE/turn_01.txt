To handle tie-breaking correctly:  

- We do DP from left to right. For each `i`, we consider all `j < i` with `a[j] < a[i]`.  
- If `dp[j] + 1 > dp[i]`, we update `dp[i]` and set `prev[i] = j`.

Simplest deterministic implementation for clarity: store full sequence tuple for each `i`. This is O(n²) memory but fine for typical constraints (n ≤ 2000). We'll implement that.  

Steps:  

1. Initialize `dp = [1]*n`, `prev = [-1]*n`, `seq = [None]*n`  
2. For each `i` from 0 to n-1:  
   - Set `seq[i] = (i,)`  
   - For each `j` from 0 to i-1:  
        if `a[j] < a[i]`:  
            cand_len = dp[j] + 1  
            if cand_len > dp[i]:  
                dp[i] = cand_len  
                prev[i] = j  
                seq[i] = seq[j] + (i,)  
            elif cand_len == dp[i]:  
                # compare seq[j] + (i,) vs seq[i]  
                candidate_seq = seq[j] + (i,)  
                if candidate_seq < seq[i]:  
                    prev[i] = j  
                    seq[i] = candidate_seq  

3. After loop, find `best_len = max(dp)`  
4. Collect all indices `i` with `dp[i] == best_len`  
5. Among them, choose the one with the smallest `seq[i]` (lexicographically).  
6. Return that sequence (list of indices).  

**Edge cases**:  
- Empty sequence? The problem says integer sequence, could be empty? Usually not, but if n=0, return empty list.  

**Implementation** in Python:  

```python
def longest_increasing_subsequence_indices(a):
    n = len(a)
    if n == 0:
        return []
    
    dp = [1] * n
    prev = [-1] * n
    seq = [None] * n
    
    for i in range(n):
        seq[i] = (i,)
        for j in range(i):
            if a[j] < a[i]:
                cand_len = dp[j] + 1
                if cand_len > dp[i]:
                    dp[i] = cand_len
                    prev[i] = j
                    seq[i] = seq[j] + (i,)
                elif cand_len == dp[i]:
                    candidate = seq[j] + (i,)
                    if candidate < seq[i]:
                        prev[i] = j
                        seq[i] = candidate
    
    best_len = max(dp)
    candidates = [i for i in range(n) if dp[i] == best_len]
    best_seq = min(seq[i] for i in candidates)
    return list(best_seq)
```

This is O(n²) time and O(n²) memory worst-case (due to storing tuples).  
We can reduce memory by only storing `prev` and using a comparison function, but this is simpler and deterministic.
