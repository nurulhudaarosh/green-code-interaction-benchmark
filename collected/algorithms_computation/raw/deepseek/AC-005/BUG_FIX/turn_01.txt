I understand the problem:  
We are given an integer sequence. We need to find a **strictly increasing subsequence** of **maximum length**. Among all such subsequences of that maximum length, we must return the one whose **original indices** (1‑based) form the **lexicographically smallest** sequence.

**Key constraints:**  
- The sequence length \( n \) is not explicitly given here, but the algorithm must work for moderate \( n \) (say up to a few thousand) using \( O(n^2) \) time and \( O(n) \) memory for DP arrays, plus \( O(n) \) for reconstruction.
- The output is the **index sequence** (1‑based) of the chosen subsequence.

**Required output:**  
A list of integers (the indices in the original sequence) that corresponds to the lexicographically smallest index sequence among all longest strictly increasing subsequences.

---

**Algorithm description (quadratic DP with explicit predecessor/index‑sequence tie‑breaking):**

1. Let `dp[i]` = length of the longest strictly increasing subsequence **ending at index i** (0‑based internally).  
2. Let `pred[i]` = the previous index in that optimal subsequence (or -1 if none).  
3. We iterate `i` from 0 to n-1:  
   - For each `j < i` where `a[j] < a[i]`:  
     - If `dp[j] + 1 > dp[i]`, we update `dp[i]` and set `pred[i] = j`.  
     - If `dp[j] + 1 == dp[i]`, we need to choose the predecessor that gives the **lexicographically smaller index sequence** for the subsequence ending at `i`.  
       Since we build from left to right, we can compare the index sequences by comparing the predecessor's index sequence first, then the current index.  
       To do this efficiently, we store for each `i` the "best index sequence" as a tuple of indices, but that would be too memory heavy.  
       Instead, we store `pred[i]` and also a ranking or we compare on the fly using the fact that if two subsequences have the same length, the lexicographically smaller one is the one with the smaller first differing index.  
       Since we are comparing sequences that end at `i`, we can compare the sequence for `j1` and `j2` by comparing their full index sequences.  
       To do this without storing tuples, we can store for each `i` a **parent pointer** and a **hash** or we can simply store the full sequence as a tuple when needed, but for n up to ~5000 that might be okay in Python (though memory heavy).  
       A better way:  
       - We store `seq[i]` as a tuple of indices for the best sequence ending at `i`.  
       - This is \( O(n^2) \) memory in worst case, but for n ≤ 2000 it's acceptable.  
       Alternatively, we can store a `rank` or compare using a custom comparison that walks back the parent pointers each time (which would be O(n) per comparison, leading to O(n^3) worst case).  
       Given the problem statement, a clear and correct quadratic DP with storing the index sequence tuple is acceptable for moderate n.

4. After filling DP, find the maximum length `L` and the set of indices with `dp[i] == L`. Among those, pick the one with the **lexicographically smallest** index sequence (store the sequence tuple).  
5. Return that tuple (convert to 1‑based indices).

**Implementation:**

```python
def longest_increasing_subsequence_indices(arr):
    n = len(arr)
    if n == 0:
        return []
    
    # dp[i] = length of LIS ending at i
    dp = [1] * n
    # seq[i] = tuple of indices (0-based) of the lexicographically smallest LIS ending at i
    seq = [None] * n
    for i in range(n):
        seq[i] = (i,)
    
    for i in range(n):
        for j in range(i):
            if arr[j] < arr[i]:
                if dp[j] + 1 > dp[i]:
                    dp[i] = dp[j] + 1
                    seq[i] = seq[j] + (i,)
                elif dp[j] + 1 == dp[i]:
                    # Compare lexicographically the index sequences
                    candidate = seq[j] + (i,)
                    if candidate < seq[i]:
                        seq[i] = candidate
    
    # Find max length
    max_len = max(dp)
    # Find the lexicographically smallest index sequence among those with max_len
    best_seq = None
    for i in range(n):
        if dp[i] == max_len:
            if best_seq is None or seq[i] < best_seq:
                best_seq = seq[i]
    
    # Convert to 1-based indices
    return [idx + 1 for idx in best_seq]

    # LIS length = 3, possible: [1,3,4] (indices 1,2,4) and [1,2,4] (indices 1,3,4)
    # Lexicographically smallest index sequence: [1,2,4] or [1,3,4]? Compare: (1,2,4) < (1,3,4) => choose (1,2,4)
    arr = [1, 3, 2, 4]
    print(longest_increasing_subsequence_indices(arr))  # Output: [1, 2, 4]

    print(longest_increasing_subsequence_indices(arr2))  # [1, 3]
    
    arr3 = [3, 2, 1]
    print(longest_increasing_subsequence_indices(arr3))  # [1] (or [2] or [3]? All length 1, lexicographically smallest: [1])
```
