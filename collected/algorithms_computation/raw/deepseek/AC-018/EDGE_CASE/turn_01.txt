Here's a clear breakdown and solution for the polynomial multiplication problem.

## Problem Understanding

We need to multiply two integer polynomials and return the coefficient array of the product. Polynomials are represented by their coefficients, where the index corresponds to the power of the variable (typically in ascending order).

**Example:** `[1, 2, 3]` represents `1 + 2x + 3x²`

If we multiply `[1, 2]` (i.e., `1 + 2x`) by `[3, 4]` (i.e., `3 + 4x`), we get `3 + 10x + 8x²`, so the result is `[3, 10, 8]`.

## Key Constraints

- Input: two lists of integers (coefficients), possibly including negatives and zeros.
- Output: a list of integers representing the product's coefficients.
- Degree of result = `len(a) + len(b) - 2`, so result length = `len(a) + len(b) - 1`.
- Handle edge cases: empty input lists → empty result (or zero polynomial).
- Direct convolution is O(n·m), which is fine for practical input sizes.

## Algorithm (Direct Coefficient Convolution)

For each coefficient `a[i]` in the first polynomial and each `b[j]` in the second, add `a[i] * b[j]` to result index `i + j`. This directly computes the Cauchy product of the two coefficient sequences.

## Python Implementation

```python
def multiply_polynomials(a, b):
    """
    Multiply two integer polynomials given as coefficient lists
    (index = power of x, ascending order). Returns the product's
    coefficient list.
    """
    # Edge case: if either polynomial is empty, the product is empty
    if not a or not b:
        return []

    # Result has degree (len(a)-1) + (len(b)-1), so length len(a)+len(b)-1
    result = [0] * (len(a) + len(b) - 1)

    # Direct convolution: accumulate products at the correct power index
    for i, coeff_a in enumerate(a):
        if coeff_a == 0:
            continue  # minor optimization; skip zero terms
        for j, coeff_b in enumerate(b):
            result[i + j] += coeff_a * coeff_b

    return result


def _run_tests():
    # Basic case
    assert multiply_polynomials([1, 2], [3, 4]) == [3, 10, 8]

    # Constant * polynomial
    assert multiply_polynomials([5], [1, 2, 3]) == [5, 10, 15]

    # Identity (multiply by 1)
    assert multiply_polynomials([1], [1, 2, 3]) == [1, 2, 3]

    # Negative coefficients
    assert multiply_polynomials([1, -2], [3, -4]) == [3, -10, 8]

    # Zeros inside
    assert multiply_polynomials([0, 1], [0, 0, 1]) == [0, 0, 0, 1]

    # Zero polynomial
    assert multiply_polynomials([0], [1, 2, 3]) == [0, 0, 0]

    # Empty inputs
    assert multiply_polynomials([], [1, 2]) == []
    assert multiply_polynomials([1, 2], []) == []

    # Larger case: (1 + x)^2 = 1 + 2x + x^2
    assert multiply_polynomials([1, 1], [1, 1]) == [1, 2, 1]

    # (1 + x)^3 = 1 + 3x + 3x^2 + x^3
    assert multiply_polynomials([1, 1], [1, 2, 1]) == [1, 3, 3, 1]

    # Verify against known: (2 + 3x + 4x^2)(5 + 6x) = 10 + 27x + 38x^2 + 24x^3
    assert multiply_polynomials([2, 3, 4], [5, 6]) == [10, 27, 38, 24]

    print("All tests passed.")


if __name__ == "__main__":
    _run_tests()
```

## How It Works

1. **Result sizing:** The product of polynomials with degrees `m-1` and `n-1` has degree `m+n-2`, requiring `m+n-1` coefficients.
2. **Convolution:** Each pair `(i, j)` contributes `a[i] * b[j]` to power `i+j` in the result. The nested loop accumulates all such contributions.
3. **Determinism:** No randomness, no external calls; purely integer arithmetic in a fixed double loop.
4. **Correctness of edge cases:** Empty inputs return `[]`; zero polynomials yield all-zero coefficient lists; negative coefficients are handled naturally by Python's signed integer arithmetic.

The algorithm runs in O(n·m) time and O(n+m) space, which is optimal for dense polynomial multiplication via direct convolution and practical for typical constraint sizes.
