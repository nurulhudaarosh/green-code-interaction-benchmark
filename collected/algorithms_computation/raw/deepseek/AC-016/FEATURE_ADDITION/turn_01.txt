Here's a complete solution for simulating a non-preemptive single-server queue with priority scheduling.

## Problem Understanding

We need to simulate a single-server queue where:
- **Non-preemptive**: Once a job starts running, it runs to completion
- **Priority scheduling**: Higher priority jobs run first
- **Tie-breaking**: If priorities are equal, earlier arrival time wins; if still tied, smaller job ID wins
- **Output**: For each job, return completion time and waiting time; also compute average waiting time

## Key Constraints

1. Jobs arrive at specific times with given service times and priorities
2. Server can only process one job at a time
3. Server is idle if no jobs are available
4. Non-preemptive: no interruption once a job starts
5. Deterministic selection rule: (priority desc, arrival time asc, job ID asc)
6. Waiting time = start time − arrival time
7. Completion time = start time + service time

## Algorithm

1. **Sort** all jobs by arrival time (for efficient ingestion)
2. **Simulate** time using a priority heap for the ready queue
3. At each decision point:
   - Add all jobs that have arrived to the heap
   - If heap is non-empty, pop the highest-priority job
   - If heap is empty and no job has arrived, jump time forward to next arrival
4. Track start, completion, and waiting times

## Python Implementation

```python
import heapq
from dataclasses import dataclass


@dataclass
class Job:
    job_id: int
    arrival: int
    service: int
    priority: int  # larger = higher priority


def simulate(jobs):
    """
    Simulate a non-preemptive single-server priority queue.

    Selection rule: highest priority first; ties broken by
    earlier arrival, then smaller job_id.

    Returns:
        results: dict job_id -> (completion_time, waiting_time)
        avg_wait: average waiting time across all jobs
    """
    # Sort jobs by arrival for streaming into the ready queue
    jobs_sorted = sorted(jobs, key=lambda j: (j.arrival, j.job_id))

    # Heap entries: (-priority, arrival, job_id, service)
    heap = []
    n = len(jobs_sorted)
    idx = 0
    current_time = 0
    results = {}

    while idx < n or heap:
        # If heap empty, jump time to next arrival
        if not heap:
            current_time = max(current_time, jobs_sorted[idx].arrival)

        # Add all jobs that have arrived by current_time
        while idx < n and jobs_sorted[idx].arrival <= current_time:
            j = jobs_sorted[idx]
            heapq.heappush(heap, (-j.priority, j.arrival, j.job_id, j.service))
            idx += 1

        # Pop the highest-priority job
        neg_priority, arrival, job_id, service = heapq.heappop(heap)

        start_time = current_time
        completion_time = start_time + service
        waiting_time = start_time - arrival

        results[job_id] = (completion_time, waiting_time)
        current_time = completion_time

    avg_wait = sum(w for _, w in results.values()) / n if n else 0.0
    return results, avg_wait


# ---- Deterministic test / demonstration ----
if __name__ == "__main__":
    # Example jobs: (id, arrival, service, priority)
    jobs = [
        Job(1, 0, 5, 1),
        Job(2, 1, 3, 3),
        Job(3, 2, 2, 3),
        Job(4, 3, 4, 2),
        Job(5, 10, 1, 5),
    ]

    results, avg_wait = simulate(jobs)

    print("Job | Completion | Waiting")
    print("----+------------+--------")
    for job_id in sorted(results):
        comp, wait = results[job_id]
        print(f"{job_id:>3} | {comp:>10} | {wait:>7}")

    print(f"\nAverage waiting time: {avg_wait:.3f}")
```

The deterministic simulation uses only Python's standard library (`heapq`, `dataclasses`), requires no network access, no randomness, and no human interaction. The heap key `(-priority, arrival, job_id)` naturally enforces the required tie-breaking rules.
