## Problem Identification and Understanding

**Problem**: Given two strings, compute:
1. The length of the Longest Common Subsequence (LCS)
2. One actual LCS (not all possible LCSs)

**Deterministic Rule**: When multiple choices yield the same LCS length during reconstruction, prefer advancing in the first string (i.e., move up in the DP table).

**Key Constraints**:
- Input: Two strings (arbitrary length, typically reasonable for quadratic DP)
- Output: LCS length (integer) and one LCS string
- Must use standard library only
- No randomness, external services, or interaction
- Deterministic behavior required

**Algorithm**:
1. **DP Table Construction**: Build a 2D table where `dp[i][j]` = LCS length of `s1[0:i]` and `s2[0:j]`
2. **Reconstruction**: Trace back from `dp[m][n]` to `dp[0][0]`:
   - If characters match: include character, move diagonally
   - If `dp[i-1][j] >= dp[i][j-1]`: move up (prefer first string)
   - Else: move left

```python
def lcs_with_reconstruction(s1: str, s2: str):
    """
    Compute LCS length and reconstruct one LCS.
    Deterministic rule: on equal DP scores, prefer advancing in s1 (move up).
    
    Returns:
        tuple: (lcs_length, lcs_string)
    """
    m, n = len(s1), len(s2)
    
    # Step 1: Build DP table
    # dp[i][j] = LCS length of s1[:i] and s2[:j]
    dp = [[0] * (n + 1) for _ in range(m + 1)]
    
    for i in range(1, m + 1):
        for j in range(1, n + 1):
            if s1[i - 1] == s2[j - 1]:
                dp[i][j] = dp[i - 1][j - 1] + 1
            else:
                dp[i][j] = max(dp[i - 1][j], dp[i][j - 1])
    
    lcs_length = dp[m][n]
    
    # Step 2: Reconstruct LCS deterministically
    # Prefer moving up (advance in s1) when dp[i-1][j] >= dp[i][j-1]
    lcs_chars = []
    i, j = m, n
    
    while i > 0 and j > 0:
        if s1[i - 1] == s2[j - 1]:
            # Characters match - part of LCS
            lcs_chars.append(s1[i - 1])
            i -= 1
            j -= 1
        elif dp[i - 1][j] >= dp[i][j - 1]:
            # Prefer advancing in s1 (move up)
            i -= 1
        else:
            # Move left (advance in s2)
            j -= 1
    
    # Reverse since we built from end to start
    lcs_string = ''.join(reversed(lcs_chars))
    
    return lcs_length, lcs_string
```

**Complexity Analysis**:
- **Time**: O(m × n) for DP table construction + O(m + n) for reconstruction = O(m × n)
- **Space**: O(m × n) for the DP table
- **Deterministic**: Yes - tie-breaking rule ensures consistent output

**Key Implementation Details**:
1. The DP table is indexed with `dp[i][j]` representing LCS of prefixes `s1[:i]` and `s2[:j]`
2. Reconstruction uses the rule: when `dp[i-1][j] >= dp[i][j-1]`, move up (prefer s1)
3. Characters are collected in reverse and then reversed at the end
4. The solution handles edge cases (empty strings, no common subsequence, identical strings)

This implementation satisfies all requirements: it's deterministic, uses only standard library, performs quadratic DP, and reconstructs one valid LCS with the specified tie-breaking rule.
