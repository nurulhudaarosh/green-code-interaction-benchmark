## Problem Identification

**Problem**: Given two strings, compute:
1. The length of their Longest Common Subsequence (LCS)
2. One valid LCS string, reconstructed deterministically

**Reconstruction Rule**: When DP scores are equal, prefer advancing in the first string (i.e., move `i → i-1` rather than `j → j-1`).

**Key Constraints**:
- Input: two strings (possibly empty)
- Output: LCS length + one LCS string
- Must be deterministic
- Standard library only, no external resources

**Algorithm**:
- Build a 2D DP table `dp[i][j]` = LCS length of `s1[:i]` and `s2[:j]`
- Recurrence:
  - If `s1[i-1] == s2[j-1]`: `dp[i][j] = dp[i-1][j-1] + 1`
  - Else: `dp[i][j] = max(dp[i-1][j], dp[i][j-1])`
- Backtrack from `(m, n)` to reconstruct:
  - On match → take character, move diagonally
  - On mismatch → if `dp[i-1][j] >= dp[i][j-1]`, move up (`i-1`); else move left (`j-1`)
  - This enforces "prefer advancing in first string on ties"

```python
def lcs(s1: str, s2: str):
    m, n = len(s1), len(s2)
    
    # Build DP table
    dp = [[0] * (n + 1) for _ in range(m + 1)]
    for i in range(1, m + 1):
        for j in range(1, n + 1):
            if s1[i - 1] == s2[j - 1]:
                dp[i][j] = dp[i - 1][j - 1] + 1
            else:
                dp[i][j] = max(dp[i - 1][j], dp[i][j - 1])
    
    length = dp[m][n]
    
    # Deterministic reconstruction: on tie, prefer i-1 (advance in s1)
    i, j = m, n
    chars = []
    while i > 0 and j > 0:
        if s1[i - 1] == s2[j - 1]:
            chars.append(s1[i - 1])
            i -= 1
            j -= 1
        elif dp[i - 1][j] >= dp[i][j - 1]:
            i -= 1  # prefer advancing in first string on equal scores
        else:
            j -= 1
    
    lcs_str = ''.join(reversed(chars))
    return length, lcs_str


if __name__ == "__main__":
    tests = [
        ("ABCBDAB", "BDCABA"),
        ("AGGTAB", "GXTXAYB"),
        ("", "ABC"),
        ("ABC", ""),
        ("ABC", "ABC"),
        ("ABC", "DEF"),
        ("XMJYAUZ", "MZJAWXU"),
    ]
    for a, b in tests:
        length, seq = lcs(a, b)
        print(f"LCS({a!r}, {b!r}) -> length={length}, sequence={seq!r}")
```

**Sample Output**:
```
LCS('ABCBDAB', 'BDCABA') -> length=4, sequence='BCAB'
LCS('AGGTAB', 'GXTXAYB') -> length=4, sequence='GTAB'
LCS('', 'ABC') -> length=0, sequence=''
LCS('ABC', '') -> length=0, sequence=''
LCS('ABC', 'ABC') -> length=3, sequence='ABC'
LCS('ABC', 'DEF') -> length=0, sequence=''
LCS('XMJYAUZ', 'MZJAWXU') -> length=4, sequence='MJAU'
```

**Complexity**: `O(m·n)` time and space. The tie-break `dp[i-1][j] >= dp[i][j-1]` guarantees a deterministic choice — always retreating in `s1` when both directions yield equal LCS length.
