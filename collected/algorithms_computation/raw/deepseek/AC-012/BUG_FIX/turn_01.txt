### Problem Understanding

You are given two strings, and you need to:

1. Compute the **length of their Longest Common Subsequence (LCS)**.
2. Reconstruct **one LCS sequence** based on a deterministic rule: when there is a tie in the DP score and you must decide which string to advance in, **prefer advancing in the first string**.
   
### Key Constraints & Output

- Strings can be of any reasonable length (typical quadratic DP means up to several thousands length is manageable).
- Output:
  - The length of the LCS.
  - One LCS that follows the deterministic rule.

### Algorithm Description

1. **DP Table Construction (Quadratic Dynamic Programming):**  
   Use a 2D DP table where `dp[i][j]` represents the length of LCS of prefixes `s1[:i]` and `s2[:j]`.  
   Compute as:  
   - If `s1[i-1] == s2[j-1]`, then `dp[i][j] = dp[i-1][j-1] + 1`  
   - Else, `dp[i][j] = max(dp[i-1][j], dp[i][j-1])`

2. **Predecessor Reconstruction with Deterministic Rule:**  
   Starting from `dp[len(s1)][len(s2)]` trace back to `dp[0][0]`.  
   - If characters match, include that char in LCS and move diagonally.
   - Otherwise, if `dp[i-1][j] == dp[i][j-1]`, **prefer moving up (advance in the first string, decrement i)**.
   - Else, move in the direction of the larger dp value.

3. Construct the LCS sequence from the backtracking path and output both length and sequence.

---

### Python Implementation

```python
def lcs_with_deterministic_reconstruction(s1, s2):
    n, m = len(s1), len(s2)
    dp = [[0] * (m + 1) for _ in range(n + 1)]

    # Build DP table for LCS length
    for i in range(1, n + 1):
        for j in range(1, m + 1):
            if s1[i-1] == s2[j-1]:
                dp[i][j] = dp[i-1][j-1] + 1
            else:
                dp[i][j] = max(dp[i-1][j], dp[i][j-1])

    # Reconstruct LCS with deterministic rule:
    lcs_chars = []
    i, j = n, m
    while i > 0 and j > 0:
        if s1[i-1] == s2[j-1]:
            lcs_chars.append(s1[i-1])
            i -= 1
            j -= 1
        else:
            if dp[i-1][j] == dp[i][j-1]:
                # Tie: prefer moving up (advance in first string)
                i -= 1
            elif dp[i-1][j] > dp[i][j-1]:
                i -= 1
            else:
                j -= 1

    lcs_chars.reverse()
    lcs_str = ''.join(lcs_chars)

    return dp[n][m], lcs_str


# Example Usage
if __name__ == "__main__":
    a = "AGGTAB"
    b = "GXTXAYB"
    length, sequence = lcs_with_deterministic_reconstruction(a, b)
    print("LCS Length:", length)
    print("LCS sequence:", sequence)
```
