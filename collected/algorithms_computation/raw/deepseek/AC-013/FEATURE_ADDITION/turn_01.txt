**Problem identification.** We are given an integer matrix and a sequence of axis-aligned rectangle queries. For each query `(r1, c1, r2, c2)` with inclusive bounds, we must return the sum, minimum, and maximum of all cells inside that rectangle.

**Key constraints.**
- The matrix dimensions and number of queries can be large, so repeatedly scanning every rectangle naively may be too slow.
- Sum queries benefit from preprocessing because sums are additive.
- Minimum and maximum are not invertible, so a simple 2D prefix table does not directly answer them.
- The chosen mixed strategy uses an $O(RC)$ 2D prefix-sum table for sum queries and direct scanning for min/max.

**Required output.** For each query, print the rectangle sum, minimum, and maximum.

**Algorithm.**
1. Read the matrix dimensions `R`, `C` and the matrix values.
2. Build a 2D prefix-sum table `pref` of size `(R+1) x (C+1)`, where `pref[i][j]` is the sum of the submatrix from `(0,0)` to `(i-1,j-1)`.
3. For each query `(r1,c1,r2,c2)`:
   - Compute the sum in $O(1)$ using inclusion-exclusion:
     `sum = pref[r2+1][c2+1] - pref[r1][c2+1] - pref[r2+1][c1] + pref[r1][c1]`
   - Scan all cells in the rectangle to compute the minimum and maximum.
4. Print the three values.

This hybrid approach keeps sum queries fast while accepting a linear scan for extrema.

```python
import sys

def solve():
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    R = int(next(it))
    C = int(next(it))
    mat = [[0] * C for _ in range(R)]
    for i in range(R):
        for j in range(C):
            mat[i][j] = int(next(it))

    # 2D prefix sums
    pref = [[0] * (C + 1) for _ in range(R + 1)]
    for i in range(1, R + 1):
        row_sum = 0
        for j in range(1, C + 1):
            row_sum += mat[i - 1][j - 1]
            pref[i][j] = pref[i - 1][j] + row_sum

    Q = int(next(it))
    out_lines = []
    for _ in range(Q):
        r1 = int(next(it))
        c1 = int(next(it))
        r2 = int(next(it))
        c2 = int(next(it))

        # Inclusive rectangle sum via prefix table
        total = (
            pref[r2 + 1][c2 + 1]
            - pref[r1][c2 + 1]
            - pref[r2 + 1][c1]
            + pref[r1][c1]
        )

        # Direct scan for min and max
        mn = None
        mx = None
        for i in range(r1, r2 + 1):
            row = mat[i]
            for j in range(c1, c2 + 1):
                v = row[j]
                if mn is None or v < mn:
                    mn = v
                if mx is None or v > mx:
                    mx = v

        out_lines.append(f"{total} {mn} {mx}")

    sys.stdout.write("\n".join(out_lines))

if __name__ == "__main__":
    solve()
```
