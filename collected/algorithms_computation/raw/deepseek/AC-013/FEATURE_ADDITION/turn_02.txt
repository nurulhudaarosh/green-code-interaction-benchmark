**Original problem restatement.**

We are given an integer matrix and a sequence of axis-aligned rectangle queries. For each query `(r1, c1, r2, c2)` with inclusive bounds, we must return:

- the **sum** of all cells inside the rectangle,
- the **minimum** of all cells inside the rectangle,
- the **maximum** of all cells inside the rectangle.

The solution uses a mixed strategy: a 2D prefix-sum table for sum queries and direct rectangle scanning for extrema.

**Existing required outputs.**

For each query, the engine must produce the triple `(sum, min, max)`. All original fields and requirements remain unchanged when the new feature is disabled or not requested.

**New concrete feature.**

Add an additional `operation_summary` field containing a deterministic summary of the computation. For this task, `operation_summary` reports the **number of major computational decisions/operations made by the algorithm**.

We define major computational operations deterministically as:

- `1` operation for each prefix-table cell computed during preprocessing,
- `1` operation for each rectangle sum computed via inclusion-exclusion,
- `1` operation for each rectangle scanned for min/max,
- `1` operation for each cell visited during a min/max scan.

This makes the summary reproducible and independent of runtime, platform, or randomness.

**Updated behavior.**

- If the feature is requested, each query result includes the original `(sum, min, max)` plus an `operation_summary` value describing the cumulative major operations performed so far.
- If the feature is disabled or not requested, the output is exactly the original `(sum, min, max)` triples, unchanged.

**Algorithm.**

1. Read the matrix dimensions `R`, `C` and the matrix values.
2. Build a 2D prefix-sum table `pref` of size `(R+1) x (C+1)`, counting one major operation per prefix cell.
3. For each query `(r1,c1,r2,c2)`:
   - Compute the sum in $O(1)$ using inclusion-exclusion, counting one major operation.
   - Scan all cells in the rectangle to compute min and max, counting one major operation for the scan plus one per visited cell.
4. If the feature is enabled, include the cumulative `operation_summary`; otherwise print only `(sum, min, max)`.

```python
import sys

def solve():
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    R = int(next(it))
    C = int(next(it))
    mat = [[0] * C for _ in range(R)]
    for i in range(R):
        for j in range(C):
            mat[i][j] = int(next(it))

    # Feature flag: set True to include operation_summary
    include_operation_summary = True

    ops = 0  # major computational operations counter

    # 2D prefix sums
    pref = [[0] * (C + 1) for _ in range(R + 1)]
    for i in range(1, R + 1):
        row_sum = 0
        for j in range(1, C + 1):
            row_sum += mat[i - 1][j - 1]
            pref[i][j] = pref[i - 1][j] + row_sum
            ops += 1  # one operation per prefix cell computed

    Q = int(next(it))
    out_lines = []
    for _ in range(Q):
        r1 = int(next(it))
        c1 = int(next(it))
        r2 = int(next(it))
        c2 = int(next(it))

        # Inclusive rectangle sum via prefix table
        total = (
            pref[r2 + 1][c2 + 1]
            - pref[r1][c2 + 1]
            - pref[r2 + 1][c1]
            + pref[r1][c1]
        )
        ops += 1  # one operation per rectangle sum computation

        # Direct scan for min and max
        mn = None
        mx = None
        ops += 1  # one operation per rectangle scan
        for i in range(r1, r2 + 1):
            row = mat[i]
            for j in range(c1, c2 + 1):
                v = row[j]
                if mn is None or v < mn:
                    mn = v
                if mx is None or v > mx:
                    mx = v
                ops += 1  # one operation per visited cell

        if include_operation_summary:
            out_lines.append(f"{total} {mn} {mx} {ops}")
        else:
            out_lines.append(f"{total} {mn} {mx}")

    sys.stdout.write("\n".join(out_lines))

if __name__ == "__main__":
    solve()
```
