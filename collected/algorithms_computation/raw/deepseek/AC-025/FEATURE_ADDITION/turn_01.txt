## Problem Understanding

**Problem:** We have multiple stages, each requiring exactly one option to be selected. Each option has:
- Cost (budget consumption)
- Memory requirement  
- Score (value to maximize)

**Goal:** Maximize total score while staying within global budget and memory limits. For ties, choose the lexicographically smallest choice vector.

**Key Constraints:**
- Must select exactly one option per stage
- Total budget ≤ global budget limit
- Total memory ≤ global memory limit
- Deterministic tie-breaking (lexicographically smallest)
- No external dependencies or randomness

**Required Output:** The optimal selection vector (one option index per stage) and the maximum achievable score.

## Algorithm

**Layered Two-Resource Dynamic Programming with Deterministic Reconstruction:**

1. **State Definition:** `dp[i][b][m]` = maximum score achievable from stages `i` to end, given remaining budget `b` and memory `m`

2. **Recurrence:** For stage `i`, try each option `j`:
   - If affordable: `score[j] + dp[i+1][b-cost[j]][m-mem[j]]`
   - Take maximum

3. **Tie-breaking:** When scores are equal, prefer smaller option indices to ensure lexicographically smallest solution

4. **Reconstruction:** Trace back through DP table to recover optimal choices

from typing import List, Tuple, Optional

def solve_stages(stages: List[List[Tuple[int, int, int]]], 
                 budget_limit: int, 
                 memory_limit: int) -> Tuple[List[int], int]:
    """
    Solve multi-stage resource allocation problem.
    
    Args:
        stages: List of stages, each containing list of (cost, memory, score) tuples
        budget_limit: Maximum total budget
        memory_limit: Maximum total memory
    
    Returns:
        Tuple of (choice_vector, max_score)
        choice_vector: List of option indices (0-based) for each stage
        max_score: Maximum achievable score
    """
    n_stages = len(stages)
    if n_stages == 0:
        return [], 0
    
    # Initialize DP table: dp[i][b][m] = max score from stage i with remaining b, m
    # Use -1 to indicate impossible states
    dp = [[[-1] * (memory_limit + 1) for _ in range(budget_limit + 1)] 
          for _ in range(n_stages + 1)]
    
    # Base case: after all stages, score is 0 with any remaining resources
    for b in range(budget_limit + 1):
        for m in range(memory_limit + 1):
            dp[n_stages][b][m] = 0
    
    # Fill DP table backwards
    for i in range(n_stages - 1, -1, -1):
        for b in range(budget_limit + 1):
            for m in range(memory_limit + 1):
                best_score = -1
                
                # Try each option in current stage
                for opt_idx, (cost, mem, score) in enumerate(stages[i]):
                    if cost <= b and mem <= m:
                        next_score = dp[i + 1][b - cost][m - mem]
                        if next_score != -1:
                            total_score = score + next_score
                            if total_score > best_score:
                                best_score = total_score
                
                dp[i][b][m] = best_score
    
    # Check if solution exists
    if dp[0][budget_limit][memory_limit] == -1:
        return [], -1  # No valid solution
    
    # Reconstruct solution with deterministic tie-breaking
    choices = []
    b, m = budget_limit, memory_limit
    
    for i in range(n_stages):
        best_opt = -1
        best_score = -1
        
        # Try options in order (ensures lexicographically smallest on ties)
        for opt_idx, (cost, mem, score) in enumerate(stages[i]):
            if cost <= b and mem <= m:
                next_score = dp[i + 1][b - cost][m - mem]
                if next_score != -1:
                    total_score = score + next_score
                    # Use > (not >=) to prefer smaller indices on ties
                    if total_score > best_score:
                        best_score = total_score
                        best_opt = opt_idx
        
        if best_opt == -1:
            return [], -1  # Should not happen if DP is correct
        
        choices.append(best_opt)
        cost, mem, _ = stages[i][best_opt]
        b -= cost
        m -= mem
    
    return choices, dp[0][budget_limit][memory_limit]


def solve_with_validation(stages: List[List[Tuple[int, int, int]]],

    """

        for j, (cost, mem, score) in enumerate(stage):
            print(f"  Option {j}: cost={cost}, memory={mem}, score={score}")
    
    # Solve
    choices, max_score = solve_stages(stages, budget_limit, memory_limit)
    
    print("\n" + "=" * 60)
    print("SOLUTION")
    print("=" * 60)
    
    if max_score == -1:
        print("No valid solution exists!")
        return
    
    # Calculate actual resource usage
    total_cost = sum(stages[i][choices[i]][0] for i in range(len(stages)))
    total_mem = sum(stages[i][choices[i]][1] for i in range(len(stages)))
    total_score = sum(stages[i][choices[i]][2] for i in range(len(stages)))
    
    print(f"\nOptimal choice vector: {choices}")
    print(f"Maximum score: {max_score}")
    print(f"\nResource usage:")
    print(f"  Budget: {total_cost} / {budget_limit}")
    print(f"  Memory: {total_mem} / {memory_limit}")
    print(f"  Score:  {total_score}")
    
    # Validation
    print("\n" + "-" * 40)
    print("VALIDATION")
    print("-" * 40)
    assert total_score == max_score, "Score mismatch!"
    assert total_cost <= budget_limit, "Budget exceeded!"
    assert total_mem <= memory_limit, "Memory exceeded!"
    print("✓ All constraints satisfied")

## Key Features

1. **Deterministic:** No randomness, uses strict `>` comparison during reconstruction to prefer smaller indices on ties

2. **Two-Resource DP:** Handles both budget and memory constraints simultaneously

3. **Complete Solution:** Includes validation and multiple test cases

4. **Efficient:** O(stages × budget × memory × max_options_per_stage) time complexity

5. **Standard Library Only:** Uses only Python's built-in types and functionality

## Time & Space Complexity

- **Time:** O(N × B × M × K) where N=stages, B=budget, M=memory, K=max options per stage
- **Space:** O(N × B × M) for the DP table

The solution correctly handles the lexicographic tie-breaking requirement by using strict inequality during reconstruction, ensuring that when multiple options yield the same optimal score, the one with the smallest index is chosen at each stage.
