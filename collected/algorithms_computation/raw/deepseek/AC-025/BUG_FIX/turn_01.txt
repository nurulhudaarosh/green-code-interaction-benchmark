## Problem Understanding

**Problem:** We have multiple stages (layers). For each stage, we must choose exactly one option. Each option has:
- Cost (budget consumption)
- Memory consumption  
- Score (value to maximize)

**Constraints:**
- Total budget across all chosen options ≤ global budget limit
- Total memory across all chosen options ≤ global memory limit
- Must select exactly one option per stage

**Objective:**
- Maximize total score
- Tie-breaking: lexicographically smallest choice vector (where choice vector = indices of selected options per stage)

**Output:** The optimal choice vector (list of option indices, one per stage).

## Algorithm: Layered Two-Resource Dynamic Programming

**State:** `dp[i][b][m]` = maximum score achievable using stages `0..i-1` with exactly `b` budget and `m` memory consumed.

**Transition:** For stage `i`, for each option `j` with cost `c`, memory `mem`, score `s`:
```
dp[i+1][b+c][m+mem] = max(dp[i+1][b+c][m+mem], dp[i][b][m] + s)
```

**Reconstruction:** Store parent pointers or recompute. For lexicographic tie-breaking, we process options in index order and prefer earlier indices when scores tie. During reconstruction, we choose the smallest index option that achieves the optimal value.

**Complexity:** O(stages × budget × memory × options_per_stage)

## Python Implementation

```python
import sys

def solve(stages, budget_limit, memory_limit):
    """
    stages: list of lists of (cost, memory, score) tuples
    Returns: list of chosen option indices (lexicographically smallest among optimal)
    """
    n = len(stages)
    
    # dp[b][m] = best score using processed stages so far
    NEG = float('-inf')
    dp = [[NEG] * (memory_limit + 1) for _ in range(budget_limit + 1)]
    dp[0][0] = 0
    
    # parent[i][b][m] = (prev_b, prev_m, option_index) for reconstruction
    # We store per-stage snapshots
    parents = []
    
    for i in range(n):
        new_dp = [[NEG] * (memory_limit + 1) for _ in range(budget_limit + 1)]
        parent = [[None] * (memory_limit + 1) for _ in range(budget_limit + 1)]
        
        options = stages[i]
        for b in range(budget_limit + 1):
            row = dp[b]
            for m in range(memory_limit + 1):
                cur = row[m]
                if cur == NEG:
                    continue
                for j, (c, mem, s) in enumerate(options):
                    nb = b + c
                    nm = m + mem
                    if nb <= budget_limit and nm <= memory_limit:
                        val = cur + s
                        if val > new_dp[nb][nm]:
                            new_dp[nb][nm] = val
                            parent[nb][nm] = (b, m, j)
                        # Tie-break during forward pass: prefer smaller option index
                        elif val == new_dp[nb][nm]:
                            prev = parent[nb][nm]
                            if prev is not None and j < prev[2]:
                                parent[nb][nm] = (b, m, j)
        
        parents.append(parent)
        dp = new_dp
    
    # Find best final state
    best_score = NEG
    best_b = best_m = -1
    for b in range(budget_limit + 1):
        for m in range(memory_limit + 1):
            if dp[b][m] > best_score:
                best_score = dp[b][m]
                best_b, best_m = b, m
    
    if best_score == NEG:
        return None  # No feasible solution
    
    # Reconstruct
    choices = [0] * n
    b, m = best_b, best_m
    for i in range(n - 1, -1, -1):
        pb, pm, j = parents[i][b][m]
        choices[i] = j
        b, m = pb, pm
    
    return choices


def main():
    data = sys.stdin.read().split()
    if not data:
        return
    idx = 0
    n = int(data[idx]); idx += 1
    budget_limit = int(data[idx]); idx += 1
    memory_limit = int(data[idx]); idx += 1
    
    stages = []
    for _ in range(n):
        k = int(data[idx]); idx += 1
        opts = []
        for _ in range(k):
            c = int(data[idx]); idx += 1
            mem = int(data[idx]); idx += 1
            s = int(data[idx]); idx += 1
            opts.append((c, mem, s))
        stages.append(opts)
    
    result = solve(stages, budget_limit, memory_limit)
    if result is None:
        print("NO SOLUTION")
    else:
        print(' '.join(map(str, result)))


if __name__ == "__main__":
    main()
```

## Key Design Points

1. **Deterministic:** No randomness, fixed iteration order, explicit tie-breaking.
2. **Two-resource DP:** 2D state space (budget × memory) per layer.
3. **Lexicographic tie-break:** During transitions, when scores tie, the option with the smaller index is stored in `parent`. Since we process stages in order and store the smallest index at each state, reconstruction yields the lexicographically smallest choice vector among optimal solutions.
4. **Standard library only:** Uses only `sys`.
5. **Feasibility check:** Returns `None` if no valid selection exists under both limits.
