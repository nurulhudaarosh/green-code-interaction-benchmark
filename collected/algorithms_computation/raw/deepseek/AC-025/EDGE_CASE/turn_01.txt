I'll start by clarifying the general problem structure, then give a clean deterministic DP solution.

## Problem understanding

We have:

- `S` stages, `0 .. S-1`
- In each stage `i`, there are `n_i` options
- Each option `j` in stage `i` has:
  - `cost[i][j]` — budget consumption
  - `mem[i][j]` — memory consumption
  - `score[i][j]` — value gained
- We must choose **exactly one option per stage**
- Total budget must be `<= B`
- Total memory must be `<= M`
- Maximize total score
- If multiple choice vectors achieve the same maximum score, choose the **lexicographically smallest choice vector** (compare option indices stage by stage)

Output:
- The maximum total score
- The chosen option index for each stage
- Total used budget and memory

## Key constraints

The intended efficient approach is:

- `S` stages
- Budget limit `B`
- Memory limit `M`
- Each stage has a small to moderate number of options
- Need deterministic tie-breaking by lexicographically smallest option-index vector

A layered two-resource DP is appropriate:

`dp[i][b][m] = best score using first i stages with exactly/at most b budget and m memory`

To keep reconstruction deterministic and memory-efficient, store:

- `dp_prev[b][m]` and `dp_curr[b][m]`
- choice tracking for each layer, or recompute choices backward

For lexicographically smallest reconstruction, the cleanest approach is:

1. Compute DP forward
2. Find best final state
3. Reconstruct backward while choosing the smallest possible option index at each stage that can still achieve the optimum

But backward reconstruction tends to prefer later-stage small indices, not earliest-stage small indices. For lexicographic smallest vector, we want the first stage's index as small as possible, then second, etc.

So a robust deterministic method is:

- Compute suffix DP: `suf[i][b][m]` = best score from stages `i..S-1` with remaining budget `b` and memory `m`
- Then greedily build the answer from stage `0` to `S-1`:
  - At stage `i`, try options in increasing index order
  - Pick the first option `j` such that:
    - it fits current remaining budget/memory
    - `score[i][j] + suf[i+1][remaining_b - cost][remaining_m - mem] == best_total_remaining`
  - This guarantees lexicographically smallest choice vector

This is deterministic and standard-library only.

## Algorithm

Let:
- `B` = budget limit
- `M` = memory limit
- `S` = number of stages
- `cost[i][j]`, `mem[i][j]`, `score[i][j]`

Define suffix DP:

`suf[i][b][m] = maximum score obtainable from stages i..S-1 using at most b budget and at most m memory`

Base:
`suf[S][b][m] = 0`

Transition:
`suf[i][b][m] = max over option j where cost[i][j] <= b and mem[i][j] <= m of score[i][j] + suf[i+1][b-cost][m-mem]`

We can compress memory by storing `suf` for all layers if needed, or compute and keep all layers because reconstruction needs `suf[i+1]`. Given typical constraints, storing `S` layers of size `(B+1)*(M+1)` is acceptable. If memory is tight, we could store only suffix layers needed, but for clarity and determinism, keep them.

Then reconstruct:

- `best = suf[0][B][M]`
- `rem_b = B`, `rem_m = M`
- For `i` from `0` to `S-1`:
  - For `j` from `0` to `n_i - 1`:
    - if `cost[i][j] <= rem_b` and `mem[i][j] <= rem_m`
    - and `score[i][j] + suf[i+1][rem_b - cost][rem_m - mem] == suf[i][rem_b][rem_m]`
    - choose `j`, update remaining resources, break
- This yields lexicographically smallest vector because we test options in increasing index order at each stage from first to last.

## Python implementation

```python
import sys

def solve():
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)

    S = int(next(it))
    B = int(next(it))
    M = int(next(it))

    cost = []
    mem = []
    score = []

    for _ in range(S):
        n = int(next(it))
        c_row = []
        m_row = []
        s_row = []
        for _ in range(n):
            c = int(next(it))
            m = int(next(it))
            sc = int(next(it))
            c_row.append(c)
            m_row.append(m)
            s_row.append(sc)
        cost.append(c_row)
        mem.append(m_row)
        score.append(s_row)

    # suf[i][b][m] = best score from stages i..S-1 with at most b budget, m memory
    # Use list of 2D lists.
    suf = [None] * (S + 1)

    # base layer
    base = [[0] * (M + 1) for _ in range(B + 1)]
    suf[S] = base

    for i in range(S - 1, -1, -1):
        nxt = suf[i + 1]
        cur = [[-10**18] * (M + 1) for _ in range(B + 1)]

        opts = list(zip(cost[i], mem[i], score[i]))

        for b in range(B + 1):
            cur_b = cur[b]
            for m in range(M + 1):
                best = -10**18
                for c, mm, sc in opts:
                    if c <= b and mm <= m:
                        val = sc + nxt[b - c][m - mm]
                        if val > best:
                            best = val
                cur_b[m] = best
        suf[i] = cur

    best_score = suf[0][B][M]

    rem_b = B
    rem_m = M
    choices = []

    for i in range(S):
        chosen = -1
        for j, (c, mm, sc) in enumerate(zip(cost[i], mem[i], score[i])):
            if c <= rem_b and mm <= rem_m:
                if sc + suf[i + 1][rem_b - c][rem_m - mm] == suf[i][rem_b][rem_m]:
                    chosen = j
                    break
        if chosen == -1:
            raise RuntimeError("No valid choice found during reconstruction")
        choices.append(chosen)
        rem_b -= cost[i][chosen]
        rem_m -= mem[i][chosen]

    used_b = B - rem_b
    used_m = M - rem_m

    print(best_score)
    print(" ".join(map(str, choices)))
    print(used_b, used_m)

if __name__ == "__main__":
    solve()
```

## Notes on correctness

- The suffix DP computes optimal score for every remaining capacity pair.
- The greedy reconstruction from stage `0` forward checks options in increasing index order.
- It only accepts an option if the remaining suffix can still achieve the optimal value.
- Because the first stage is decided as small as possible, then the second, and so on, the resulting choice vector is lexicographically smallest among all optimal solutions.

## Complexity

Let `N = max options per stage`.

- Time: `O(S * B * M * N)`
- Space: `O(S * B * M)`

If `S * B * M` is too large, you can reduce space by storing only suffix layers needed for reconstruction, but the above is the straightforward deterministic standard-library solution.
