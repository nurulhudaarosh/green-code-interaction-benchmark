## Problem Restatement

**Largest Threshold Region Problem:**

Given:
- A rectangular grid of integers with dimensions R × C
- A threshold value T

Find the **largest 4-connected region** (orthogonally adjacent cells) where every cell has value ≥ T.

For the best region, output:
1. **Size** - number of cells in the region
2. **Perimeter** - number of exposed sides (edges adjacent to cells with value < T or outside the grid)
3. **Smallest coordinate** - the lexicographically smallest (row, column) pair within the region

**Tie-breaking rules (in order of priority):**
1. Prefer larger size
2. If sizes are equal, prefer larger perimeter
3. If both size and perimeter are equal, prefer smaller coordinate (row-major order: smaller row first, then smaller column)

---

## Key Difficult Cases Handled

### 1. Repeated Values and Identical Regions
When multiple regions have identical characteristics, the deterministic tie-breaking ensures consistent results.

### 2. Full Grid Regions
When all cells meet the threshold, the entire grid forms one region.

### 3. Multiple Regions with Same Size but Different Perimeters
The algorithm correctly selects the one with larger perimeter.

### 4. Multiple Regions with Same Size and Perimeter
The algorithm selects the one with the smallest coordinate.

import sys
from collections import deque

def find_best_region(grid, T):
    """Find the best 4-connected region with values >= T."""
    if not grid or not grid[0]:
        return 0, 0, (0, 0)
    
    R, C = len(grid), len(grid[0])
    visited = [[False] * C for _ in range(R)]
    
    best_size = 0
    best_perimeter = 0
    best_coord = (R, C)  # Initialize to max possible
    
    dirs = [(-1, 0), (1, 0), (0, -1), (0, 1)]
    
    for start_r in range(R):
        for start_c in range(C):
            if visited[start_r][start_c] or grid[start_r][start_c] < T:
                continue
            
            # BFS flood fill
            queue = deque([(start_r, start_c)])
            visited[start_r][start_c] = True
            cells = []
            min_r, min_c = start_r, start_c
            
            while queue:
                r, c = queue.popleft()
                cells.append((r, c))
                
                # Update smallest coordinate
                if r < min_r or (r == min_r and c < min_c):
                    min_r, min_c = r, c
                
                for dr, dc in dirs:
                    nr, nc = r + dr, c + dc
                    if 0 <= nr < R and 0 <= nc < C:
                        if not visited[nr][nc] and grid[nr][nc] >= T:
                            visited[nr][nc] = True
                            queue.append((nr, nc))
            
            # Calculate perimeter: count exposed sides
            perimeter = 0
            for r, c in cells:
                for dr, dc in dirs:
                    nr, nc = r + dr, c + dc
                    if nr < 0 or nr >= R or nc < 0 or nc >= C or grid[nr][nc] < T:
                        perimeter += 1
            
            size = len(cells)
            
            # Apply tie-breaking rules
            if (size > best_size or
                (size == best_size and perimeter > best_perimeter) or
                (size == best_size and perimeter == best_perimeter and 
                 (min_r < best_coord[0] or (min_r == best_coord[0] and min_c < best_coord[1])))):
                best_size = size
                best_perimeter = perimeter
                best_coord = (min_r, min_c)
    
    return best_size, best_perimeter, best_coord

def run_test_case(grid, T, expected_size, expected_perimeter, expected_coord, test_name):
    """Run a single test case and compare results."""
    size, perimeter, coord = find_best_region(grid, T)
    
    print(f"\n=== Test: {test_name} ===")
    print(f"Grid: {len(grid)}x{len(grid[0])}, T={T}")
    print("Grid:")
    for row in grid:
        print("  " + " ".join(str(x) for x in row))
    
    print(f"Result: size={size}, perimeter={perimeter}, coord={coord}")
    print(f"Expected: size={expected_size}, perimeter={expected_perimeter}, coord={expected_coord}")
    
    if (size == expected_size and perimeter == expected_perimeter and coord == expected_coord):
        print("✓ PASSED")
    else:
        print("✗ FAILED")
    
    return size == expected_size and perimeter == expected_perimeter and coord == expected_coord

    # Actually let's design two regions with same size:
    # Region 1: 2x3 rectangle at (0,0)-(1,2) - size 6, perimeter 10
    # Region 2: 3x2 rectangle at (0,2)-(2,3) - size 6, perimeter 10
    # Need different perimeters...
    
    # Simpler: two regions size 4, one is square (perimeter 8), one is line (perimeter 10)
    grid7b = [

    ]
    # Region A: 2x2 square at (0,0),(0,1),(1,0),(1,1) - size 4, perimeter 8, coord (0,0)
    # Region B: vertical line at col 3, rows 0-3 - size 4, perimeter 10, coord (0,3)

    return passed, total

def main():
    """Main function for production use."""
    # Read input
    line = sys.stdin.readline().strip()
    if not line:
        return
    
    R, C = map(int, line.split())
    grid = []
    for _ in range(R):
        row = list(map(int, sys.stdin.readline().split()))
        grid.append(row)
    
    T = int(sys.stdin.readline().strip())
    
    # Find and output the best region
    size, perimeter, coord = find_best_region(grid, T)
    print(size)
    print(perimeter)
    print(coord[0], coord[1])

if __name__ == "__main__":

    # test_all()
    
    # Production mode:

## Explanation of Key Implementation Details

### 1. **Flood Fill (BFS)**
- Iterates through all unvisited cells
- Only starts a new region when cell value ≥ T and not visited
- Uses a queue for deterministic order (though stack would work too)

### 2. **Perimeter Calculation**
- For each cell in the region, checks all 4 orthogonal neighbors
- Counts a side as "exposed" if:
  - Neighbor is outside grid bounds, OR
  - Neighbor's value < T

### 4. **Determinism**
- No randomness used
- Iteration order is fixed (row-major)
- BFS with deque ensures consistent traversal
- All comparisons use strict inequalities

### 5. **Edge Cases Handled**
- Empty grid
- No valid cells (returns size=0, perimeter=0, coord=(R,C))
- Single-cell regions
- Regions with holes (counts both outer and inner perimeter)
- Rectangular, L-shaped, and irregular regions

The solution uses only the Python standard library and produces exactly the required output format.
