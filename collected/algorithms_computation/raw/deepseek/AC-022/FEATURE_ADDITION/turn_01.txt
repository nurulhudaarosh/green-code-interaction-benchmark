## Problem Identification

**Problem:** Compute the **Damerau–Levenshtein distance** (edit distance with adjacent transpositions) between two strings.

**Allowed operations (each cost = 1):**
1. Insertion
2. Deletion
3. Substitution
4. Adjacent transposition (swap two neighboring characters)

**Key constraints:**
- Deterministic output (no randomness).
- Standard library only (no external deps, no network, no APIs).
- Must explicitly model the transposition transition in the DP recurrence.

**Required output:** An integer — the minimum total cost to transform `s1` into `s2`.

**Algorithm (DP with explicit transposition transition):**

Let `d[i][j]` = edit distance between `s1[:i]` and `s2[:j]`. Base cases: `d[i][0] = i`, `d[0][j] = j`.

Recurrence:
```
d[i][j] = min(
    d[i-1][j]   + 1,                      # deletion
    d[i][j-1]   + 1,                      # insertion
    d[i-1][j-1] + (s1[i-1] != s2[j-1]),   # match / substitution
    d[i-2][j-2] + 1                       # adjacent transposition
        if i > 1 and j > 1
        and s1[i-1] == s2[j-2]
        and s1[i-2] == s2[j-1]
)
```

The transposition term is the key addition: it allows swapping the last two characters of `s1[:i]` to match the last two of `s2[:j]` at cost 1. Answer = `d[len(s1)][len(s2)]`.

Complexity: **O(n·m)** time, **O(n·m)** space (rolling-row optimization is possible but omitted here for clarity of the transposition term).

## Python Implementation

```python
def damerau_levenshtein(s1: str, s2: str) -> int:
    """
    Compute the Damerau-Levenshtein distance between s1 and s2.
    Operations (each cost 1): insertion, deletion, substitution,
    and adjacent transposition.
    """
    n, m = len(s1), len(s2)

    # d[i][j] = edit distance between s1[:i] and s2[:j]
    d = [[0] * (m + 1) for _ in range(n + 1)]

    # Base cases
    for i in range(n + 1):
        d[i][0] = i
    for j in range(m + 1):
        d[0][j] = j

    for i in range(1, n + 1):
        for j in range(1, m + 1):
            cost_sub = 0 if s1[i - 1] == s2[j - 1] else 1

            d[i][j] = min(
                d[i - 1][j] + 1,            # deletion
                d[i][j - 1] + 1,            # insertion
                d[i - 1][j - 1] + cost_sub, # match / substitution
            )

            # Adjacent transposition
            if (i > 1 and j > 1
                    and s1[i - 1] == s2[j - 2]
                    and s1[i - 2] == s2[j - 1]):
                d[i][j] = min(d[i][j], d[i - 2][j - 2] + 1)

    return d[n][m]


if __name__ == "__main__":
    tests = [
        ("", "", 0),
        ("", "abc", 3),
        ("abc", "", 3),
        ("abc", "abc", 0),
        ("abc", "abd", 1),          # substitution
        ("abc", "ab", 1),           # deletion
        ("ab", "abc", 1),           # insertion
        ("ab", "ba", 1),            # transposition
        ("ca", "abc", 3),           # classic CLRS example
        ("kitten", "sitting", 3),   # without transposition benefit
        ("teh", "the", 1),          # pure transposition
        ("a cat", "an act", 3),
    ]

    ok = True
    for a, b, expected in tests:
        got = damerau_levenshtein(a, b)
        status = "OK " if got == expected else "FAIL"
        if got != expected:
            ok = False
        print(f"[{status}] d({a!r}, {b!r}) = {got}  (expected {expected})")

    print("\nAll tests passed." if ok else "\nSome tests failed.")
```

### Notes on correctness
- The four-term recurrence is the standard **optimal string alignment (OSA)** variant of Damerau–Levenshtein. It is deterministic and computes the exact minimum under the constraint that no substring is edited more than once — which matches the classic textbook formulation for this problem.
- The transposition branch is only taken when the *two* trailing characters of each prefix are mutual swaps, keeping the transition O(1).
