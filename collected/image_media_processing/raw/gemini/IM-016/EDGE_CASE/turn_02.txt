Here is the updated implementation.

The primary cause of errors or unexpected behavior with 1D/1-pixel-wide dimensions when using Scipy's `convolve2d` with `boundary='symm'` or `boundary='reflect'` is that Scipy requires the input array size to be strictly larger than the kernel dimensions along every axis being reflected.

To handle 1-pixel-wide ($1 \times H$) or 1-pixel-tall ($W \times 1$) images robustly with edge-replication, we explicitly pad the array using `np.pad(..., pad_width=1, mode='edge')` and apply the convolution using `'valid'` mode:

```python
from pathlib import Path
import numpy as np
from PIL import Image
from scipy.signal import convolve2d


def sobel_edges(input_dir: str | Path, output_dir: str | Path) -> None:
    """Applies explicit Sobel gradient convolution to all PNG and JPG images in

    input_dir and saves the clipped gradient magnitude to output_dir.

    Handles 1-pixel-wide or 1-pixel-tall edge cases safely using edge replication.
    """
    input_path = Path(input_dir)
    output_path = Path(output_dir)
    output_path.mkdir(parents=True, exist_ok=True)

    # 3x3 Sobel kernels
    Gx = np.array([[-1, 0, 1], [-2, 0, 2], [-1, 0, 1]], dtype=np.float32)

    Gy = np.array([[-1, -2, -1], [0, 0, 0], [1, 2, 1]], dtype=np.float32)

    valid_extensions = {".png", ".jpg", ".jpeg", ".bmp", ".webp"}

    for file_path in input_path.iterdir():
        if file_path.suffix.lower() not in valid_extensions:
            continue

        # Load image and convert to grayscale float32 array in [0, 255]
        img = Image.open(file_path).convert("L")
        img_arr = np.asarray(img, dtype=np.float32)

        # Replicate edge pixels explicitly (1 pixel on all sides).
        # This handles 1xN, Nx1, and 1x1 edge cases safely without boundary lookup errors.
        padded_img = np.pad(img_arr, pad_width=1, mode="edge")

        # Perform 2D spatial convolution on the padded array using 'valid' mode
        # to produce an output matching the original image dimensions.
        grad_x = convolve2d(padded_img, Gx, mode="valid")
        grad_y = convolve2d(padded_img, Gy, mode="valid")

        # Compute gradient magnitude
        magnitude = np.hypot(grad_x, grad_y)

        # Clip values to valid [0, 255] range and convert to uint8
        magnitude_clipped = np.clip(magnitude, 0, 255).astype(np.uint8)

        # Save result as grayscale PNG
        out_img = Image.fromarray(magnitude_clipped)
        out_file = output_path / f"{file_path.stem}_sobel.png"
        out_img.save(out_file)


if __name__ == "__main__":
    sobel_edges("input_images", "output_edges")

```

### Why This Fixes 1D Dimensions

* **Edge Replication (`mode='edge'`):** `np.pad(img_arr, pad_width=1, mode='edge')` duplicates the border pixel values. For a $1 \times H$ image, it expands the width to 3 by copying the single column to both the left and right sides.
* **Exact Shape Retention:** Convolving a $(H+2) \times (W+2)$ padded image with a $3 \times 3$ kernel in `mode='valid'` yields an output shape of strictly $H \times W$, preserving the exact dimensions even for $1 \times 1$, $1 \times N$, or $N \times 1$ inputs.
