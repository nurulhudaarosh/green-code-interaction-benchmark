The code above actually already used `max_dim <= 1920` for medium, but if you're using a version where that logic was strict (e.g., `elif max_dim < 1920:`), here is the explicitly corrected implementation:

```python
from pathlib import Path
import shutil
from PIL import Image

def organize_by_resolution(input_dir: str | Path, output_dir: str | Path) -> None:
    """
    Copies images from input_dir into 'small', 'medium', or 'large' 
    subfolders in output_dir based on their maximum dimension (width or height).

    Thresholds:
    - small:  max_dim < 640
    - medium: 640 <= max_dim <= 1920 (inclusive)
    - large:  max_dim > 1920
    """
    input_path = Path(input_dir)
    output_path = Path(output_dir)

    valid_extensions = {".jpg", ".jpeg", ".png", ".webp", ".bmp", ".tiff", ".gif"}

    for file_path in input_path.rglob("*"):
        if file_path.is_file() and file_path.suffix.lower() in valid_extensions:
            try:
                with Image.open(file_path) as img:
                    max_dim = max(img.width, img.height)

                # Classification logic using inclusive boundary for 1920
                if max_dim < 640:
                    category = "small"
                elif max_dim <= 1920:  # Includes exactly 1920px in 'medium'
                    category = "medium"
                else:
                    category = "large"

                target_dir = output_path / category
                target_dir.mkdir(parents=True, exist_ok=True)

                shutil.copy2(file_path, target_dir / file_path.name)

            except (IOError, SyntaxError) as e:
                print(f"Skipping non-image or corrupt file {file_path.name}: {e}")

```

### Key Logic

* **`max_dim < 640`** $\rightarrow$ `small` (1 to 639 px)
* **`max_dim <= 1920`** $\rightarrow$ `medium` (640 to 1920 px inclusive)
* **`else`** $\rightarrow$ `large` (1921+ px)
