You're right that there's still a subtlety in the previous version: even though I skip calling `GaussianBlur` at radius 0, re-saving via `img.copy().save(...)` re-encodes the image (recompresses JPEG, may drop metadata/ICC profiles, changes palette handling, etc.), so the output bytes aren't guaranteed identical to the input. The real fix is to copy the raw file bytes directly for the radius==0 case instead of decoding/re-encoding through Pillow at all.

```python
import os
import shutil
from PIL import Image, ImageFilter

def apply_blur(input_dir, output_dir, radius):
    if radius < 0:
        raise ValueError(f"radius must be non-negative, got {radius}")

    os.makedirs(output_dir, exist_ok=True)

    valid_ext = {".png", ".jpg", ".jpeg", ".bmp", ".gif", ".tiff", ".webp"}

    for name in os.listdir(input_dir):
        src_path = os.path.join(input_dir, name)

        if not os.path.isfile(src_path):
            continue
        if os.path.splitext(name)[1].lower() not in valid_ext:
            continue

        dst_path = os.path.join(output_dir, name)

        if radius == 0:
            # True passthrough: copy raw bytes, never decode/re-encode via Pillow.
            shutil.copyfile(src_path, dst_path)
            continue

        with Image.open(src_path) as img:
            result = img.filter(ImageFilter.GaussianBlur(radius=radius))
            result.save(dst_path)
```

Key change: for `radius == 0`, the function now calls `shutil.copyfile(src_path, dst_path)` and `continue`s — it never opens the image with Pillow at all in that branch, so the output file is byte-for-byte identical to the input (same encoding, metadata, ICC profile, everything). Pillow's `Image.open`/`.save()` round-trip is bypassed entirely for that case, which is what guarantees identity rather than just "visually indistinguishable."

For `radius > 0`, behavior is unchanged: open, apply `GaussianBlur(radius)`, save.
