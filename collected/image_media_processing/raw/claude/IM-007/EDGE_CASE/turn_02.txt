Good catch — worth handling explicitly rather than relying on float behavior. Here's the updated version, using integer arithmetic throughout (avoiding any floating-point rounding risk) so the tie-breaking rule is guaranteed rather than incidental:

```python
from PIL import Image


def compute_ahash(image_path, hash_size=8):
    """
    Compute the average hash (aHash) of an image.

    Classic algorithm:
      1. Load the image and convert to grayscale.
      2. Resize to (hash_size x hash_size) pixels.
      3. Compute the mean pixel value.
      4. Build a bit for each pixel: 1 if pixel >= mean, else 0.
      5. Pack the bits into an integer (the hash).

    Edge case: for a perfectly flat (uniform-color) image, every pixel
    equals the mean exactly. Ties are broken toward 1 (pixel >= mean),
    so a flat image always yields a well-defined hash of all 1s
    (i.e. 2**(hash_size**2) - 1), never an error or NaN-driven result.

    Args:
        image_path (str): Path to the image file.
        hash_size (int): Side length of the square the image is
            downsampled to. The resulting hash has hash_size**2 bits.
            Default is 8 (64-bit hash).

    Returns:
        int: An integer whose lowest hash_size*hash_size bits encode
            the hash (bit i corresponds to pixel i in row-major order,
            with the first pixel occupying the highest of those bits).
    """
    if hash_size <= 0:
        raise ValueError("hash_size must be a positive integer")

    with Image.open(image_path) as img:
        resample = getattr(Image, "LANCZOS", None) or Image.ANTIALIAS
        small = img.convert("L").resize((hash_size, hash_size), resample)
        pixels = list(small.getdata())

    n = len(pixels)
    total = sum(pixels)  # sum of pixel values, always an int

    # Compare pixel >= mean using only integers:
    #   pixel >= total / n  <=>  pixel * n >= total
    # This avoids any floating-point division/rounding, so the
    # comparison (and thus the tie-breaking rule) is exact and
    # deterministic — including when every pixel equals the mean.
    bits = 0
    for pixel in pixels:
        bits <<= 1
        if pixel * n >= total:
            bits |= 1

    return bits


def hamming_distance(hash_a, hash_b):
    """
    Compute the Hamming distance between two integer hashes,
    i.e. the number of bit positions at which they differ.

    Args:
        hash_a (int): First hash.
        hash_b (int): Second hash.

    Returns:
        int: Number of differing bits.
    """
    return bin(hash_a ^ hash_b).count("1")


if __name__ == "__main__":
    import sys

    if len(sys.argv) == 3:
        h1 = compute_ahash(sys.argv[1])
        h2 = compute_ahash(sys.argv[2])
        print(f"Hash 1: {h1:016x}")
        print(f"Hash 2: {h2:016x}")
        print(f"Hamming distance: {hamming_distance(h1, h2)}")
    else:
        print("Usage: python ahash.py <image1> <image2>")
```

**What changed and why**

- **`pixel * n >= total` instead of `pixel >= total / n`**: mathematically equivalent, but avoids ever computing a float mean. This matters for the flat-color case: previously `avg = sum/len` for an all-`p` image is `float(p)`, and while `p >= float(p)` happens to be exactly `True` in practice, that correctness was incidental — it relied on Python's float representation of small integers being exact. Doing the comparison purely in integers removes that dependency entirely and makes the tie-break provably exact for any `hash_size` and any pixel value range (0–255), with no rounding edge cases possible.
- **Explicit tie rule**: `>=` means ties go to `1`. For a fully uniform image every pixel equals the mean, so every comparison is a tie, and the result is deterministically the all-1s hash (`2**(hash_size**2) - 1`) — no exception, no NaN, no partial/garbage hash.
- **Two flat images of different colors now correctly hash identically** (both produce all-1s) and have Hamming distance `0`, which is the semantically correct answer: aHash intentionally can't distinguish flat colors from each other since it only encodes relative structure, not absolute brightness.
