```python
import os
from PIL import Image, ImageFilter


def apply_blur(input_dir, output_dir, radius):
    """
    Apply a Gaussian blur of the given radius to every image in input_dir,
    saving results to output_dir with the same filenames.

    Args:
        input_dir (str): Directory containing source images.
        output_dir (str): Directory to write blurred images to.
        radius (float): Gaussian blur radius. 0 means passthrough (no blur).
                        Negative values are rejected.

    Raises:
        ValueError: If radius is negative.
        NotADirectoryError: If input_dir is not a directory.
    """
    if radius < 0:
        raise ValueError(f"radius must be non-negative, got {radius!r}")

    if not os.path.isdir(input_dir):
        raise NotADirectoryError(f"input_dir is not a directory: {input_dir!r}")

    os.makedirs(output_dir, exist_ok=True)

    for filename in os.listdir(input_dir):
        src_path = os.path.join(input_dir, filename)
        if not os.path.isfile(src_path):
            continue

        dst_path = os.path.join(output_dir, filename)
        try:
            with Image.open(src_path) as img:
                if radius > 0:
                    blurred = img.filter(ImageFilter.GaussianBlur(radius=radius))
                else:
                    # radius == 0: passthrough (copy image without blurring)
                    blurred = img.copy()

                # Preserve the original format when possible; fall back to PNG.
                fmt = img.format or "PNG"
                blurred.save(dst_path, format=fmt)
        except (OSError, ValueError) as e:
            # Skip files that aren't valid images or can't be saved.
            print(f"Skipping {src_path!r}: {e}")
```

Key points:

- **Negative radius rejected** with `ValueError` before any work is done.
- **`radius == 0` passthrough** — the image is copied unchanged rather than run through `GaussianBlur` (Pillow's blur with radius 0 is a no-op anyway, but copying makes the intent explicit and avoids any filter overhead).
- **`input_dir` validation** via `os.path.isdir`, and `output_dir` created if missing.
- **Non-image files** (or unreadable ones) are skipped with a warning instead of crashing the whole batch.
- **Format preservation**: uses the source image's format when saving (e.g. JPEG stays JPEG). Note that for JPEG, repeated saves re-encode; if you need bit-exact passthrough at radius 0, you could `shutil.copy2` instead — but this implementation keeps the save path uniform.
