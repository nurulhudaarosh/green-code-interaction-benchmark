You're right — the original code has the filter call unconditionally on the `radius > 0` branch check, but there's a subtler issue: even the `else` branch's `img.copy()` can lose byte-identity for formats like JPEG because re-saving re-encodes the image. For a true passthrough at `radius == 0`, we need to copy the *file* itself, not the decoded image.

Here's the fix:

```python
import os
import shutil
from PIL import Image, ImageFilter


def apply_blur(input_dir, output_dir, radius):
    """
    Apply a Gaussian blur of the given radius to every image in input_dir,
    saving results to output_dir with the same filenames.

    Args:
        input_dir (str): Directory containing source images.
        output_dir (str): Directory to write blurred images to.
        radius (float): Gaussian blur radius. 0 means byte-exact passthrough
                        (file is copied, not re-encoded). Negative values
                        are rejected.

    Raises:
        ValueError: If radius is negative.
        NotADirectoryError: If input_dir is not a directory.
    """
    if radius < 0:
        raise ValueError(f"radius must be non-negative, got {radius!r}")

    if not os.path.isdir(input_dir):
        raise NotADirectoryError(f"input_dir is not a directory: {input_dir!r}")

    os.makedirs(output_dir, exist_ok=True)

    for filename in os.listdir(input_dir):
        src_path = os.path.join(input_dir, filename)
        if not os.path.isfile(src_path):
            continue

        dst_path = os.path.join(output_dir, filename)

        # radius == 0: byte-exact passthrough. Copy the file directly so we
        # never invoke the filter (whose kernel normalization is not exactly
        # identity even at radius 0) and never re-encode via Image.save.
        if radius == 0:
            shutil.copy2(src_path, dst_path)
            continue

        try:
            with Image.open(src_path) as img:
                blurred = img.filter(ImageFilter.GaussianBlur(radius=radius))
                fmt = img.format or "PNG"
                blurred.save(dst_path, format=fmt)
        except (OSError, ValueError) as e:
            print(f"Skipping {src_path!r}: {e}")
```

Why this is the correct fix, not just `img.copy()`:

1. **Skips the filter entirely at radius 0.** The `if radius == 0: shutil.copy2(...)` branch runs before `Image.open`, so `GaussianBlur` is never constructed and no filter kernel is applied. This addresses your point directly.

2. **Byte-identical output.** Even `img.copy()` followed by `blurred.save(...)` can produce bytes that differ from the input for lossy formats (JPEG re-encodes; PNG may re-compress with different zlib settings; EXIF/metadata may be dropped or reordered). `shutil.copy2` copies the raw file bytes and preserves mtime/metadata, guaranteeing byte-for-byte identity.

3. **Format-agnostic.** Works for any file type the caller considers an "image" at radius 0, without needing Pillow to parse it.

If your test only checks decoded pixel equality (not file bytes), `img.copy()` + `save` would pass — but your phrasing "output isn't byte-identical to input" implies file-level comparison, so `shutil.copy2` is the right tool.
