Looking at the code again, the branch is there, but let me make the passthrough genuinely byte-identical by copying the raw file rather than re-encoding through Pillow. Re-saving via `img.copy().save(...)` still re-encodes (JPEG especially will not be byte-identical), so the correct fix is to copy the file bytes directly when `radius == 0`.

```python
import os
import shutil
from PIL import Image, ImageFilter


def apply_blur(input_dir, output_dir, radius):
    """
    Apply a Gaussian blur of the given radius to every image in input_dir,
    saving the results to output_dir.

    Args:
        input_dir (str): Directory containing source images.
        output_dir (str): Directory to write blurred images to.
        radius (float): Gaussian blur radius. 0 means passthrough (byte-identical copy).
                        Negative values are rejected.

    Raises:
        ValueError: If radius is negative.
        NotADirectoryError: If input_dir is not a directory.
    """
    if radius < 0:
        raise ValueError(f"radius must be non-negative, got {radius}")
    if not os.path.isdir(input_dir):
        raise NotADirectoryError(f"input_dir is not a directory: {input_dir}")

    os.makedirs(output_dir, exist_ok=True)

    for filename in os.listdir(input_dir):
        src_path = os.path.join(input_dir, filename)
        if not os.path.isfile(src_path):
            continue

        dst_path = os.path.join(output_dir, filename)

        if radius == 0:
            # True passthrough: copy raw bytes, no decode/encode round-trip.
            shutil.copyfile(src_path, dst_path)
            continue

        try:
            with Image.open(src_path) as img:
                img.load()
                out = img.filter(ImageFilter.GaussianBlur(radius=radius))
                out.save(dst_path)
        except (IOError, OSError):
            # Skip files that aren't valid images.
            continue
```

Key changes:

- **`radius == 0` uses `shutil.copyfile`** instead of any Pillow round-trip, so the output is byte-for-byte identical to the input — including for lossy formats like JPEG where a decode/re-encode would change pixels.
- **The filter is only invoked for `radius > 0`**, so `GaussianBlur(0)` is never called and its floating-point kernel normalization can't perturb pixels.
- The `radius < 0` rejection is unchanged.

One behavioral note: with the byte-copy path, non-image files in `input_dir` will also be copied verbatim when `radius == 0`, whereas for `radius > 0` they're silently skipped. If you want strictly consistent behavior across radii (only images copied), say the word and I'll add an image-validation check before the copy.
