Here's a robust implementation of `rotate_and_crop` that handles rotation, center-cropping, and padding to ensure the output is exactly `crop_size`:

```python
import os
from pathlib import Path
from PIL import Image

# Common image extensions to process
IMAGE_EXTENSIONS = {'.jpg', '.jpeg', '.png', '.bmp', '.tif', '.tiff', '.webp'}


def rotate_and_crop(input_dir, output_dir, angle_degrees, crop_size):
    """
    Rotate each image in input_dir by angle_degrees and center-crop/pad it
    to exactly crop_size (width, height). Results are written to output_dir.
    
    Args:
        input_dir (str | Path): Directory containing input images.
        output_dir (str | Path): Directory to write processed images.
        angle_degrees (float): Rotation angle in degrees (counter-clockwise).
        crop_size (tuple[int, int]): Target size as (width, height).
    """
    input_dir = Path(input_dir)
    output_dir = Path(output_dir)
    output_dir.mkdir(parents=True, exist_ok=True)

    if not input_dir.is_dir():
        raise NotADirectoryError(f"Input directory not found: {input_dir}")

    target_w, target_h = crop_size
    if target_w <= 0 or target_h <= 0:
        raise ValueError("crop_size dimensions must be positive")

    for path in sorted(input_dir.iterdir()):
        if not path.is_file() or path.suffix.lower() not in IMAGE_EXTENSIONS:
            continue

        try:
            with Image.open(path) as img:
                # Preserve alpha channel if present; otherwise stay in RGB.
                if img.mode in ('RGBA', 'LA') or 'transparency' in img.info:
                    img = img.convert('RGBA')
                    fill = (0, 0, 0, 0)
                else:
                    img = img.convert('RGB')
                    fill = (0, 0, 0)

                # Rotate with expand=True so the whole image fits without clipping.
                rotated = img.rotate(
                    angle_degrees,
                    resample=Image.BICUBIC,
                    expand=True,
                    fillcolor=fill,
                )

                # Center-crop if larger than target, otherwise pad.
                rw, rh = rotated.size
                if rw >= target_w and rh >= target_h:
                    left = (rw - target_w) // 2
                    top = (rh - target_h) // 2
                    result = rotated.crop((left, top, left + target_w, top + target_h))
                else:
                    # Create a canvas and paste the rotated image centered.
                    canvas = Image.new(rotated.mode, (target_w, target_h), fill)
                    paste_x = (target_w - rw) // 2
                    paste_y = (target_h - rh) // 2
                    if rotated.mode == 'RGBA':
                        canvas.paste(rotated, (paste_x, paste_y), rotated)
                    else:
                        canvas.paste(rotated, (paste_x, paste_y))
                    result = canvas

                # Save with original extension; force a sensible default quality.
                out_path = output_dir / path.name
                save_kwargs = {}
                ext = path.suffix.lower()
                if ext in ('.jpg', '.jpeg'):
                    result = result.convert('RGB')
                    save_kwargs = {'quality': 95, 'subsampling': 0}
                elif ext == '.png':
                    save_kwargs = {'optimize': True}
                elif ext == '.webp':
                    save_kwargs = {'quality': 95}

                result.save(out_path, **save_kwargs)
                print(f"Processed: {path.name} -> {out_path.name}")

        except Exception as e:
            print(f"Failed to process {path.name}: {e}")


if __name__ == "__main__":
    rotate_and_crop("input_images", "output_images", angle_degrees=30, crop_size=(512, 512))
```

### Key behaviors

- **Rotation**: `expand=True` ensures nothing is clipped off during rotation; corners are filled with black (or transparent for images with alpha).
- **Crop vs. pad**: If the rotated image is larger than the target in both dimensions, it's center-cropped. If it's smaller in either dimension, a canvas of exactly `crop_size` is created and the rotated image is pasted centered — so the result is *always* exactly `crop_size`.
- **Alpha preserved**: RGBA images keep transparency; JPEGs are forced to RGB (required by the format).
- **Format-aware saving**: JPEGs use high quality with no chroma subsampling; PNGs are optimized; WebP uses quality 95.

### Notes / possible tweaks

- **Angle convention**: PIL rotates counter-clockwise for positive angles. Use negative values for clockwise.
- **Fill color**: Change `fill` if you'd prefer white or another background instead of black/transparent.
- **Resampling filter**: `BICUBIC` is a good default; `LANCZOS` gives slightly sharper results at the cost of speed.
- **Filename collisions**: If `input_dir` has subdirectories, only top-level files are processed. Add `rglob` if you want recursion.
